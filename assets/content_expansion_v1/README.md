# 달그늘 콘텐츠 확장 에셋 · v1

2026-10-08 장기 콘텐츠 기획안의 디자인 후보를 준비하는 전용 폴더입니다. 게임 적용, 경제 수치 확정, 생산·저장 코드 변경은 포함하지 않습니다. 제작 완료 여부는 `catalog.json`의 `status`와 각 품목의 `status`를 기준으로 확인합니다.

**제작 완료:** 전체 67개 품목 중 신규 원본 57개를 생성하고, 기존 10개 품목과 설비 기본 외형 4개를 재사용했습니다. 물약 병 32개, 재배 성장 시트 10개, 설비 단계 아이콘 24개를 포함합니다. 모든 경로·PNG 크기·투명 알파·병의 고유 픽셀 데이터·성장 변화·설비 3단계 차이 검사에 통과했습니다. 재사용 입력 PNG 20개의 SHA-256도 제작 전후 동일합니다. 분류별 비교 시트를 직접 확인했으며, 게임에는 연결하지 않은 디자인 후보입니다.

## 파일 구조와 사용

- `catalog.json`: 품목명, 안정적인 영문 ID, 분류·계열·지역, 아이콘·병·성장·단계별 경로, 재사용 여부, 완료 상태. 경로는 Godot `res://` 기준입니다.
- `asset-list.csv`: 최종 검증 시 생성하는 동일 품목 목록. 스프레드시트에서 검토할 수 있습니다.
- `source/`: 내장 imagegen으로 만든 실제 투명 PNG 원본과 품목별 `.generation.json`. 프롬프트와 원래 생성 경로를 함께 보관합니다.
- `potions/`: 32 × 40 목록 아이콘과 12 × 16 진열·전달용 병. 두 파일은 같은 원본에서 비율을 유지해 가져옵니다.
- `materials/`: 32 × 40 재료 아이콘. 재배 품종의 성장 시트는 64 × 80이며, 32 × 40 프레임 4개를 2 × 2로 배치합니다. 순서는 새싹·성장·성숙·수확입니다.
- `regions/`, `employees/`, `families/`: 각각 32 × 40 투명 아이콘.
- `equipment/`: 각 설비의 `_basic.png`, `_improved.png`, `_premium.png`. 목록 기본 아이콘은 `_basic.png`를 참조합니다.
- `tiers/`: 기존 SVG UI와 함께 쓸 수 있는 단순 단계 표시. 실제 투명 배경, 선명한 픽셀 모서리.
- `previews/`: 실제 아이콘과 병의 1배·2배 크기를 함께 보여주는 비교 시트. 화면 배치 시안이 아닌 콘텐츠 아트 검토 자료입니다.
- `verification/`: 크기·알파·완료 범위·기존 파일 보존 검사 결과.

이미지 생성은 내장 imagegen을 사용합니다. 크기 가져오기에서는 전체 피사체를 자르고 nearest 방식으로 축소하며 원본 알파를 보존합니다. 병이나 식물의 일부를 코드로 다시 그리지 않습니다. 12 × 16 병은 실루엣과 색으로 구별하고 문양은 목록 아이콘에서 더 명확하게 보입니다. 품목명을 아이콘과 함께 표시하는 사용을 권장합니다.

## 독립 검토 도구

`build_art.gd`는 이 폴더의 목록을 읽어 존재하는 원본을 내보냅니다. `preview_art.gd`는 가게 스크립트를 불러오지 않고 비교 시트를 렌더합니다. `validate_art.gd`는 전체 범위와 PNG의 크기·실제 투명 알파·병 중복·성장 프레임·설비 3단계 외형을 검사하고 CSV를 생성합니다. 플레이어 저장을 읽거나 쓰지 않습니다.

Godot 4.6에 프로젝트 경로와 아래 스크립트를 전달합니다. 검토 실행 시 APPDATA를 이 폴더의 `verification/appdata`로 지정하면 로그도 별도로 보관할 수 있습니다.

```text
--headless --path <프로젝트> --script res://assets/content_expansion_v1/build_art.gd
--path <프로젝트> --script res://assets/content_expansion_v1/preview_art.gd
--headless --path <프로젝트> --script res://assets/content_expansion_v1/validate_art.gd
```

## 범위 분리와 후속 항목

이 폴더의 새 에셋은 아직 게임에 연결하지 않습니다. `scripts/`, `scenes/`, `project.godot`, 승인된 `assets/items_v1/`·`assets/management_v1/`, 공용 README·기획 문서는 이 제작 작업에서 수정하지 않습니다. 다른 대화의 작업실 UI 시안 폴더도 수정하지 않습니다.

폴더 소유 범위가 확정되기 전에 만든 `assets/expansion_v1/`의 초기 목록·도구·기준 해시와 `assets/source/expansion_v1/`의 빈 준비 폴더는 삭제·이동하지 않았습니다. 현재 정식 에셋 목록은 이 폴더의 `catalog.json`이며, 초기 준비 파일의 실제 경로는 `legacy_preparation_artifacts`에 기록합니다.

기획 문서에 언급된 지역 기념품 8종은 이번 전달된 명시 제작 범위에 포함되지 않아 추가 제작 후보로 별도 기록합니다. 게임 연결, 확정 이름·효과·가격, 실제 훈련 단계 연결도 후속 개발 작업입니다.
