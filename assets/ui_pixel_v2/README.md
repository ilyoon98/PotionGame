# 관리 아이콘 · 픽셀 규칙 통일 v2

2026-11-05 사용자의 캐릭터·약초·원정과 기존 아이콘 전반 개선 요청에 따라 연결한 표시 전용 자산이다. 기존 자산은 덮어쓰지 않는다. 별도의 새 그림 승인을 받았다고 기록하지 않는다.

- 새 그림: 원정 9종, 재료 12종, 직원 역할 4종, 강화 계열 4종, 공통 UI 8종, 설비 8계열 × 3단계, 명성·동전의 16px 보조본 2종. 총 63 PNG.
- 물약: 승인된 작업실 병 40종을 정확히 2배로 확대하여 32×32 투명 캔버스에 배치했다. 레시피와 물약 목록에서 같은 그림을 쓴다. 기존 병의 코르크 경계색은 원본 그대로다.
- 일반 아이콘 32×32, 작은 명성·동전 16×16, 승인된 24색의 재질 램프 안에서 개별 최대 5색, 알파 0/255. 새 그림의 외곽선은 `#241C32` 1픽셀이다.
- 목록의 48px 칸에는 32px 그림을 1배로 중앙 배치한다. 배합·보상 32px 칸에서도 1배다. 실제 그림이 슬롯에 정확히 정수 배율로 들어갈 때만 확대한다.
- 캐릭터 5명 및 기존 승인된 화분 성장 그림 11종은 원본을 유지한다. 성장 그림은 기존 색상 규칙 예외이며 이 폴더의 규격 통과 주장에 포함하지 않는다.

`catalog.json`은 `scripts/ui_pixel_catalog.gd`가 읽는다. `icons`는 ID→경로, `equipment`는 계열→기본·개량·고급 경로 배열이다. 경제 데이터와 저장 형식을 바꾸지 않고 ItemArt/ManagementArt에서 우선 선택한다. 자산이 없으면 기존 경로를 사용한다.

재현 순서:

1. `tools/build_ui_pixel_v2.py`: 내장 image_gen의 원본 시트를 분리하고 고정 `process_pixel_art.py`의 배경 정리→원본 격자→재질 램프→검사를 거쳐 63개를 게시한다.
2. `tools/build_ui_pixel_v2_potions.py`: 승인 병의 RGBA를 보존하여 40개 목록 그림을 포장하고 캐릭터 감사 결과를 쓴다.
3. `tools/publish_ui_pixel_v2.py`: 경로와 별칭을 합치고 자체 포함 비교 페이지를 만든다.
4. Godot headless editor import 후 `tools/verify_ui_pixel_v2.gd` 실행. GPU 실행은 관리 화면도 캡처한다.

원본·프롬프트·재질 마스크·검사·비교 페이지는 `art/mockups/ui-pixel-v2/`에 있다. 실제 게임 렌더 검증은 `.verification/ui-pixel-v2/`에 별도로 기록한다.
