# 새 손님 전신 디자인 시안

여마법사, 엘프, 고양이 도적의 전신을 새로 생성한 디자인 시안입니다.
여행자는 기존 걷기의 양발 교대가 정상이라 재생성하지 않았습니다.

- 원본: `assets/source/customer_redesign_v1/`
- 생성 도구와 전체 프롬프트: `generation.json`
- 각 캐릭터: 대기 / 걷기 1 / 걷기 2 / 구매 완료
- 프레임: 투명 RGBA 48×64, 시트: 96×128, 행 우선 2×2
- 걷기 1·2: 서로 반대쪽 다리가 앞으로 나오는 착지 자세
- `all_poses_4x.png`: 전체 자세 비교
- `walk_preview_4x.gif`: 두 걷기 자세를 6fps로 반복하는 미리보기

생성 원본의 전신을 자르고, 캐릭터별로 동일한 비율로 축소하며 머리 위치와
발바닥 기준선을 맞췄습니다. 기존 몸통에 새 다리를 합성하지 않았습니다.
여마법사와 고양이 도적 원본의 중간 걷기 자세는 같은 다리를 반복하여
제외했습니다. 이번 출력은 4프레임 걷기 완성본이 아니라 두 착지 자세의 시안입니다.

현재 게임의 `animations_v1` 연결은 그대로이며 이 시안은 아직 적용되지 않았습니다.
재출력: `tools/prepare_customer_redesign.py` (Pillow 사용).
