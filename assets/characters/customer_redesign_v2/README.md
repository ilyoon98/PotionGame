# 여행자 기준 손님 전신 재제작 시안 v2

기존 여행자의 머리·몸 비율과 낮은 해상도의 도트 표현을 참조해
여마법사, 엘프, 고양이 도적의 전신을 새로 생성했습니다.
복잡한 장식과 명암을 줄여 캐릭터별 24색 공통 팔레트로 출력했습니다.
기존 몸통에 다리만 합성하는 방식은 사용하지 않습니다.

- 프레임: 투명 RGBA 48×64
- 시트: 96×128, 행 우선 2×2 (대기 / 걷기 1 / 걷기 2 / 구매 완료)
- 실루엣 최대 높이: 엘프·도적 47px, 모자를 포함한 마법사 56px
- 비교 기준: 기존 여행자 대기 실루엣 32×47px
- 걷기: 두 착지 자세에서 띠가 있는 가까운 쪽 부츠가 앞·뒤로 교대
- 마법사: 다리 구분을 위해 짧은 외투 아래 단순한 보라색 바지로 정리

`traveler_comparison_1x.png`는 원본 크기, `traveler_comparison_2x.png`는
게임 표시 배율의 비교 이미지입니다. 왼쪽부터 기존 여행자, 새 마법사,
새 엘프, 새 도적입니다. `walk_preview_2x.gif`도 같은 순서와 배율입니다.
`all_poses_4x.png`에는 새 캐릭터의 전체 자세가 있습니다.

현재는 게임에 연결되지 않은 검토용 시안입니다. 원본과 프롬프트는
`assets/source/customer_redesign_v2/`, 프롬프트 사본은 `generation.json`에 있습니다.
생성 도구: built-in image_gen. 재출력 명령:
`python tools/prepare_customer_redesign.py --version v2` (Pillow 필요).
