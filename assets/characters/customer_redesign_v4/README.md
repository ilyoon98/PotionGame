# 첨부 디자인 기준 손님 전신 시안 v4

사용자가 제공한 캐릭터 콘셉트의 의상과 색상을 기준으로,
기존 여행자의 등신·도트 크기에 맞춘 전신 시안입니다.

- 마법사: 긴 보라색 로브, 큰 모자, 은은한 눈 밑 그림자. 바지로 대체하지 않음.
- 엘프: 갈색 상체 의상과 아이보리·연두색의 가벼운 천 패널, 은발.
- 고양이 도적: 첨부 그림의 주황색 머리·귀·꼬리, 검은 상의와 짧은 바지, 단순한 붉은 스카프.
- 걷기: 두 전신 자세의 팔 위치와 다리 겹침을 재구성. 마법사는 노출된 다리가 첫 걸음에서는 앞, 둘째 걸음에서는 뒤로 이동하도록 수정.
- 마법사·엘프의 천 자락이 보행 자세를 따라 움직임.
- 프레임 48×64, 시트 96×128, 투명 RGBA, 캐릭터별 24색.
- 전체 자세: 대기 / 걷기 1 / 걷기 2 / 구매 완료.

`walk_preview_2x.gif`: 실제 게임 표시 배율의 비교. 왼쪽부터
기존 여행자, 새 마법사, 새 엘프, 새 도적입니다.
`all_poses_2x.png`와 `all_poses_4x.png`: 전체 자세 비교.

전신을 함께 그린 원본을 자르고 동일 비율로 축소했습니다.
기존 몸통에 다리를 붙이는 합성은 하지 않았습니다.
생성물의 작은 독립 점 잡음은 크기 측정에서 제외하여 프레임 기준선을 정리했습니다.
생성 도구는 built-in image_gen이며 전체 프롬프트와 수정 프롬프트는 `generation.json`에 기록했습니다.
원본·디자인 기준 그림·자세 기준 그림은 `assets/source/customer_redesign_v4/`에 보존했습니다.

2026-10-07 게임 적용 완료. 마법사·엘프·고양이 도적의 대기·걷기 2장·구매 완료 자세를 이 폴더에서 불러옵니다. 걷기는 6fps, 2배 정수 확대이며 입장과 퇴장에 모두 적용합니다. 여행자와 상점 주인은 기존 `animations_v1`을 유지하고, 여기사는 제외합니다.
재출력: `python tools/prepare_customer_redesign.py --version v4` (Pillow 사용).
