# 특별 레시피와 포션 디자인 · v1

2026-10-08. 디자인 제작용 후보 4종을 위한 전용 에셋 폴더입니다. 이름과 설정은 후보이며, ID는 에셋 연결을 위한 예약 이름입니다. 실제 아이템 등록·배합 확정·가격·제조 시간·획득 규칙·발견 확률은 이 아트 작업에서 결정하지 않습니다.

**제작 완료:** 독립 생성 원본 12개와 최종 PNG 12개를 모두 저장했습니다. 크기·실제 투명 알파·서로 다른 작은 병 실루엣 검사에 통과했고, 기존 일반 물약과 나란히 비교한 두 시트를 직접 확인했습니다. 비교에 사용한 기존 승인 이미지 8개의 SHA-256도 제작 전후 동일합니다. 게임 연결은 대기 상태입니다.

## 산출물과 연결

각 ID마다 `potions/<ID>_icon.png` 32×40, `potions/<ID>_12x16.png` 12×16, `recipes/<ID>_recipe.png` 32×40의 투명 PNG를 제공합니다. 레시피는 대응 포션의 주색과 문양을 반복하는 별도 두루마리 그림이며 병 이미지를 재사용하지 않습니다. 총 4세트, 출력 PNG 12개입니다.

`catalog.json`에는 후보명·지역·세 경로·정확한 규격·제작 상태와 `connection_status: awaiting_game_integration`을 기록합니다. `connected_to_game`은 false입니다. 실제 원정에서 레시피를 얻는 방식이 확정된 뒤 개발이 연결합니다. 아트 생성 자체는 지급·해금·보상 추첨을 발생시키지 않습니다.

## 원본과 제작 기록

내장 imagegen을 사용했습니다. `source/`에는 포션·레시피·작은 병을 각각 별도 생성한 PNG 원본 12개와 개별 `.generation.json`을 보관합니다. 전체 최종 프롬프트·참조 역할·원래 생성 경로는 `source/generation.json`에 모읍니다.

작은 병은 32×40 아이콘을 그대로 축소한 파일이 아닙니다. 별도 생성한 원본에서 복잡한 장식과 문양을 줄이고 실루엣과 색을 우선했습니다. 파일 내보내기는 알파 경계로 피사체 전체를 맞춰 자르고 nearest 방식으로 규격에 맞춥니다. 원본 알파를 보존하며 피사체를 코드로 다시 그리지 않습니다. 작은 병의 문양은 몇 픽셀의 표시로 간략해집니다.

## 비교와 검증

- `previews/pairs-and-general-comparison.png`: 특별 포션·전용 레시피·작은 병 4쌍, 기존 성장·은신·달빛·별빛 물약과의 비교. 아이콘 3배, 작은 병 실제 크기 및 4배.
- `previews/small-bottles.png`: 특별 물약 4종의 실제 12×16 병과 8배 확대.
- `verification/art-validation.json`: 정확한 크기, 비어 있지 않은 실제 알파, 모서리 투명 여백, 12개 출력의 서로 다른 픽셀 데이터, 작은 병 4종의 서로 다른 실루엣 검사.
- `verification/approved-preservation.json`: 비교용 기존 아이콘과 병 8개 파일의 제작 전후 SHA-256.
- `verification/art-manifest.json`: PNG 파일 경로·크기·SHA-256.

기존 `content_expansion_v1/`은 비교용으로 읽기만 합니다. 새 산출물과 검토 도구는 모두 이 폴더에 있습니다. 게임 코드·씬·기존 프로젝트 설정·경제 데이터·저장 파일은 수정하지 않습니다. Computer Use와 화면 입력, 포커스 변경, 눈에 보이는 게임·에디터 실행을 사용하지 않습니다.

## 화면을 띄우지 않는 검토 도구

`verification/export_art.gd`는 별도 SceneTree로 PNG를 가져오고 검사합니다. 새 폴더를 작업 경로로 지정해 Godot의 `--headless --script`로 실행하며 게임 스크립트는 로드하지 않습니다. APPDATA도 이 폴더의 `verification/appdata/`로 분리합니다.

`render_preview.ps1`은 System.Drawing의 메모리 비트맵에 그림과 검토용 캡션을 배치해 PNG를 저장합니다. 창과 사용자 입력을 생성하지 않는 파일 렌더입니다. 비교 시트의 캡션만 읽을 수 있는 글씨를 사용하며 실제 게임 아이콘에는 글씨가 없습니다.
