# 캐릭터 비율·남캐 설정 수정 목업 v3

2026-10-13 사용자 지적을 반영한 수정 후보이다. 모자 끝부터 발끝까지의 실루엣 높이를 맞추던 기준을 폐기하고, 모자 아래 머리·얼굴과 몸의 크기를 기준으로 삼았다. 모자 없는 엘프는 32×48 캔버스 위쪽에 투명 여백을 남긴다.

- 주인은 원본 남캐로 복원: 짧은 갈색 머리, 크림색 하이넥 셔츠, 앞이 열린 보라 망토, 갈색 반바지, 드러난 무릎과 갈색 부츠. 원본 `assets/source/character_idle_v2/keeper.png`를 신원·의상 참고로 사용했다.
- 엘프는 큰 머리만 교체했다. 원본 y≥27의 몸·손·발 픽셀은 그대로다. 새 머리 영역은 18×13이며 이전 머리 약29×26보다 작다. 얼굴 높이는 두 캐릭터 모두 약7 native 픽셀이다. 귀와 얼굴 방향 때문에 노출 피부의 가로폭까지 완전히 같다고 주장하지 않는다.
- 두 캐릭터는 같은 원본 크기32×48·공통3배를 사용하며, 장면 원점 y=32 / 발 마지막 행 y=46으로 지면이 일치한다. 모자 때문에 남자 주인의 전체 실루엣은 더 높다.
- 발판 제거, 8종 진열, 창밖 날씨, 솥 기포, 불꽃, 호흡·깜빡임, 일반 DOM 텍스트는 v2와 같은 기준이다. 받은 물약은 손과 함께 고정한다.

## 보기

- `animated-preview.html` / `animated-preview.gif`: 최신 움직임 전체 화면. HTML에서 날씨·재생을 비교한다.
- `character-comparison.png`: 이전/수정 캐릭터의 같은 배율 비교.
- `still.png` / `still-2x.png`: 전체 화면 확인. 2배본은 도트 확인용이다.
- `characters/`: 남자 주인과 수정 엘프의 원본·3배 PNG, 생성 소스·재질 마스크·눈 좌표·검사 보고서.
- `generation.json`: built-in image_gen 최종 프롬프트와 참고 이미지 기록.
- `validation.json`: 팔레트·반투명·원본 격자·IDLE·정수 배율 검사.

## 재현

기존 v2 효과를 만든 뒤 다음 순서로 실행한다. Pillow·NumPy가 필요하다.

```powershell
python tools/prepare_character_proportions_v3.py
python tools/build_character_corrected_mockup.py
```

같은 `process_pixel_art.py`의 배경 정리 → 원본 격자 → 재질별 램프 → 검사 함수를 사용한다. 머리가 캔버스 높이에 맞춰 다시 커지지 않도록 엘프 머리를 독립 처리한 뒤 원본 몸에 붙인다. 눈처럼 격자 정리에서 사라질 수 있는 작은 특징은 명시적인 재질 마스크로 보존한다. 각 캐릭터는 최대5색, 팔레트 밖0색, 반투명0픽셀이다. 글자 안티앨리어싱은 스프라이트 검사에서 제외한다.

팔레트 승인은 유지되지만 새 캐릭터 후보의 승인을 의미하지 않는다. 실제 Godot 런타임 연결은 이 목업 작업에 포함하지 않았다.
