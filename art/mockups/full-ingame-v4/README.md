## 움직임 기준

원본 캐릭터를 다시 생성하지 않고, 수정된 v3 남캐의32×48 격자에서 지정된 자유 끝부분만 움직인다. 모자 끝·앞머리·망토 끝은 서로 다른 위상을 사용하며 얼굴·몸·손·발·받은 물약의 접점은 고정한다. 눈 깜빡임은 기존 마스크로 합성한다.

두 방법을 구분했다. 원본 격자 모드는 기존 색으로 작은 주름과 내부 윤곽을 옮기고 끝점을 드물게 바꾼다. 표시 1/3픽셀 모드는 3배 그림의 움직일 영역을 화면1픽셀씩 옮기는 렌더 실험이다. 같은 크기·같은 팔레트를 사용하지만 후자의 움직이는 부분은 원본3×3 정렬에서 벗어난다. 흐림·반투명·색 추가는 없다.

색 변화로 미세 움직임을 표현하는 기법은 [Kiwi의 서브픽셀 애니메이션 설명](https://2dwillneverdie.com/tutorial/give-your-sprites-depth-with-sub-pixel-animation/)을 참고했다. 원본 격자의 색 변화와 소수 좌표 이동을 같은 방법이라고 부르지 않는다. Godot의 좌표 스냅에 대한 설명은 [공식2D 문서](https://docs.godotengine.org/en/stable/tutorials/2d/introduction_to_2d.html)에서 확인했다. 이 후보는 실제 엔진 설정을 변경하지 않는다.

## 진열·솥·접지

병36종은 기존 몸통 실루엣과 실제 ID를 유지하며 공통 코르크·유리·외곽선으로 정돈했다. 진열은8종·4병씩2줄이다. 선반 보드 y=22/43, 병 중심 x=8/18/28/38이며 긴16행 병도 윗칸에 닿지 않는다. 병 밑면은 해당 보드 바로 위에 맞춘다.

솥 액체는 제조 레시피 ID에 따라 바뀐다.36종 모두 액체의 정확한63픽셀 마스크를 사용하며 솥 몸체·달 문양·돌 화덕·불꽃을 재칠하지 않는다. 액체색은 병과 같은 재질 램프에서 고른다. 검토용 선택기는 게임의 제조 동작을 수동으로 바꾸는 제품 UI가 아니다.

발판은 하나의 낮은 목재 판이다. 솥·남자 주인·손님·진열대·약초대의 바닥 접점이 원본 y=78, 공통 발판 상단이 y=79이다. 약초대는 접지를 맞추기 위해 아래로 옮겼으며 재배 텍스트는 창문 밑으로 이동했다. 이미지 영역은 원본180×83의 정확한3배인540×249, 전체 화면은540×300이다.

## 재현·검사

```powershell
python tools/build_secondary_motion_frames.py
python tools/build_potion_shelf_mockup.py
python tools/build_refined_workshop_mockup.py
```

- 움직임128장: 캐릭터별 최대5색, 팔레트 밖0, 반투명0, 지정 영역 밖 변화0.
- 병36 + 선반1 + 솥108: 개별 최대5색. 솥의 액체 영역 밖 변화0.
- 전체 아트는 두 모드 각각144프레임을 검사한다. 정상 글자 안티앨리어싱은 별도로 렌더한다.
- 18초 루프는 캐릭터2초 / 날씨1.5초 / 불꽃0.5초 / 솥0.5초 / 깜빡임4.5초의 주기를 맞춘다.

검사 파일은 `validation.json`, `motion/frames.json`, `potions/recipes.json`이다. 팔레트 승인은 유지되지만 새 후보 디자인의 승인을 의미하지 않는다. 실제 런타임 에셋과 저장에는 연결하지 않았다.
