# 전체 움직임 목업 v6

2026-10-13 사용자가 “목업 좋고”라고 답해 후속 아트 제작 기준으로 승인했다. 최신 승인 범위는 `approval.json`에 기록했다. 이후 제작 순서는 캐릭터별·물약별 팔레트 → 캐릭터 키프레임 → 행동별 애니메이션이며, 첫 팔레트 확인표는 `art/palettes/v1/`에 있다. 아래 제작 당시 후보 설명과 검사 파일의 상태보다 최신 승인 기록을 우선한다.

최신 사용자 피드백을 반영해 오른쪽을 보는 남캐의 눈 방향, 엘프의 짝눈처럼 보이던 앞머리 접합, 넓은 치마 실루엣을 수정했다. v5 엘프 머리 크기, 공통 발판, 물약 진열과 제조 레시피별 솥 액체색36종은 유지한다.

## 눈과 비율

남캐는 오른쪽을 보는 얼굴에 x15/x18,y20/21의 같은 높이 눈2개를 배치했다. 엘프는 x10/x15,y21/22의 같은 높이 눈2개이다. 각각1×2픽셀이며 검은색 연결 성분은2픽셀, 위·아래·대각선의 피부 여백은1픽셀로 머리카락과 분리한다. 귀나 외곽선을 눈으로 선택하지 않으며 시선을 맞춘다고 눈 하나를 없애지 않는다.

엘프 하의는 y34..36에서10픽셀, y37..39에서12픽셀 폭으로 줄였다. 손·팔과 y40 이후 다리·발 RGB는 원본과 같다. 목 옆의 기존 투명 틈2픽셀만 외곽선 색으로 연결했다. 다리 사이의 원래 빈 공간은 유지한다. 원본32×48 격자, 발 마지막 행46, 장면 접지78은 유지한다. 남캐 의상과 엘프22×16 머리 크기는 바꾸지 않았다.

## IDLE 합성

16개 안쪽 포즈에 기본/호흡 올림, 열린 눈/깜빡임을 합쳐64프레임 은행을 만든다. 포즈는8fps·2초, 호흡은3초, 깜빡임은4.5초이다. 같은18초 안에 모든 주기가 맞는다.

손과 발은 고정하고 머리·목·상체 위쪽이 원본1픽셀 올라갔다 내려온다. 모자·망토·머리 안쪽 움직임은 호흡과 동시에 계속된다. 경계는 호흡과 함께 이동하므로 v5처럼 절대 좌표까지 고정됐다고 주장하지 않는다. 각 프레임의 원본/표시 경계색 위반0, 팔레트 밖0, 반투명0, 개별 최대5색을 검사한다. 원본에 있는 알파 구멍과 새 구멍 발생 여부를 구분한다.

## 약초대·포션

약초 화분의 긴 측면(y19..22), 밑선(y24), 나무 상판·다리는1픽셀 선이다. 두꺼운 부분은 잎 접합과 화분 손잡이/곡선 코너(y14..18), 손잡이와 윗테두리 접합(y15)에 한정되어 기존 그림을 유지했다. 단순히 모든 어두운 덩어리를 지우지 않았다.

물약 디자인은 사용자의 긍정 피드백대로 그대로 유지했다. 제조 물약 선택에 따라 솥의 정확한 액체63픽셀만 재칠하며, 몸체·달 문양·화덕·불꽃은 바꾸지 않는다. 일반 텍스트는 별도 DOM/폰트로 렌더한다.

## 재현·검사

```powershell
python tools/prepare_character_v6.py
python tools/build_combined_idle_v6.py
python tools/build_combined_workshop_v6.py
```

`characters/validation.json`, `motion/frames.json`, `validation.json`에 근거를 둔다. 생성된 새 인물로 바꾸지 않고, v5 원본에 명시적 픽셀 마스크와 하의 실루엣 편집을 적용했다. 기존 이미지 생성 출처·프롬프트는 [v5 기록](../full-ingame-v5/generation.json)에 있다. 아직 실제 게임 런타임 에셋을 교체하지 않은 검토용 목업이다.
