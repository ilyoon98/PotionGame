# 전체 작업실 목업 v5

엘프 머리를 너무 작게 줄인 문제와 캐릭터 외곽선이 끊겨 보이던 문제를 수정한 후보다. 기존 남자 주인 설정, 공통 목재 발판, 정돈한8병 진열, 제조 물약별 솥 액체색36종을 유지한다.

## 보기

- `animated-preview.html`: 최신 움직이는 전체 화면. 기본은 원본 격자 움직임이며 제조 물약·날씨·움직임 모드를 비교한다.
- `animated-preview.gif`: 기본 원본 격자 모드,144프레임·18초 반복.
- `animated-fine.gif`: 안쪽1/3픽셀 움직임 비교. 바깥 윤곽은 같은 상태로 고정한다.
- `still.png` / `still-2x.png`: 전체 정지 확인.
- `characters/anatomy-guide.png`: 남캐·이전 엘프·수정 엘프의 같은 배율 전신 비교.
- `characters/validation.json`, `motion/frames.json`, `validation.json`: 외곽선·비율·움직임·전체 합성 검사.

## 바뀐 기준

32×48 원본에서 모자는 머리 위의 추가 공간이다. 머리 기준 영역은 y=11..26(16행), 몸통27..39(13행), 다리·신발40..46(7행)으로 잡으며 원본 발 마지막 행46과 장면 접점78을 유지한다. 이 영역은 설계 기준이며 같은 모양의 얼굴이나 같은 실루엣을 강제한다는 뜻이 아니다.

엘프 머리는22×16 프레임으로 만들었다. 원래 너무 컸던29×26 머리와 너무 작아진18×13 머리의 중간이다. 귀를 제외한 연결 피부 영역은 남캐9×7 / 엘프10×8로 확인했다. 엘프 몸체의 알파 형상은 유지하며 외곽선 색만 정돈했다. 남캐의 셔츠·반바지·드러난 무릎·부츠·앞이 열린 보라 망토를 유지한다.

모든 캐릭터의 상하좌우 투명 픽셀과 맞닿는 불투명 경계를 원본1픽셀 외곽선으로 정리했다. 두 움직임 모드 모두 바깥 실루엣과 외곽선 및 바로 안쪽 색을 고정한다. 안쪽 망토 주름·모자 주름·머리 선만 바꾸고, 눈 깜빡임은 귀와 구분된 명시적 눈 마스크를 쓴다. 따라서 테두리를 밝게 했다가 지우는 방식의 움직임은 사용하지 않는다.

기법상의 구분은 [Kiwi의 색 변화 기반 서브픽셀 설명](https://2dwillneverdie.com/tutorial/give-your-sprites-depth-with-sub-pixel-animation/)을 참고했다. 비교 모드의 안쪽1/3픽셀 이동은 표시 격자를 세분화한 렌더 실험이며 색 변화 기반 기법과 구분한다. 흐림·새 색·반투명은 추가하지 않는다.

## 재현·검사

```powershell
python tools/prepare_character_outline_v5.py
python tools/build_secondary_motion_v5.py
python tools/build_outline_workshop_v5.py
```

입력 생성 이미지와 프롬프트는 `characters/source/`와 `generation.json`에 보관한다. 기존v4 물약36종과 선반 후보를 재사용한다.

캐릭터128프레임은 경계 위반0·바깥 실루엣 변화0·외곽선 변화0·팔레트 밖0·반투명0을 검사한다. 개별 최대5색이다. 전체 화면은 두 모드 각각144프레임의 아트를 검사한다. 일반 DOM/폰트 글자의 안티앨리어싱은 스프라이트 검사에서 제외한다.

이 후보는 전체 움직임과 비율을 검토하는 목업이며 실제 게임의 저장과 런타임 에셋을 교체한 상태는 아니다.
