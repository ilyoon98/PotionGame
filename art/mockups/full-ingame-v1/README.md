# 전체 인게임 작업실 목업 v1

2026-10-13, 여러 물약을 반영한 전체 인게임 화면을 만들어 달라는 요청으로 제작한 **후보 목업**이다. 이전에 승인한 24색과 솥·마녀의 아트 기준을 사용했다. 이번 전체 배치, 새 가구·손님·물약 변환은 아직 사용자 디자인 승인을 받지 않았다.

## 확인할 그림

- `full-ingame.png`: 현재 본 작업실과 같은 **540×300** 크기의 완성 목업.
- `full-ingame-2x.png`: 위 그림을 최근접 보간으로 2배 확대한 검토용 이미지.
- `full-ingame-transparent.png`: 사물 사이가 투명한 실제 작업실 방향의 목업. 회보라색 배경은 미리보기용 바탕색이며 게임의 벽·바닥으로 제안한 것이 아니다.
- `potions-36-review.png`: 일반 32종과 특별 4종 전체의 팔레트·실루엣 확인표. 이 표는 게임 안에 새로 추가한 UI가 아니다.
- `workshop-art-native.png` / `workshop-art-3x.png`: UI 글자를 얹기 전 그림 레이어의 원본과 공통 3배 확대본.

## 기획과 코드에서 반영한 것

- `scripts/workshop_layout.gd`: 현재 540×300 본 작업실과 248px 그림 영역, 52px 하단 조작부. 관리·최소화·확대·닫기 버튼의 화면 좌표와 크기는 기존값을 사용했다. 새로운 아트의 배치 좌표는 기존 사물 좌표와 다르므로 그대로 코드에 연결했다고 주장하지 않는다.
- `scripts/potion_display.gd`: 눈에 보이는 진열은 **8병**, 처음의 보관 한도는 **12병**이다. 전체 36종을 선반에 동시에 올려놓지 않았다.
- `data/content_expansion.json`: 체력·마나·달빛·정화·민첩을 포함한 일반 물약 32종.
- `scripts/rare_recipes.gd`: 숲숨결·물안개·월광봉인·성운 증류액의 특별 물약 4종.
- `scripts/item_art.gd`: 체력·마나와 기존 특수 물약 3종은 실제 런타임 경로를 따로 분기한다. 비슷한 이름의 확장 카탈로그 파일로 임의 대체하지 않았다.
- `scripts/shop_content.gd`: 엘프는 정화를 선호하며, 달빛은 현재 제조 항목의 예시로 사용했다. 솥의 노출된 액체도 달빛 색으로 맞췄다.
- 작업실 대표 표시: 기본 약초 그림 1개 + `N종 재배 중`, 제조 1개, 원정 포스터 1개 + `N곳 탐사 중`으로 표현한다.

진열한 8종은 체력·마나·달빛·정화·민첩·활력·야행·숲숨결이다. 엘프가 든 정화 물약은 **이미 판매된 다른 병**이며, 선반의 정화 병과 같은 재고 인스턴스를 두 번 그린 것이 아니다. 새 가구, 기준 마녀, 솥, 손님, 창틀과 날씨, 재배/제조/원정 상태, 재고·선호 판매 표시, 골드·시간·날씨·조작 버튼을 한 화면에 배치했다.

골드 1,284, 재고 8/12, 9종 재배, 2곳 탐사, +24G 판매는 설명용 목업 상태이다. 플레이어 저장이나 실행 중인 상태에서 읽은 실제 값이 아니다. `scene.json`에 이 구분과 진열 ID, 제조 ID, 판매된 ID, 좌표를 기록했다.

## 픽셀과 색 처리

- 마녀·엘프 32×48, 솥·창틀·약초 받침 32×32, 선반 48×48, 판매대 48×16, 포스터 24×32. 각 물체는 같은 원본 1픽셀 단위와 공통 3배 확대를 사용한다.
- 진열 물약은 기본 8×12. 기존 실루엣이 가늘고 긴 병은 8×16으로 둔다. 이 병은 12×16 원본의 투명 좌우 여백만 잘라 내부 픽셀을 보존한다. 가로로 늘리거나 가장자리를 두 번 덧칠해 액체를 한 줄로 줄이지 않았다.
- 물약의 기존 짙은 외곽선과 밝은 유리 가장자리를 보존해 재질 램프로 색을 맞췄다. 병의 투명도는 0/255로 정리했다.
- 선반 프레임과 병 각각을 별도 에셋으로 검사했다. 여러 종류의 물약이 함께 있는 선반 전체는 5색보다 많을 수 있다.
- 물체별 최대 5색, 팔레트 밖 색 0개, 반투명 픽셀 0개를 확인했다. UI 글자는 프로젝트의 Pretendard를 화면 크기에 맞춰 사용하고, 글자 픽셀도 승인된 팔레트 색으로 제한했다. UI 글자는 게임 사물의 3배 픽셀 격자와 구분된다.
- 그림 레이어는 180×83 → 540×249의 정확한 3배 확대다. 기존 248px 그림 영역에 맞춰 맨 아래 투명 1줄만 제외했다. 사물을 비정수 배율로 늘리지 않았다.
- 새 색 추가와 물체별 색 상한 예외: 없음.

## 재현과 근거

Pillow와 NumPy가 설치된 Python으로 프로젝트 루트에서 실행한다.

```powershell
python tools/build_full_ingame_mockup.py
```

현재 PC에서 실행 확인된 명령:

```powershell
& 'C:\Users\imtl\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools/build_full_ingame_mockup.py
```

`build_full_ingame_mockup.py`는 코드에 등록된 ID와 실제 병 경로를 읽어 `manifest.json`을 작성하고 기존 `process_pixel_art.py`를 호출한다. 고정 순서는 **배경 정리 → 원본 격자 정리 → 명시적인 재질별 램프 변환 → 검사**이다. 액체는 물약 ID별로 지정한 램프를 사용하고, 코르크·유리·외곽선은 별도의 재질로 유지한다. 전체 팔레트의 가장 가까운 RGB로 치환하지 않는다.

`source/`는 내장 imagegen으로 생성한 가구 5종과 엘프 1종의 원본이다. 원본 생성에는 승인된 목업과 기존 엘프를 참고했다. 전체 프롬프트는 `generation-prompts.json`에 있다. 물약은 기존 게임용 그림을 후처리한 것이며 새로 36장을 생성했다고 주장하지 않는다.

`potion-identities.json`에는 36종의 기획 데이터·실제 원본 경로·이번 목업의 원본 규격을 기록했다. `validation.json`은 후처리한 43개 에셋의 색 수와 픽셀·원본 해시를 기록한다. 기존 승인 마녀는 별도로 검사해 재사용했다. `scene.json`은 전체 화면의 팔레트 검사와 정수 확대 검사를 포함한다.

중간 `stages/`와 생성 `source/`는 정식 팔레트 출력이 아니다. 최신 검사나 전체 화면 생성이 실패하면 이전 PNG가 남아 있어도 새 결과로 쓰지 않는다.

이 작업은 정지 디자인 목업이며 Godot의 실제 게임 화면 캡처나 실행 검증이 아니다. 런타임 에셋·게임 코드·경제·저장·Windows 등록과 실행 중인 게임은 변경하지 않았다.
