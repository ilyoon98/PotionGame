# 움직임 목업 v2

2026-10-13 사용자 피드백을 반영한 후보이다. **마녀 아래 노란 발판/러그를 제거**하고 창밖 날씨·솥 액체·불꽃·마녀/엘프 IDLE에 작은 움직임을 추가했다. 이전 전체 작업실과 같은 540×300 크기, 동일한 8종 진열과 24색 아트 팔레트를 사용한다.

## 보기

- `animated-preview.html`: 일반 DOM 텍스트와 픽셀 아트를 분리한 움직이는 미리보기. 밤/낮·비/맑음을 선택하고 재생/멈춤을 비교할 수 있다. UI는 목업 상태이며 게임 저장과 연결되지 않는다.
- `animated-preview.gif`: 밤·비 기본 화면의 9초 반복 영상. 일반 Pretendard 글씨를 함께 렌더한 공유용 미리보기이다.
- `still.png` / `still-2x.png`: 일반 텍스트와 발판 제거를 확인할 정지 이미지. 확대본은 도트 확인용이며 실제 UI 글자를 확대해 쓰겠다는 규격이 아니다.
- `browser-preview.png` / `browser-validation.json`: 실제 브라우저 화면과 날씨 전환·멈춤·재생 확인 기록.
- `static-art.png`: 글자·러그·날씨·캐릭터·솥이 없는 정적 그림 레이어.
- `frames/`: 마녀·엘프·솥의 원본 픽셀 애니메이션. 날씨와 불꽃은 `effects/`에 있다.

## 움직임

| 요소 | 움직임 | 고정하는 것 |
| --- | --- | --- |
| 창밖 | 4종 날씨, 각각 12프레임·8fps. 달/해와 작은 구름, 비 | 창틀과 내부 마스크. 창문 밖 표시 0픽셀 |
| 마녀·엘프 | 4프레임. 3초 호흡, 4.5초마다 짧은 깜빡임. 서로 다른 위상 | 손과 발. 상체 전체를 흔들지 않고 머리·목만 1픽셀 |
| 솥 | 3프레임·6fps. 노출된 달빛 액체에 작은 기포/잔물결 | 몸체·손잡이·돌 화덕과 접점 |
| 불꽃 | 4프레임·8fps. 높이와 중심의 작은 변화 | 바닥. 화덕 중앙 틈으로만 보임 |

솥 하단의 돌 화덕은 유지하고 중앙 개구부만 정리했다. 불꽃을 솥 이미지 위에 덧칠하지 않고 뒤에 두어 돌과 몸체가 앞에서 가리도록 한다. 엘프가 받은 물약은 별도 소품 레이어이며 손 위치는 변하지 않는다.

## 글씨 규칙 변경

사용자가 글씨는 픽셀로 하지 말고 자체 텍스트를 넣을 것이라고 명시했다. 미리보기는 프로젝트 Pretendard의 일반 DOM 텍스트를 사용하고, 실제 Godot 연결 시에는 Label로 옮길 수 있도록 이미지에서 분리했다. 글자에 알파 임계값·픽셀화·팔레트 강제 변환을 적용하지 않는다.

스프라이트와 효과만 최대 5색/팔레트 밖 0색/반투명 0픽셀로 검사한다. 일반 텍스트의 안티앨리어싱 색은 검사 대상에서 제외한다. GIF 저장에서 승인된 24색은 그대로 보존하고, 남는 인덱스는 글자 가장자리의 부드러운 색을 담는 데 사용한다.

## 재현

프로젝트 루트에서 Pillow와 NumPy가 있는 Python으로 실행한다.

```powershell
python tools/build_weather_fire_frames.py
python tools/build_animated_ingame_mockup.py
```

현재 PC의 번들 Python은 `C:/Users/imtl/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`이다. HTML은 자체 이미지 데이터를 포함하며 Pretendard는 프로젝트 내부의 상대 경로로 읽는다. 폰트를 읽지 못해도 일반 시스템 글씨로 표시한다.

기존 승인 그림과 v1 에셋을 유지하고 별도 v2 프레임을 만들었다. 새 이미지 생성 호출로 인물의 외형을 다시 뽑지 않았으며, 움직임은 명시적인 원본 픽셀 프레임과 레이어 합성으로 작성했다.

## 검사와 범위

- `validation.json`에 원본 프레임 검사와 날씨·불꽃 검사, 72개 합성 아트 프레임의 검사 근거가 있다.
- 마녀 `y≥30`, 엘프 `y≥27`은 모든 IDLE 프레임에서 동일하다. 눈 마스크는 기존 얼굴의 실제 눈 위치와 일치하는지 확인했다.
- 불꽃 4프레임은 실제 화덕 뒤에 합성해도 서로 다르게 보이며, 숨겨진 프레임만 교체하는 애니메이션이 아니다.
- GIF는 72프레임, 총 9,000ms이며 반복 재생한다.
- 웹 미리보기의 일반 텍스트·날씨 선택·멈춤/재생을 확인한다. 운영체제의 동작 감소 설정에서는 초기 재생을 멈추고 사용자가 재생할 수 있다.

아직 정지/움직임 디자인 후보이며 실제 게임에 새 에셋을 연결한 구현이 아니다. 런타임 에셋·경제·저장·Windows 등록·실행 중인 게임을 변경하지 않았다.
