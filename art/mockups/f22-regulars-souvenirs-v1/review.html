기념품 4종

관리 패널 크기 미리보기

관리 패널의 작은 아이콘 칸(24px)과 주 아이콘 칸(32px = 원본 1배)에 놓은 모습입니다. 24px은 원본 32px의 0.75배 축소라 픽셀이 고르지 않게 보일 수 있습니다. 실제 적용 칸 크기는 승인 후 정합니다.

같은 크기로 나란히 · 32px / 3배 96px

검사 결과

재현: python tools/build_f22_souvenirs_v1.py → 원본 지도(source/*.txt) → 등록 PNG → tools/process_pixel_art.py(manifest.json) → 추가 검사(validation.json) → 이 페이지. 수치 검사는 디자인 승인을 대신하지 않습니다.

정해 주실 것

1. 네 기념품의 모양과 색을 이대로 쓸지, 고칠 곳(예: 책갈피 끈, 은방울 리본 색).
2. 관리 패널 기념품 칸에 쓸 표시 크기(32px 원본 1배 권장, 24px 칸이면 축소 표시).
