# 솥·마녀·선반 픽셀 기준 목업 v1

2026-10-13의 사용자 요청으로 만들고, 완성 목업에 대한 사용자 답변 “좋아”로 **승인된 아트 기준**이 되었다. 이후 에셋은 이 24색 팔레트와 픽셀 규격, 재질별 단순화를 따른다. 승인 기록은 `art/palette-log.md`에 있다.

## 보기

- `review-board.png`: 원본 규격과 공통 배율을 표시한 검토 보드.
- `mockup-3x.png`: 같은 격자로 배치한 576×216 목업. 보라 회색 배경은 검토용이며 팔레트 안의 색이다.
- `mockup-native.png`: 투명 배경 192×72 합성 원본.
- `mockup-transparent-3x.png`: 투명 배경의 3배 확대 합성본.
- `cauldron-native.png`: 32×32, 5색. 솥을 낮은 돌 화덕에 붙여 받치고 불꽃은 가운데에 배치했다.
- `witch-native.png`: 32×48, 5색. 큰 모자와 짧은 몸, 단순한 얼굴을 사용했다.
- `shelf-native.png`: 64×64, 5색. 위아래 4병씩 총 8병을 배치했다. 목업 병은 장식이며 실제 재고를 표시하지 않는다.
- 각 물체의 `*-3x.png`: 원본 픽셀을 정확히 3×3 블록으로 확대한 투명 PNG.

## 재현

프로젝트 루트에서 Pillow와 NumPy가 설치된 Python으로 실행한다.

```powershell
python tools/process_pixel_art.py art/mockups/cozy-witch-v1/manifest.json
```

현재 PC의 실행 확인된 번들 Python:

```powershell
& 'C:\Users\imtl\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools/process_pixel_art.py
```

처리 순서는 알파 배경 정리 → 원본 격자 정리 → 재질별 램프 변환 → 수치 검사이다. 알파 224 미만을 투명하게 정리한 뒤, 각 격자 셀에서 가장 많이 나타나는 색 묶음의 실제 원본 픽셀을 선택한다. 서로 다른 재질을 전체 팔레트의 가장 가까운 색으로 치환하지 않는다.

재질은 `manifest.json`의 물체별 색상 범위·영역 규칙으로 배정한다. 보라색 옷, 피부, 나무, 물약을 먼저 분리하고, 각 재질에 허용된 색만 사용한다. 여러 명암을 쓰는 재질은 원본의 밝기 순서를 유지해 정해진 램프의 일부로 옮긴다. 분류가 잘못되면 `material_rectangles`로 원본 격자상의 영역을 지정해 수정할 수 있다. 재질 분류는 모든 AI 그림에 자동으로 맞는 범용 판별기가 아니므로 새 그림마다 마스크와 결과를 시각적으로 확인한다.

`stages/`의 `*-clean.png`, `*-grid.png`는 중간 결과이며 게임용 출력이 아니다. `*-materials.png`는 각 픽셀의 재질 ID를 나타내는 회색조 디버그 마스크이고, ID 의미는 `validation.json`에 있다. 이 파일들은 최종 팔레트 그림으로 취급하지 않는다.

검사 실패 시 `validation.json`에 실패를 기록하고 해당 실행의 정식 결과는 게시하지 않는다. 이전 정상 출력이 남아 있어도 최신 검사 보고서가 실패면 새 결과로 사용하지 않는다.

## 생성 근거와 검토

- 내장 imagegen으로 물체별 1장을 생성하고 `source/`에 보존했다. 전체 프롬프트·참고 그림 경로는 `generation-prompts.json`에 있다.
- 참고 그림은 기존 솥·주인 마녀·작업실 선반이며 새 목업의 승인된 기준 이미지로 간주하지 않았다.
- 각 최종 물체는 5색, 팔레트 밖 색 0개, 반투명 픽셀 0개이다. 원본 규격과 정수 3배 확대를 검사했다.
- 에이전트의 시각 검토에서는 돌 받침의 접점, 보라색 옷/피부/나무의 재질 분리, 두 줄 8병, 공통 픽셀 단위와 발/다리의 접점을 확인했다. 이 검토는 사용자 디자인 승인을 대신하지 않는다.
- 이번 범위는 정지 목업이다. 캐릭터 애니메이션, 실제 물약 종류별 색, 기존 게임 전체의 규격 변환은 포함하지 않는다.
- 기존 런타임 에셋·스크립트·저장·Windows 등록은 변경하지 않았다.
