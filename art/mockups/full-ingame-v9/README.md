# 전체 인게임 마법 전달 목업 v9

최신 사용자 피드백: 두 캐릭터 손을 반드시 맞출 필요가 없고, 기존 날아가는 물약과 전시대 역할을 살린다. 직접 손 전달 v8을 대체하는 검토 후보다. 실제 게임은 아직 수정하지 않았다.

- 15초 방문: 입장 → 제조 → 4초 선반 입고 → 4.65초 진열(7→8병) → 7초 주문 병 출고(8→7병) → 7.45초 판매대 → 7.9초 마법 비행 → 8.45초 손님 받기 → 품에 모으기 → 병 든 퇴장.
- 선반은 실제 재고 진열, 판매대는 주문한 한 병을 준비하는 자리다. 같은 선택 병은 이동/진열/판매대/손 중 한 장소에만 존재한다. 주인공의 전달 포즈는 멀리서 마법을 보내는 몸짓이며 병을 직접 들지 않는다.
- 주인공72,32/손님148,32/판매대105,64로 원래 간격을 복원했다. 손은 마지막 받기와 들고 걷기에만 맞춘다.
- 네 손님을 선택하거나 순서대로 자동 재생할 수 있다. 물약36종을 선택하면 솥과 병의 내용물 배정이 함께 바뀐다. 선반 진열/판매대/받기/퇴장 버튼과 탐색 막대로 확인한다.
- 기존 캐릭터 전신32×48/공통3배, 개별5색과64상태 움직임 뱅크를 재사용한다. 기존 호흡/깜빡임/모자/망토/머리카락/귀/꼬리를 보존했다. 표시1픽셀과 원본격자1픽셀 모드를 비교할 수 있다. 확대 검수창만6배다. 글자는 일반 DOM 텍스트다.

## 출처와 확인

기존 구현 `scripts/potion_display.gd`의 `_brew_position`/`handover_position` 및 `scripts/shop_art.gd`의 재고/전달/들고 있는 병 렌더링을 확인했다. 목업의 판매대 경유와 시간은 검토용 연출이며 런타임과 완전히 동일한 코드는 아니다.

캐릭터: `../../characters/keyframes-v4/keeper`, `../../characters/actions-v1/{traveler,mage,elf,rogue}`. 배경과36종 물약은 v7 기준, 창밖/불꽃은 v8에 디코딩해 보존한 동일 환경 픽셀을 참조한다. 새 인물 그림을 생성하거나 원본 얼굴·팔다리를 조립하지 않았다. `palms/`는 원본 손의 피부와 인접 외곽선을 병 앞에 재표시하는 투명 마스크다.

`contact-validation.json`: 4손님×36물약의 받기·모으기·병 든 걷기 접점1440건. 같은 병 내부 잡는 점을 퇴장까지 유지한다.
`flight-validation.json`: 날아오는 병이 실제 움직이는 손님 머리를 가리는지 검사.
`validation.json`: 전체 합성 팔레트/알파/공통배율과 기존 원본 SHA-256 대조.
`verification.json`: 진열/출고/판매대/잡기 전환, 중복 병 없음, 잡기 순간 위치 연속, 퇴장까지 유지, Python과 브라우저 JS 시간 상태 대조.
`browser-validation.json`: 실제 브라우저 제어와 검수 캡처.

제작 `tools/build_flying_workshop_v9.py`, 페이지 `tools/flying_workshop_v9.template.html`, 검증 `tools/verify_flying_workshop_v9.py`.

다음은 전체 화면 연출 검토 후 Godot의 기존 재고/판매 이벤트에 새32×48아트와 행동을 연결하는 단계다. 실제 재고·경제·저장·자동실행은 변경하지 않았다.
