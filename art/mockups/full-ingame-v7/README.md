# 움직이는 전체 목업 v7 · 얼굴과 앞머리 수정

주인공의 비어 보이던 오른쪽 위 헤어라인과 네모로 보이던 엘프 얼굴을 다듬은 후보 목업이다. 근거·생성 프롬프트·수정 전후와 검사 기록은 `art/characters/face-refinement-v1/`에 있다. 다른 캐릭터의 키프레임 얼굴 수정도 그 기록을 따른다.

주인공·엘프는 원본32×48, 공통3배, 최대5색이다. 두 눈1×2와 피부 여백1픽셀을 검사한다. 기존 발46행·머리22×16 기준·몸통13행·다리7행, 공유 발판, 물약36종·선반8병, 날씨·솥·불꽃을 이어받는다. 호흡과 모자·망토·머리 움직임을 함께 유지한다.256IDLE프레임의 외곽선·눈·헤어라인 검사를 통과했다.

`animated-preview.html`에서 실제 움직임을 확인한다. 새 얼굴과 전체 v7 화면은 검토 후보이며 v6의 기존 승인으로 자동 승인하지 않는다. 실제 게임 적용은 별도 단계다. 재현: `python tools/build_round_face_workshop_v7.py`.
