# 손님02 · 여마법사 키프레임 v1

긴 보라색 머리, 큰 모자, 긴 로브, 갈색 허리띠·책·부츠를 유지한 여성 마법사 손님의8개 키프레임 후보다. 여행자의 여성 인상이 약하다는 피드백은 `../production-status.json`에 보류로 기록하고 여행자 그림은 바꾸지 않았다.

원본은32×48, 표시 배율은 공통 최근접3배다. 모자를 제외한 머리 기준은22×16 영역(11~26행), 몸통27~39행(13행), 다리·부츠40~46행(7행), 발 접지는46행,47행은 투명하다. 긴 로브가40~43행의 다리를 덮는 의상이다. 모자와 어깨 아래로 흐르는 머리는 머리 크기에서 제외한다. `anatomy-comparison.png`에서 승인한 주인공·엘프 및 모자 없는 몸을 같은 배율로 비교할 수 있다.

캐릭터5색: 테두리·눈 #241C32 / 피부 #F6D1AC / 머리·의상 어두운 면 #50315F / 보라색 밝은 면 #86548E / 모자 띠·허리띠·책·부츠 #916047. 팔레트 밖0색, 반투명0픽셀, 외곽선 경계 위반0이다.

`review.html`에서 대기, 걷기 접지A/통과A/접지B/통과B, 받기 손 내밀기/모으기, 깜빡임을 확인한다. `frames/`에는 완성 합성32×48 PNG, `body-frames/`에는 모자 없는32×48 전신, `layers/hat.png`에는 별도32×14 모자가 있다. `mage-keyframes-native.png`는128×96 시트이며 `mage-keyframes-3x.png`는384×288 확대다.

전신 생성 결과에 공통 배율과 머리·발 기준을 적용한다. 몸통·다리 조각을 다른 포즈에서 가져오지 않는다. 생성 원본과 모든 프롬프트는 `generation.json` 및 `source/`에 보관한다. 전체 모자를 포함한 첫 두 원본은 비율 문제로 사용하지 않았다. 최종 선택은 `source/body-v3.png`와 `source/hat-v1.png`다.

사용자 피드백 “모자가 아예 공중에 떠있는데..?”에 따라 모자 합성 위치를[0,0]에서[0,4]로 수정했다. 모자 안쪽 착용점[14,10]을 정수리 착용점[14,14]에 맞춘다. 챙이 정수리를 충분히 덮는지8포즈 모두 검사하며, 단순히 몇 픽셀이 연결돼 있다는 이유만으로 착용 위치를 통과시키지 않는다. `hat-fit-review.png`에서 같은3배의 수정 전/후를 비교할 수 있다. 전신 격자와 눈·발 기준은 유지한다.

고정 후처리는 배경 정리 → 원본 격자 정리 → 재질 램프 배정 → 검사 순서다. 생성 눈의 모양이 격자 축소에서 불균일해지는 문제는 `manifest.json`의 명시적 피부/눈 재질 마스크로 정리했다. 열린 눈은 x10/x14,y22/23의1×2픽셀2개이며 피부 여백1픽셀을 대각선까지 검사한다. 깜빡임은 동일 대기 전신의 눈4픽셀만 바꾼다.

물약은 별도 병으로 합성한다. 손 앵커는 내밀기[5,29], 모으기[12,32]이며 실제 피부 픽셀에 닿는다. 병 로컬 접점은[width/2,6]으로 상부 몸체를 잡는다.36종의 짧은 병·긴 병과2포즈, 총72조합을 검사했다. 병이 프레임을 벗어나거나 눈의 피부 여백을 가리지 않는다. 병 색은 캐릭터5색 예산에 합치지 않는다.

재현: `python tools/build_mage_keyframes_v1.py`. 수치 검사 기록은 `validation.json`, 병 접점은 `hand-anchors.json`, 처리 중간 결과는 `pipeline/stages/`에 있다. 키프레임 디자인은 검토 후보이며 완성 행동 애니메이션·Godot 런타임 적용은 다음 단계다.
