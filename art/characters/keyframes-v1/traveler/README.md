# 손님 01 · 여행자 키프레임 v1

2026-10-13 사용자가 승인한 캐릭터 팔레트와 부위별 크기를 지켜 손님을 한 명씩 제작하도록 요청했다. 첫 대상은 현재 게임의 **여행자**이다. 기존 갈색 머리·밝은 셔츠·갈색 반바지·짧은 부츠·배낭과 침낭을 유지한다.

## 결과

- `review.html`: 8포즈, 부위 기준선, 승인한 주인공·엘프와 같은3배 비교. 받기 포즈에서 별도 병 접점을 확인한다.
- `keyframes-review.png`: 8포즈 전체 확인표.
- `anatomy-comparison.png`: 주인공·엘프·여행자의 공통 격자/비율 비교.
- `frames/*.png`: 각32×48 투명 원본.
- `traveler-keyframes-native.png`: 128×96 원본 시트,4열×2행.
- `traveler-keyframes-3x.png`: 동일 시트의 최근접3배 확대.
- `keyframes.json`: 프레임 순서·사각형·역할·손 앵커.
- `validation.json`: 색, 크기, 외곽선, 눈, 부위 범위, 접지, A/B 포즈 차이와 깜빡임 검사.
- `hand-anchors.json`: 받기2포즈×36종 병의72개 접점 검사.

포즈 순서는 대기 → 걷기 접지A → 통과A → 접지B → 통과B → 받기 손 내밀기 → 받기 손 모으기 → 대기 깜빡임이다. 현재는 **검토용 키프레임**이다. 아직 중간 프레임·행동 속도·상하 호흡과 부분 움직임을 합친 완성 행동 애니메이션이나 Godot 적용 결과가 아니다.

## 크기·팔레트

원본32×48, 모자를 제외한 머리 기준11~26행(16행), 몸통/옷27~39행(13행), 다리·신발40~46행(7행), 마지막 발 행46이다. 머리는22×16 기준 영역 안에 들어간다. 배낭/침낭처럼 머리 옆에 붙는 부착물은 머리 크기에 합산하지 않는다. 걷기의 들어 올린 무릎은 동작에 따라 몸통 기준 구간으로 올라올 수 있다. 서 있는 포즈는 기준 구간에서 다리 피부가 시작하지 않도록 검사한다.

5색: 테두리·눈 `#241C32`, 피부 `#F6D1AC`, 셔츠·침낭 `#FFF0BC`, 머리·가죽 `#916047`, 반바지·배낭 밝은 면 `#C99463`. `art/palettes/v1/characters/traveler.hex`와 같다. 팔레트 밖0색, 반투명0픽셀, 외곽선 경계 위반0이다.

열린 눈은 x10/x14,y22/23의 같은 높이1×2픽셀2개이다. 각각 대각선을 포함한 검은 연결 성분은2픽셀이며 피부 여백1픽셀을 검사한다. 깜빡임은 대기 원본에서 눈4픽셀만 바꾼 별도 상태로, 몸·머리·발·배낭이 흔들리지 않는다.

## 생성·후처리

내장 `image_gen`으로 전체 여행자 시트를 생성하고 걷기B와 바짓단 길이를 보완했다. 원본3회와 전체 프롬프트는 `generation.json`, `source/proportion-correction.json`, `source/generated-v1.png`~`generated-v3.png`에 보관했다. 이미지1은 승인한 v6 엘프의 픽셀 스타일/비율 참고, 이미지2는 기존 여행자의 정체성/복장 참고이다. 처음 생성된 원본을 그대로 사용하지 않는다.

`tools/build_traveler_keyframes_v1.py`가 모든 전신 포즈에 공통 배율을 사용하고 머리/접지 앵커로 정렬한다. 몸통과 다리를 다른 그림에서 조립하지 않는다. 기존 `tools/process_pixel_art.py`와 `manifest.json`으로 배경 정리 → 원본 격자 → 재질별 램프 변환 → 검사를 수행한다. 짧은 바지 끝의 경계에서 양자화가 피부색을 선택하는 경우에는 명시적 재질 마스크로 옷 끝을39행까지 유지한다. 깜빡임은 같은 원본의 눈 상태 마스크로 만든다.

각 포즈의 원본과3배 결과를 함께 보관한다. 설명 글씨는 일반 글꼴이다. 수치 검사는 자연스러운 걸음걸이나 디자인 승인까지 대신하지 않으므로 전신 포즈를 눈으로 함께 확인한다.

## 물약 접점

받기 손 내밀기 손 앵커 `[5,31]`, 손 모으기 앵커 `[12,35]`이다. 병의 로컬 잡는 점은 `[width/2,height-6]`로 둔다. 작은 병과 긴 병36종 모두 화면을 벗어나지 않고 두 눈과 피부 여백을 가리지 않는지 확인했다. 병은 캐릭터 원본에 칠하지 않고 별도 에셋으로 합성한다.

## 재현

`python tools/build_traveler_keyframes_v1.py`

실제 게임 에셋·저장·경제·Windows 자동 시작 등록은 바꾸지 않았다. 다른 손님은 이번 산출물에서 새로 제작하지 않았다.
