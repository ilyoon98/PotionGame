# 제작 원본과 진단용 중간 그림

`generated-v1.png`~`generated-v3.png`는 내장 image_gen의 원본이며, 선택한 원본과 전체 프롬프트는 상위 `generation.json`과 `proportion-correction.json`에 있다. `rough-*.png`, `rough-review.png`는 처음 비율을 확인한 진단 그림으로 최종 키프레임이 아니다.

`*-registered.png`는 공통 배율로 전신을 정렬한 후 팔레트 변환 전에 만든 중간 원본이다. 실제 검토 결과는 상위 `frames/`, `traveler-keyframes-native.png`, `keyframes-review.png`, `review.html`을 사용한다. 숫자 검사는 상위 `validation.json`을 따른다.
