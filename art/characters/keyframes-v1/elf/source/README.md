# 생성 원본과 중간 결과

`generated-v1.png`는 전체8포즈 생성 원본이며 `anatomy-guide.png`는 승인한 엘프와 부위별 격자 가이드다. 전체 프롬프트·참고 경로는 상위 `generation.json`에 있다.

`*-registered.png`와 `native-diagnostic.png`는 처리 중간 결과다. 최종 파일은 상위 `frames/`, `elf-keyframes-native.png`, `review.html`, `keyframes-review.png`를 사용한다. 생성 원본의 반투명 배경과 색은 최종 팔레트 에셋으로 쓰지 않는다.
