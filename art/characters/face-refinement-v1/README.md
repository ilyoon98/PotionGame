# 얼굴·앞머리 수정 후보 v1

사용자가 엘프가 못생기고 모든 캐릭터의 얼굴이 네모로 보이며, 주인공 오른쪽 위의 헤어라인이 비어 보인다고 지적했다. 숫자 검사만으로 외형이 자연스럽다는 결론을 내리지 않는다. 머리22×16은 기준 영역이며 피부 면을22×16 직사각형으로 채우라는 뜻이 아니다.

`review.html`은 남자 주인공·엘프·여마법사·여행자의 수정 전후를 같은 배율로 비교한다. 기본3배, 전체 캐릭터를 함께6배로 확대 검사하는 선택과 눈 감은 상태를 비교하는 기능이 있다. 글씨는 일반 글꼴이다. `before-after.png`는 전체 전신 비교, `faces/*.png`는32×48 정지 결과와 깜빡임이다.

내장 image_gen으로 기존 전신4명을 참고해 볼·턱·앞머리를 함께 다듬었다. 생성 원본은 `source/generated-round-v1.png`, 전체 프롬프트는 `generation.json`에 있다. 원본을 배경 정리 → 격자 정리 → 재질 램프 배정 → 검사로 처리한 후, `profiles.json`의 머리 영역과 접점을 통해 각 기존 전신에 적용했다. 다른 포즈의 다리를 붙이거나 몸의 비율을 바꾸지 않는다. 비교 원본은 `source/originals/`와 `source/before-keyframes/`에 보관했다.

새 얼굴은 아래턱으로 갈수록 피부 면이 좁아지며 모서리를 계단형으로 다듬는다. 눈 주변의 작은 피부 여백만 정리하고 얼굴 전체를 직사각형 피부 패치로 다시 덮지 않는다. 주인공은 두 눈을21~22행에 맞춰 앞머리 여유를 확보하며, 오른쪽 위17~20열/19행과19~20열/18행을 기존 갈색으로 연결했다. 원래 목 접점26행은 보존한다. 엘프는 왼쪽 머리 장식만 초록색으로 두고 나머지 머리 영역의 색 분류 오류를 갈색으로 정리했다. 두 눈은1×2이고 대각선까지 피부 여백1픽셀이다. 깜빡임은 같은 그림의 눈4픽셀만 바꾼다.

엘프·여마법사·여행자의 각8키프레임, 총24포즈에 반영했다. `validation.json`에서 모든 포즈의27행 아래 몸·손·의상·다리·발이 수정 전과 같은지, 눈·외곽선·5색·원본32×48을 검사한다. 이전 여마법사 모자 착용 위치[0,4]는 유지했다. 여행자의 여성 인상이 약하다는 기존 피드백은 별도 보류 사항이다.

움직이는 전체 화면은 `art/mockups/full-ingame-v7/animated-preview.html`이다. 승인한 v6의 나머지 가구·물약 진열·날씨·솥 액체색·불꽃을 이어받고, 수정한 주인공과 엘프의 상하 호흡·깜빡임·모자/망토/머리 부분 움직임을 함께 검사했다. 총256IDLE프레임에서 두 눈·피부 여백과 주인공의 앞머리 연결을 별도로 검사한다. 기록은 `art/mockups/full-ingame-v7/motion/eye-fringe-validation.json`이다.

새 얼굴 디자인은 검토 후보이며 기존 얼굴 승인으로 자동 승인하지 않는다. 실제 Godot 런타임 에셋은 이번 얼굴 후보로 교체하지 않았다.

재현 순서: `tools/build_face_refinement_v1.py` → 엘프/여마법사/여행자 키프레임 빌더 → `tools/build_round_face_workshop_v7.py` → `tools/validate_round_face_motion_v7.py` → `tools/publish_face_refinement_v1.py`.
