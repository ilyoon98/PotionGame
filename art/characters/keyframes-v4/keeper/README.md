# 남자 주인공 행동 수정 v4

사용자 지적: 제조는 얼굴만 왼쪽, 모자는 이전 방향 / 반대손이 허리에 올라감 / 전달 머리에 보라색 / 전달 중 허리가 앞뒤로 움직임 / 모자가 정지 / IDLE 누락.

- 새 전신 시트로 제조의 모자·얼굴·목·몸 방향을 함께 맞췄다. 기존 v3 머리 방향만 수정하는 방식을 폐기했다. 반대팔은 옆으로 내려둔다.
- 팔레트5색뿐 아니라 머리 재질을 별도로 검사한다. 새 갈색 머리에는 보라색이 없다.
- 전달은 같은 머리/허리/반바지/다리/발을 쓰며 완전한 작업 팔 영역(투명 공간 포함)만 등록한다. 이전 다른 포즈의 독립 팔/머리 덧붙임을 쓰지 않는다.
- 기존 IDLE 방식(위아래 호흡3초, 깜빡임4.5초)을 새 전신으로 다시 만들고 검토 화면에 직접 연결했다. 키포즈만 반복하는 화면에서 끝내지 않는다.
- 모자 끝의 실루엣과 망토 끝, 갈색 앞머리 결을 같은 루프에서 움직인다. 모자 착용점과 손 접점, 허리, 발을 고정한다.
- 원본32×48/3배. 각6포즈×2모드×64상태=768움직임 검사. 표시1픽셀 부분 움직임은1/3원본픽셀, 원본 격자는1원본픽셀. 색 보간/반투명 없음. 눈은 열림1×2 / 감김1×1 두개다.
- 36물약 제조108/전달72조합 검사. 머리 충돌에는 팔 부착물을 제외한 실제 머리/모자 마스크를 쓴다. 병과 국자는 별도 에셋이며 물약별 색을 유지한다.
- 새 키포즈/움직임은 검토 후보. 다른 손님 행동 애니메이션과 Godot 통합은 남았다. 기존 저장/자동실행/런타임 에셋은 수정하지 않았다.
