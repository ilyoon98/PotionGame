# 엘프 전신 재디자인 v1

2026-10-14 사용자 요청: “엘프 너무 아무개처럼 생겼는데 새로 디자인을 하면 안될까?”

숲의 약초 수집가를 떠올릴 수 있도록 옆땋은 머리, 큰 두 잎 머리장식, 짧은 비대칭 잎 어깨망토를 함께 새로 디자인했다. 둥근 볼과 좁아지는 턱, 좁은 튜닉, 짧은 다리는 공통 규격으로 단순화했다. 이름이나 역할을 게임 데이터에 추가한 것은 아니다.

- 상태: 새 전신 정지 시안, 검토 후보. 사용자 승인 전이다.
- 검토 화면: `review.html`. 기존/새 전신은 공통6배 또는3배, 캐릭터 비교와 작업실은 공통3배다.
- 최종 원본: `elf-native.png`32×48 / `elf-3x.png`96×144.
- 승인된 엘프5색만 사용했다. 추가 색0, 팔레트 밖 색0, 반투명0, 외곽선 경계 오류0이다.
- 머리22×16 기준/11~26행 안의 실제 bbox는[5,11,26,27]21×16이다. 몸통27~39행, 다리40~46행, 발46행, 상단11행과 마지막47행은 투명이다.
- 눈은 x11/x16,y22/23의1×2픽셀2개다. 대각선까지 각각 고립된2픽셀 연결 성분이고 주변1픽셀 피부 여백을 지킨다. 새 앞머리에 맞춘 위치이며 예전 엘프 눈 좌표를 억지로 덮지 않았다.
- 서 있는35행 허리10픽셀,37~39행 하단12/12/10픽셀이다. 땋은 머리는34행에서 끝난다.

내장 `image_gen` 도구로 새 전신을 생성했다. 원본과 프롬프트는 `source/generated-v1.png`, `generation.json`에 보관했다. 참고 그림은 기존 비교 보드이며 픽셀 밀도·팔레트·부위 비율만 참고했다.

고정 후처리 `tools/process_pixel_art.py`: 배경 정리 → 격자 정리 → 재질 램프 변환 → 검사. 전신 전체를 같은 비율로 등록하고 몸통/다리를 다른 포즈에서 잘라 붙이지 않았다. 축소된 앞머리2픽셀의 재질과 눈4픽셀을 명시적 마스크로 정리했으며, 허리와 하단의 작은 초과4픽셀은 이유가 있는 배경 마스크로 제거했다. 마스크는 `manifest.json`에 있다.
