# 고양이 도적 키프레임 v2

2026-10-14. 엘프 뒤 다음 손님을 진행하라는 요청으로 제작한8키포즈 후보다.

- 기존 게임 v4의 주황 머리·고양이 귀/꼬리·붉은 목도리·평평한 검은 짧은 상의·반바지/장갑/부츠를 단순화했다. 승인된 도적 팔레트5색만 사용했다.
- 원본은 모두32×48이며 공통3배 nearest로 표시한다. 머리는11~26행의22×16 기준 영역 안에 있다(실제 실루엣20~22×15~16). 몸통27~39행, 다리/부츠40~46행, 발46행, 마지막47행은 투명하다. 귀와 머리를 합쳐도 이 영역을 넘지 않는다.
- 대기, 걷기 접지/통과A/B, 받기 손 내밀기/모으기, 대기 깜빡임. 깜빡임은 같은 대기 전신에서 눈4픽셀만 바뀐다. 새 전신을 생성했으며 다른 포즈의 팔다리를 잘라 붙이거나 예전 얼굴 훅을 사용하지 않았다.
- 두 눈은 x10/x14,y23/24의1×2이고 같은 높이다. 피부 여백1픽셀은 대각선까지 검사했다. 닫힌 눈은 y24의2×1이다.
- 왼쪽/오른쪽 통과 포즈에서 지지 발이 바뀌고 접지 포즈는 두 발이 접지한다. 생성 시트들의 서로 다른 출력 확대율은 전신 높이로 맞췄다. B포즈와 접지A는 전신을1행 아래에 등록하고 발 아래 초과1행만 배경 마스크로 정리했다. 외곽선은 고정 파이프라인에서 다시 구축했다.
- 솥·물약색은 캐릭터에 넣지 않는다. 받기 손 앵커는 [4,30]과 [12,34], 병의 접점은 [폭/2,4]다.36종×2포즈=72조합의 화면 안 배치, 실제 피부 손 접점, 머리와 두 눈의 가림을 검사했다.
- 목 주변의 실제 중심 영역 [11,26,18,31]은 빈 구멍0이다. 말려 올라온 꼬리와 몸 사이의 빈 공간은 실루엣의 의도된 음영 없는 틈으로 보존했다.

검토 화면은 review.html, 전체 확인표는 keyframes-review.png, 네이티브 시트는 rogue-keyframes-native.png이다. 걷기 반복은4주요 포즈의 확인용 재생이고 완성 행동 애니메이션은 후속 단계다. 기존 캐릭터38파일의 해시가 그대로인지 검사했으며 Godot 런타임에는 적용하지 않았다.

재생성: tools/build_rogue_keyframes_v2.py → tools/process_pixel_art.py. 배경/알파 정리 → 격자 → 재질 램프 변환 → 검사 순서. semantic-masks.json에 눈·의상·발 아래 배경 마스크의 이유를 남겼다. 원본과 프롬프트/참고 경로는 generation.json과 source/에 보존했다. 생성 방식은 image_gen.imagegen의 builtin 모드다.

다음 순서: 도적 포즈 검토 → 남자 주인공의 제조/전달 키프레임 → 손님 입장/대기/받기/병을 든 퇴장 행동 → 상하 호흡과 머리·망토·모자·꼬리 부분 움직임 → 전체 목업 합성 → Godot 적용.
