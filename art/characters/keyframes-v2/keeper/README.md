# 남자 주인공 제조/전달 키프레임

2026-10-14. 전체 캐릭터의 팔레트를 검사하고 다음 작업을 진행하라는 요청에 따라 만든6키포즈 후보다.

원본은32×48, 표시3배 nearest다. 승인 팔레트5색(테두리/눈, 피부/셔츠, 머리/반바지/부츠, 모자/망토, 장식)을 그대로 쓴다. 현재 남자 주인공의 짧은 갈색 머리와 크림 셔츠, 앞이 열린 보라 망토, 반바지·맨 무릎·부츠를 유지한다. 모자/머리/목의 기존 불투명 픽셀은 그대로 유지하고, 올린 팔만 기존 머리 실루엣 밖 [0,14,10,28]에 추가한다. 몸통과 팔·다리는 각각 한 전신 생성 원본에서 가져왔으며 다른 포즈의 팔다리를 잘라 붙이지 않았다. 예전 얼굴 보정 훅은 쓰지 않았다.

포즈는 대기, 제조 손 뻗기, 젓기A/B, 전달 손 내밀기, 손 회수다. 두 눈은 같은 높이의1×2이며 x15/x18,y21/22와 피부 여백1픽셀을 유지한다. 발은46행이고47행은 투명하다. 몸통27~39행, 다리/부츠40~46행이다. 올린 팔과 모자 폭을 머리 크기에 포함하지 않는다.

최초 제조 포즈는 손이32×32솥의 입구보다 낮아 폐기하고, 실제 같은 발 높이의 솥을 참고해3전신을 다시 생성했다. 제조 손 접점은 [2,17], [2,21], [3,17], 전달은 [28,30], [22,34]다. 국자는 별도18×12/2색 에셋이고 접점 [15,0]이다. 국자의 대각선은 모서리로 이어지는 픽셀 선이다. 솥의 앞면이 잠긴 국자 부분을 가린다. 물약병 접점은 [폭/2,4]다.

검사:6원본의 지정5색, 팔레트 밖0, 반투명0, 외곽선 위반0, 두 눈/피부 여백, 발/목 연결을 통과했다.36물약×3제조=108국자/액체 표면 접점,36물약×2전달=72병/손/머리 가림 접점을 통과했다. 기존169아트 파일은 변경하지 않았다. 전체 최신38키포즈와 주인공IDLE128장,166장의 별도 재검사는 [전체 검사 기록](../../audit-v1/validation.json)에 있다.

review.html에서6포즈, 국자/물약 접점, 제조/전달 키포즈 반복과36물약의 솥 내용물색을 확인할 수 있다. 완성 행동 애니메이션은 다음 단계이며 Godot에는 아직 적용하지 않았다. 여행자의 여성 인상 보류 등 기존 검토 상태는 그대로 기록했다.
