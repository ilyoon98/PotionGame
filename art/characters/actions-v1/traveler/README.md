# 여행자 행동 애니메이션 후보 v1

- 기존7키포즈는 그대로 복사하고, 내장 image_gen으로 빈손이 아닌 병 받침 자세의 걷기4전신을 새로 생성했다. 머리/몸통/다리를 다른 포즈에서 조립하지 않는다. 생성 원본·참고·프롬프트는 source/ 및 generation.json.
