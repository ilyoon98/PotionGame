- 기존7전신 키포즈는 픽셀/파일 그대로 보존했다. 병 든 걷기4전신을 내장 image_gen으로 생성하고 같은 배율로 등록했다. 다른 포즈의 머리/몸통/다리를 조립하지 않았다. 원본/프롬프트/참조와 처리 기록은source/ 및generation.json.
