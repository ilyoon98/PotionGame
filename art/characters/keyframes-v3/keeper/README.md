# 왼쪽 제조 전신 v3

2026-10-14. 사용자가 손뻗기 포즈의 세 번째 손과 겨드랑이의 가는 팔을 지적하며 왼쪽 전신 재제작을 요청했다. v2 제조3포즈는 시각 검수에서 실패한 후보로 보존하고 최신 연결에서 제외한다.

제조3포즈는 머리부터 다리까지 새 전신으로 생성했다. 기존 머리/팔을 덧붙이지 않는다. 남캐의 짧은 갈색 머리·크림 셔츠·앞이 열린 보라 망토·갈색 반바지/맨 무릎/부츠·모자와 지정5색을 유지한다. 셔츠는 연속된 크림색 면이고 허리 왼쪽에 예전 손 조각을 남기지 않았다. 대기/전달2포즈는 오른쪽의 기존 전신과 픽셀 단위로 같다.

32×48, 발46행/47행 투명. 몸통27~39행, 무릎·부츠40~46행. 새 제조 얼굴의 두 눈은 x12/x15,y18/19의1×2이며 대각선까지 피부 여백1픽셀이다. 이전 오른쪽 눈 좌표를 새 왼쪽 얼굴에 강제로 사용하지 않는다. 대기/전달 눈은 기존 x15/x18,y21/22다. 모자는 머리 크기에서 분리한다.

anatomy-masks.json은 두 손/셔츠/머리/무릎의 실제 피부 픽셀 영역과 소매 단면을 기록한다. 제조마다 손2영역, 각 손의 피부 연결1개, 분류되지 않은 피부0픽셀을 확인한다. 셔츠/무릎을 추가 손으로 세지 않으며, 허리의 남은 손 조각을 셔츠로 숨겨 판정하지 않는다. 검사한 팔 단면은4~6픽셀로 채워져 있고 보라 안쪽 색2픽셀 이상을 확인했다. validation.json에 실제 값과 눈/색/외곽선/접지 판정이 있다.

제조 손 접점은 [5,16], [3,24], [3,19], 전달은 [28,30], [22,34]다. 별도 국자18×12/2색, 물약병36종을 재사용한다. 같은 발 높이의 솥은 [30,28], 캐릭터는 [52,12]다. 제조108조합의 액체 표면 접점, 전달72조합의 화면/손/머리와 내용물 가시성을 검사했다. 기존166아트 파일은 바꾸지 않았다.
