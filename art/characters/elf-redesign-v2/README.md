# 엘프 의상 재디자인 v2

2026-10-14 요청: “너무 하늘하늘한디 좀더 엘프답게 파격적인 옷은 안돼?”

한쪽 어깨가 드러나는 짧은 잎 상의, 작은 허리 노출, 가죽 허리띠와 손목 보호대, 짧은 반바지 위의 각진 비대칭 잎 장식, 갈색 윗단의 짙은 부츠로 의상을 바꿨다. ‘잎 정찰복’은 시안 설명이며 게임의 직업/이름/행동 데이터를 바꾸지 않았다.

2026-10-14 사용자의 “그래 이정도면 뭐 진행하자” 답변으로 이 전신 디자인을 승인받았다. 범위와 원본 해시는 `approval.json`에 있다. 이 폴더는 정지 전신 기준이며 새 키프레임은 `../keyframes-v2/elf/`에 따로 제작했다. 완성 행동 애니메이션은 아직 아니다. `review.html`에서 이전 v1 의상과 새 의상을 공통6배/3배로 비교하고 작업실 배치도 볼 수 있다.

- 원본: `elf-native.png`32×48 / `elf-3x.png`96×144.
- 머리/얼굴0~26행은 v1과 RGBA 픽셀 단위로 같다. 두 눈은 x11/x16,y22/23의1×2이며 각각 고립된2픽셀과 완전한1픽셀 피부 여백을 지킨다.
- 머리21×16은22×16 기준 안에 있다. 몸통27~39행13행, 다리/부츠40~46행7행, 발46행, 상단11행/마지막47행은 투명이다.
- 서 있는35행 허리10픽셀,37~39행 하단12/12/10픽셀이다.
- 승인 팔레트5색만 사용했다. 팔레트 밖 색0, 반투명0, 외곽선 경계 오류0, 전체 알파 연결 성분1, 목 접점 내부 빈 픽셀0이다.

내장 `image_gen`으로 의상을 편집했다. 생성 원본과 전체 프롬프트/참고 기록은 `source/`와 `generation.json`에 보관했다. 최종 선택 원본은 `source/generated-costume-v2.png`이다. 얼굴 수정이 요청되지 않았으므로 머리는 원본 격자 위치의 보호 영역으로 유지했다. 몸통과 다리는 하나의 생성된 같은 대기 의상에서 왔으며 다른 포즈의 팔다리를 섞지 않았다.

고정 후처리는 `tools/process_pixel_art.py`의 배경 정리 → 격자 정리 → 재질 램프 변환 → 검사다. 의상 전체를 같은 비율로 원본20행에 등록하고 기존 땋은 머리 x22 접점에 맞춰 배치했다. 허리 피부6픽셀은 명시적 재질 마스크로 정리했다. 손목 가장자리 초과2픽셀과 축소 중 묻힌 부츠 사이3픽셀은 이유가 기록된 배경 마스크로 처리했다. 마스크와 검사 보고서는 `manifest.json`, `validation.json`에 있다.
