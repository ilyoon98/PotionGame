# 최신5명 아트 독립 검사

2026-10-14. 주인공6장, 여행자8장, 여마법사8장, 새 엘프8장, 고양이 도적8장으로38키포즈를 검사했다. 주인공 v7의 격자/부분 움직임64장씩도 검사해166이미지를 확인했다. 과거 소스·구형 엘프·48×64런타임 그림을 최신 원본으로 섞지 않았다.

각 캐릭터의 art/palettes/v1/characters/*.hex를 기준으로 직접 RGB색을 셌다. 팔레트 파일과 승인된 역할/재질 배정의 색 집합이 같은지, 공통24색 안의5색인지도 대조했다. 공통24색 안에 있다는 이유만으로 다른 캐릭터의 색을 허용하지 않는다.

전체 통과: 지정 팔레트 밖0, 반투명0, 최대5색, 상하좌우 알파 경계의 외곽선 위반0. 원본32×48, 두 눈1×2와 대각선을 포함한 피부 여백1픽셀, 발46행/47행 투명, 몸통27~39와 다리40~46의 행별 존재를 검사했다. 모자/배낭/말린 꼬리/높이 든 팔은 얼굴 크기와 분리해 기록했다. 주인공128움직임은96×144표시 격자, 호흡 상태별 눈 위치, 닫힌 눈, 발 접지와 색/경계를 검사했다. 격자 모드는 정확한3배인지도 확인했다. 부분 움직임 모드의 내부1/3픽셀 변화는 허용된 기존 규격이다.

검사 기록에는 모든 파일의 SHA256과 색 목록, 눈 좌표, 개별 판정이 있다. 현재 연결은 art/characters/current-art.json에 기록했다. 여행자의 여성 인상 수정은 사용자의 보류 지시를 유지한다. 시각적인 캐릭터 취향을 수치 검사만으로 승인했다고 표현하지 않는다. 실제 Godot의 구형 아트 교체는 후속 단계다.
