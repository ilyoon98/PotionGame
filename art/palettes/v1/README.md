# 캐릭터·물약 팔레트 v1

2026-10-13 사용자가 v6 목업에 “목업 좋고”라고 답하고, **캐릭터별·물약별 팔레트 → 캐릭터 키프레임 → 행동별 애니메이션** 순서를 요청했다. 이번 산출물은 그 첫 단계인 전체 팔레트와 후속 제작 기준이다.

이후 확인표를 본 사용자가 “좋아 이제 손님 한명씩 만들자고”라고 답해 이 팔레트 배정을 키프레임 제작 기준으로 승인했다. 최신 상태는 `approval.json`을 따른다. 첫 여행자의8개 키프레임은 `art/characters/keyframes-v1/traveler/`에 저장했으며, 새 키프레임의 디자인 자체는 아직 검토 후보이다. 아래 최초 팔레트 제작 시점의 미제작 설명보다 이 최신 기록이 우선한다.

## 확인

- `review.html`: 캐릭터 5명, 물약 36종, 공통 재질을 탭으로 확인한다. 색 코드를 복사하거나 물약 이름·ID를 검색할 수 있다.
- `characters-overview.png`: 주인공·손님별 색 역할.
- `potions-overview.png`: 기존 병과 제조 물약별 솥 색 36종.
- `catalog.json`: 전체 색 역할과 원본 참조.
- `characters.json`, `potions.json`, `materials.json`: 대상별 데이터.
- `characters/*.hex`, `potions/*-bottle.hex`, `potions/*-cauldron.hex`, `materials/*.hex`: 에셋별 색 목록. 공통 파일처럼 `#` 없이 6자리 RGB를 한 줄에 하나 적는다.
- `production-plan.json`: 신체 기준, 키프레임 목록, 실제 게임 행동과 애니메이션 제작 순서.
- `validation.json`: 실제 등장 손님·36개 레시피의 포함 여부, 색 수, 재질 램프, 참조 원본의 색 및 해시 검사.

## 색 사용

공통 팔레트는 기존 승인된 `art/palette.hex`의 **24색**이다. 새 색을 추가하지 않는다. 재질별 색 범위는 `art/ramps.json`을 사용한다. 캐릭터·병·솥별 고유색은 최대5개이며, 역할 여러 개가 같은 색을 공유할 수 있다. 주황 머리와 불꽃처럼 다른 재질도 명시적으로 같은 승인 램프를 공유할 수 있다. 전체 팔레트의 가장 가까운 RGB색으로 자동 치환하지 않는다.

주인공·엘프는 승인한 v6 원본의 실제5색을 그대로 기록했다. 여행자·여마법사·고양이 도적은 현재 게임의 정체성·의상을 유지한 **5색 배정 후보**이며 새 그림은 아직 만들지 않았다. 현재 손님에서 제외된 여기사는 새 제작 목록에 포함하지 않는다.

물약36종의 병 테두리는 `#241C32`, 마개는 `#916047`, 유리·라벨은 `#FFF0BC`이다. 내용물에는 물약별 지정 램프의2색을 배정한다. 유리색과 액체색이 같아도 영역의 역할을 혼동하지 않는다. 색이 같은 물약은 기존 병 모양·라벨·이름으로 구분한다.

솥 테두리·몸체·달 문양·화덕은 각각 `#241C32` / `#86548E` / `#E9B95F` / `#827589`로 고정한다. 솥 내용물은 해당 물약 램프의 밝은 색1개를 사용하고, 현재 v6처럼 기포에는 테두리색을 사용한다. 정확한 노출 액체63픽셀만 물약에 따라 바뀐다. 이 구성에서 솥 전체는 최대5색이다.

표의 설명 글자는 일반 글꼴이며 스프라이트 팔레트 검사 대상에서 제외한다. 기존 v6 PNG는 색을 바꾸지 않고 확인표에 표시했다. 재현 스크립트는 원본 파일 해시가 유지되는지 확인한다.

## 다음 제작 순서

1. 5명 각각의 중립 전신 키프레임을 같은32×48 규격으로 준비한다. 머리11~26행, 몸통27~39행, 다리·신발40~46행, 발46행을 기준으로 한다. 모자 높이는 머리 크기에 포함하지 않는다.
2. 주인공의 제조 준비·젓기·전달, 손님의 걷기 접지·통과·물약 받기 주요 포즈를 준비한다. 원본의 성별·머리 크기·의상을 유지하고 전신 자세를 함께 확인한다.
3. 키프레임을 기준으로 행동별 애니메이션을 제작한다. 주인공은 대기/제조/전달, 손님은 입장/대기/받기/퇴장이다. v6의 상하 호흡과 모자·망토·머리 부분 움직임을 함께 유지한다.
4. 받은 물약은 별도 레시피 병 에셋을 손 앵커에 합성한다. 캐릭터 원본에 물약색을 추가하지 않는다. 퇴장은 병을 든 걷기 동작으로 준비한다.
5. 전체 목업에서 움직임과 판매 시점을 확인한 뒤 기존 Godot 구조에 연결한다.

키프레임과 행동별 애니메이션은 이번 팔레트 산출물에 포함된 완성 그림이 아니다. `production-plan.json`에 제작 목록과 검사 기준을 남겼다. 실제 게임 에셋·저장·경제·Windows 자동 시작 등록은 이번 단계에서 바꾸지 않았다.
