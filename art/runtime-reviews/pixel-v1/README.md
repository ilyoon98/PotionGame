# 실제 게임 적용 확인 · 픽셀 아트 v1

2026-10-15. v9의 마법 전달 흐름과 새 캐릭터를 실제 게임 코드에 연결하고, 바닥을 맵 양끝까지 이어 달라는 요청을 적용했다.

## 적용 내역

- `scripts/pixel_art_catalog.gd`, `pixel_shop_scene.gd`: 남자 주인공과 여행자·여마법사·새 의상의 엘프·고양이 도적. 원본32×48, 본 화면 공통3배. 호흡·깜빡임·모자·망토·머리카락·귀·꼬리와 제조·입장·대기·받기·병을 든 퇴장을 연결했다. 기존 전신을 재사용하며 다른 포즈의 얼굴이나 팔다리를 조립하지 않았다.
- `scripts/shop_art.gd`: 실제 제조 이벤트는 선반 입고로, 실제 판매 이벤트는 선택 병의 출고→판매대에 놓기→마법 비행→손님이 잡기→퇴장으로 이어진다. 같은 업데이트의 여러 판매는 현재 손님과 물약을 덮지 않고 시각 대기열에 넣는다. 경제는 계속 ShopState가 소유한다.
- `scripts/potion_display.gd`, `workshop_layout.gd`: 작업실과 기본 실내의 보이는8자리와 예비 보관 재고, FIFO, 제조·판매가 겹치는 경우를 유지했다. 병 높이에 따라 밑면을 선반 보드에 맞춘다. 손에서 손으로 직접 건네는 조건은 없다.
- `scripts/shop_motion.gd`: 실제 판매 간격에 맞춰 판매대·비행·받기·모으기·퇴장·다음 입장의 시간을 조절한다. 판매 가격이나 경제 시간을 바꾸지 않는다.
- `scripts/potion_visual.gd`, `item_art.gd`:36종 병과 솥3프레임에 같은 승인 액체색을 쓴다. 병은 별도 에셋으로 실제 손 앵커에 붙인다. 새 아트는 색을 바꾸는 조명 셰이더를 거치지 않는다.
- 본 작업실의 원본x=0..179/표시x=0..539, 기본 실내의 표시x=0..407 바닥을 연결했다. 기본 화면도 같은 창문·선반·화분·솥·판매대의 픽셀 스타일로 구성하며, 좁은 폭에서는 화분을 벽 선반 위에 둔다. 축소 모드는 같은 주인공·솥 원본의 공통 정수3배와 승인된 부착물 움직임을 쓴다. v9 목업의 바닥도 수정했다.
- 재고와 판매 금액은 실제 상태를 일반 글꼴로 표시한다. 긴 병과 겹치지 않도록 글씨를 옆으로 옮겼다. 목업의 물약 선택기는 실제 게임에 추가하지 않았다.

## 검증 근거

`tests/test_pixel_runtime.gd`: 네 손님×36종144조합,1440실제 렌더 상태. 규격·배율·진열 출고·판매대 접지·잡는 순간 위치 연속·퇴장 중 손과 병·중복 병 없음·동시 거래·이동 중인 병 판매·빠른 판매·닫기·모드 전환·렌더링의 경제 불변성을 검사했다.

`tests/test_pixel_catalog.gd`와 PNG 대조:327개 엔진 텍스처의 RGBA SHA-256이 게시된 PNG와 전부 일치한다. 공통24색 밖0색, 반투명0픽셀이다. 원래 캐릭터 전신 파일은 변경하지 않았다.

`tools/verify_potion_liquid.gd`:36종108솥 프레임에서 액체 마스크 밖의 몸체·테두리·손잡이·문양·화덕이 같다. `verify_rare_item_art.gd`: 특별4종의 기존 아이콘·레시피·미발견 지도 해시는 유지되며 새 병·솥·색을 사용한다. 이전48픽셀 솥 검사는 현재32픽셀 원본과 명시된 마스크로 갱신했다.

기존 `test_motion`, `test_potion_display`(30분 재고), `test_fifo`(저장·복원), `test_sales_counter`, `test_shop`와 메인 `--smoke-test`도 통과했다. 오래된 스모크 검사의48×64 기대값은96×144표시 프레임으로 고쳤다. 이미 변경되어 있던 일시정지 성장률과 동작 카드 배치도 실제 상태·영역을 검증하도록 갱신했으며, 해당 제품 동작 자체를 바꾸지는 않았다.

`tools/verify_pixel_game.gd`: 실제 Shop과 GPU 렌더러를 실행했다. 네 손님의 실제 판매4건과 혼합 재고8→7병을 사용하고 기본·축소 모드도 확인했다. `game-render.gif`는 실제 뷰포트160장/10fps 재생이며 HTML로 다시 그린 애니메이션이 아니다. GIF 팔레트에도 원본 아트24색을 정확히 포함한다.

원기록은 `.verification/pixel-runtime-v1/`, 재생 포장은 `tools/build_pixel_game_review.py`다. `review.html`에서 손님과 거래 단계의 정지 화면을 선택할 수 있다. 검증 재생의 골드·재고는 격리된 예시 상태다. 플레이어 저장·자동 시작 등록·실행 중인 게임을 덮어쓰지 않았다. 이미 실행 중인 프로세스는 재실행해야 새 스크립트와 리소스를 읽는다.


실제 게임 창 확인: `tools/play_pixel_game_review.gd`로 실제 Shop을 투명한 Windows 창에서 반복 실행했다. 플레이어 저장은 읽거나 쓰지 않는 검증 모드이며 예시 손님/재고를 사용한다. 최근4거래/36화면의 재고8→7→8·솥/병 내용물 색·알파 검사 결과는 `live-pixel-proof.json`과 `live-review.json`에 있다. Windows 창 자동 캡처 권한은 거부돼 바탕화면 합성 자체는 자동으로 육안 검증하지 못했다.


실행 화면 피드백 수정: 원정 표지판 테두리/문구 정렬, 실제 손→액체 내부 국자 접점, 솥 접지(원본1픽셀 하강), 최소 모드 공통3배와256×228배치, 툴바 양끝8px와 최소 크기를 반영했다. 검증 재생기의 손님 변경이 선택 모드를 강제로 되돌리던 문제를 수정했다. `layout-proof.json`과 제조 동작 이미지가 수정본의 실제 GPU 결과다.


실행 구분 정정: 이 페이지의4손님 순환은 예시 상태를 매회 초기화하는 자동 아트 검증 결과이며 누적 플레이 검증이 아니다. 사용자 수동 플레이에는 이 초기화 재생기를 사용하지 않는다. 현재 정상 게임은 원래 AppData 저장을 이어 읽고 자동 저장하며, 통계 창 열기/닫기는 상태를 초기화하지 않는다. 관련 검사는 `.verification/statistics-persistence/`에 있다.
