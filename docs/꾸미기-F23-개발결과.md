## 화면

- **작업실:** 장착한 소품을 승인된 A안 자리(판매대 왼쪽 끝, 주인공 쪽, 원본 캔버스 원점 96,40 = 표시 288,120, 3배)에 그린다. 판매대 다음, 재고 병·선반·사람보다 먼저 그려 판매 병과 손님이 앞에 온다. 캡처: `.verification/f23-decor-20261023/workshop-decor_*.png`.
- **축소(캐릭터) 모드·기본(전체 실내) 화면:** 표시하지 않는다(장착 상태는 유지).
- **관리 · 가구·직원:** "꾸미기" 구역에 소품 2행. 버튼은 `구매 · 120 G` → `장착` → `해제`. 목록 아이콘은 32×32 그림의 16×16 부분을 48px(정확히 3배)로 보여준다.
- 저장 실패 시 골드·직접 투자·소장·장착을 모두 되돌린다(`Shop.perform_decor_action`).

## 저장

- 저장 버전 16 → **17**. 새 키 `decor`: `{version: 1, owned: [id], equipped: {counter: id 또는 ""}}`.
- v17 저장의 `decor`가 없거나 잘못되면(모르는 id·중복 소장·소장하지 않은 장착·칸 누락·버전 불일치) 저장 전체를 거부한다. v16 이하는 장식 없이 시작한다.
- `verify_f20_recovery`·`verify_f20_unpurchased`는 고정 기준과 비교할 때 `decor`도 제외한다. `verify_sfx_v1`·`verify_f22_regulars`의 저장 버전 단언을 갱신했다.

## 작업실 기념품 칸 · 2026-11-05

사용자가 작업실용 작은 기념품 후보(`art/mockups/f23-souvenir-mini-v1/`)를 보고 **"A안 창틀 위"**를 골랐다. 12×12 작은 기념품 4종과 A안 자리를 승인 범위로 기록했다(B안·벽 못 그림은 채택하지 않음).

- 게시: `tools/publish_f23_souvenir_mini_v1.py` → `assets/pixel_v1/souvenirs/souvenir_*_mini.png`, catalog `souvenirs_mini` (승인 스프라이트 바이트 그대로). 관리 창의 32×32 기념품은 그대로 둔다.
- 칸: 장식에 `souvenir` 칸을 더했다. 기념품은 사지 않고, 해당 손님이 단골(기록 60) 단계에 오르면 소장된다. 장착·교체·해제는 무료이고 판매대 소품 칸과 따로 움직인다.
- 화면: 작업실 창틀 위(12×12 캔버스 원점 원본 14,0 = 표시 42,0, 3배)에 그린다. 숙성통과 함께 보이며, 캐릭터·전체 실내 모드에는 그리지 않는다. 관리 · 가구·직원 "꾸미기" 구역에 기념품 4행(목록 아이콘은 12×12 작은 그림의 4배). 받지 않은 기념품은 "단골이 되면 받아요"로 잠겨 있다.
- 저장: 저장 버전은 17 그대로이고 `decor` 내부 버전만 1 → 2로 올렸다. 버전 1 기록은 빈 기념품 칸으로 이관된다. 장착된 기념품을 단골 기록상 아직 받지 않았으면 저장 전체를 거부한다.
