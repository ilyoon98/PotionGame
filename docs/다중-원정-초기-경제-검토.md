## 확인한 경계 조건

- 초기 모델에서 예비금 바로 아래는 출발하지 않고 골드가 충족되면 자동 출발했다. 진행 중에는 재출발비를 다시 차감하지 않았다.
- 격리된 전 지역 해금 상태에서 8개 원정이 동시에 독립 진행했다. 일반 진행에서 보관·출발 조건에 따라 실제 최대 동시 수가 6~7이었다.
- 완료 지역의 보상 보관이 가득 차면 재출발하지 않고, 보유량 감소 후 자동 출발했다. 미완료 조사 비용 부족 시 완료 지역이 그 예산을 소진하지 않았다.
- 9회 모두 2시간에 레시피·지역·투자 목표가 남았으며 매출·재료비·원정비·투자·골드 장부가 일치했다.
- 모든 지역의 필수 조사 회차 출발비 합계는 1,947 G다. 옛 지역의 추가 재료 원정 비용은 별도다. 8지역이 쉬지 않고 최대 30% 시간 단축으로 반복한다고 가정한 이론 지출 상한은 분당 약 98.2 G다. 실제로는 완료 지역의 보관 대기가 지출을 줄인다.

## 실제 검증에서 남은 항목

- 이번 모델에는 실제 저장 이전·회차 ID 복원·Godot UI·Windows 입력·OS 클릭 전달 검증이 없다. 이를 통과한 것처럼 보고하지 않는다.
- 3~5시간 주요 콘텐츠 목표는 원정·레시피 우선과 복귀 전략에서 관찰됐지만 설비 우선은 더 오래 걸렸다. 강화 선택을 강제하지 않는다.
- 재고 줄타기·개별 손님 대기·신규 재료의 체감 가치·기본 구매 예비금은 실제 엔진에서 추가로 측정한다. 초기 비용을 영구 확정 수치로 약속하지 않는다.
- 이전 후보 C의 독립 계산과 실제 5물약 게임 측정을 이 새 구조의 결과로 재사용하지 않는다.
