F02 구현: `scripts/desktop_input.gd`가 `native/windows/DesktopPassthrough.cs` 보조 프로그램 하나만 실행한다. Windows x64에서 그림 영역(y=0~247)은 보기 전용으로 뒤 프로그램에 입력을 넘기고, 하단 관리·아이콘·이동 바(y=248~287)는 입력을 받는다. 캐릭터·날씨 위에서도 클릭이 통과한다. `WS_EX_LAYERED | WS_EX_TRANSPARENT`를 포인터 위치에 따라 전환하여 사물 렌더를 자르지 않는다. 누른 마우스 버튼의 입력 대상은 유지하며 다른 화면 모드·종료에서는 원래 플래그로 복구한다. 잠금 화면에서는 복구 후 기다린다. 보조 프로그램 실패 시 UI 입력을 유지하고 툴팁에 알린다. Windows 외 환경은 이 네이티브 클릭 통과 대상이 아니다.

빌드: `tools/build_desktop_passthrough.ps1`로 C# 소스와 내장 바이너리를 함께 갱신한다. Godot 내보내기에는 preload한 `desktop_bridge_binary.gd`가 포함되며 실행 시 사용자 데이터의 `native` 폴더에 해시 이름으로 추출한다. 테스트는 별도 폴더에 추출한다. 중복 구현은 제거했고 실제 실행에서도 작업실 진입 시 활성화한다. 렌더 전용 테스트에서는 비활성화한다.

검증: 별도 Godot 프로세스의 뒤쪽 버튼이 실제로 눌리는 것과 투명 화면 유지, 관리 버튼으로 독립 창 열기, 전체 실내 복귀를 확인했다. `tools/verify_desktop_lifecycle.gd`는 전체·작음·최소 모드 전환, 빠른 껐다 켜기, 노드 종료 시 보조 프로세스 제거를 검증하며 최종 코드에서 PASS했다. 관리 렌더·경제 진행·smoke 검사도 통과했다. 기본 창 드래그가 움직이지 않아 작업실을 이벤트 좌표 기반 이동으로 수정했다. 최종 수정 후 연속 드래그·관리·최소화 조합, 다중 모니터 배율 125~200%, 배포본 실사용은 아직 검증하지 않았다. 사용자 요청에 따라 Computer Use를 중단했으며 이 부분은 검증 완료로 표시하지 않는다.

환경 비교 이미지는 실제 게임 렌더를 밝고 어두운 **검증용 배경에 합성**한 자료이며 다른 프로그램을 캡처한 것으로 표현하지 않는다. `.verification/environment-comparison.png` 및 `workshop-*.png`, `management-page-*.png`에 저장한다.

목록 하이라이트는 `success_chance()`와 `growth_rate()`의 실제 환경 보정에서 계산한다. 기본 물약·기본 약초에는 환경 보너스가 없으므로 강조하지 않는다. 잠긴 특수 물약과 별잎 재배는 운영 목록에서 숨기고 구매 메뉴에서 확인한다. 관리 창을 연 채로 낮·맑음→밤·비→낮·맑음을 바꾸는 검증에서 강조 켜짐/해제를 확인했다. `.verification/management-environment-highlights.png`에 화면을 저장했다. 바깥 작업실에는 품목별 성장 문구를 나열하지 않는다.

- 일반 거래 명성 +1, 선호 거래 +2. 명성은 소비하지 않는다.
- 판매 보조: 명성 20 필요, 고용비 360 G 1회, 선호 거래 +2 G. 급여·훈련·피로·식사·교대 없음.
- 숲 원정: 명성 10 필요, 해금비 400 G 1회, 해금 즉시 자동 출발. 탐색 60초+귀환 10초, 보상 별잎 2개. 반복 비용·직원 조건·희귀 추첨 없음. 보관 초과는 한 회차분만 보존하고 재출발 대기.
- 결과 화면을 여는 것만으로 집계 기준을 변경하지 않는다. `여기서 새 집계 시작`을 누르면 이미 받은 보상은 유지한 채 비교 기준만 갱신한다. 시작 날짜·시각과 앱 실행 누적 시간을 함께 표시한다.

비중은 금지 조건이 아니며 최소 0.5다. 손님은 방문 시작 시 선택되고 품절이면 같은 손님이 기다린다. 일반 구매는 선입선출이고, 선호품이 있으면 **해당 종류 안에서 선입선출**이다. 판매한 칸 뒤의 물약만 당겨지며 새 포션은 맨 뒤로 간다.

## 남은 결정

- 가격·성공률·방문 비중·명성·원정 보상/시간은 플레이 테스트 후 확정해야 한다.
- 여기사는 현재 제외한다. 네 손님은 준비된 4프레임 애니메이션을 사용한다. 여기사 재추가는 별도 결정 전까지 진행하지 않는다.
- 신규 포션은 기존 병에 색을 적용한 구분용 표현이다. 개별 병 디자인, 별잎 전용 그림, 직원의 작업실 캐릭터는 후속 외형 작업이다.
- 일반 실내·작은 모드·최소 모드는 보존했다. 전체 화면의 `작업실` 버튼에서 새 모드로 들어간다. 작업실 하단 바를 드래그하고 `관리`로 패널을 연다.
- 사치·장식, 종료 중 수익, 연구 타이머, 반복 원정 비용, 출시·과금 기능은 구현하지 않았다.
