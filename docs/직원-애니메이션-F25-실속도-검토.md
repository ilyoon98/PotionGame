# F25 직원 실제 속도 검토와 수정

2026-11-06. 사용자 요청에 따라 직원 4명을 기존 캐릭터 5명과 같은 화면에서 1배 속도로 재생했다. 게임 세이브와 배치를 건드리지 않는 별도 Godot 4.6 비교 창을 사용했다.

[함께 움직이는 비교](../art/mockups/f25-staff-playback-v2/review.html) · [기존+직원 GIF](../art/mockups/f25-staff-playback-v2/together-1x.gif) · [직원 수정 전후 GIF](../art/mockups/f25-staff-playback-v2/before-after-1x.gif)

## 확인한 문제와 수정

- 수정 전에는 네 명이 3초마다 같은 시점에 머리를 올리고, 4.5초마다 같은 시점에 눈을 깜빡였다. 실제 창에서도 같은 프레임 전환이 함께 반복됐다.
- 호흡 시작 시점과 들숨 유지 시간을 각각 분리했다. 호흡 주기 자체는 기존 캐릭터와 같은 3초이며 움직임 크기는 원본 1픽셀이다.
- 눈 감음은 120ms에서 200~220ms로 늘렸다. 18초 안에 각자 3~4회 깜빡이도록 간격을 다르게 구성했다. 재생 화면에서 재배 보조만 눈을 감는 시점도 확인했다.
- 신체 정렬과 네 가지 원본 상태(정지·들숨·깜빡임·들숨/깜빡임)는 한 픽셀도 바꾸지 않았다. 목과 옷 접합에서 추가 수정이 필요한 단절은 보이지 않았다. 손·발·소품도 유지된다.

| 직원 | 3초 주기 안 들숨 시작 | 들숨 유지 | 눈 감음 |
|---|---:|---:|---:|
| 판매 보조 | 1.50초 | 1.20초 | 200ms |
| 재배 보조 | 2.05초 | 1.10초 | 220ms |
| 조제 보조 | 2.65초 | 1.25초 | 200ms |
| 원정 길잡이 | 0.85초 | 1.15초 | 220ms |

## 기존 캐릭터의 실제 재생과 맞춘 부분

현재 게임은 `scripts/pixel_art_catalog.gd`의 `motion_index()`로 `idle-fine.png`에서 프레임을 고른다. 16단계 부분 움직임(2초), 호흡(3초), 눈 깜빡임(4.5초)을 조합하므로 전체 주기는 **18초**다. 64칸을 순서대로 재생하는 방식은 사용하지 않았다.

기존 캐릭터는 실제 fine 96×144 그림을 1배로, 직원은 32×48 그림을 최근접 3배로 표시한다. 기존 fine에는 승인된 화면 1픽셀 단위 세부 움직임이 있으므로 native를 3배로 확대한 그림과 같지 않다. 두 집단 모두 최종 표시 영역은 96×144이고 발 바닥 위치는 141px다. 승인된 기존 그림은 그대로 두었다.

## 실제 확인과 한계

- **Godot 라이브 확인:** 별도 창의 1배 재생을 Computer Use로 확인했다. 수정 전·후의 실제 화면과 시간 기록을 함께 검토했다. 저장한 수정 후 기록은 60.08초, 117개 시점이며 13개 항목(기존 5 + 직원 전 4 + 후 4)의 모든 시간 구간과 반복 경계를 통과했다. 접지 오류와 비정수 위치는 모두 0이었다.
- **원본 검증:** 기존 캐릭터의 fine 320프레임을 독립 픽셀 검사로 대조했다. 원본과 RGBA가 동일하고 각 152구간의 시간표도 현재 게임 함수와 일치했다.
- **Godot 리소스:** 직원 `.tres` 4개를 별도 프로젝트에서 로드했다. 19~21개 타이밍 구간의 18초 반복, 원본 5색과 이진 알파를 확인했다.
- **GIF:** 두 공유 GIF 모두 360프레임·20fps·18초다. 모든 캐릭터의 움직임과 시점별 픽셀을 확인했다. 공유 GIF는 50ms 간격으로 표본화하므로 정확한 25ms 경계까지 확인하려면 HTML 또는 Godot 비교 창을 사용한다.
- 화면 캡처와 라이브 시간 기록으로 확인한 결과이며, 연속 재생 영상을 분석한 것 또는 사용자 미술 승인을 뜻하지 않는다. 이번 개선은 대기 타이밍에 한정된다. 새 전신 행동과 게임 연결은 포함하지 않는다.

## 다시 만드는 방법

```powershell
node tools/build_f25_staff_playback_v2.mjs
```

Pixelbolt 0.11.0으로 원본을 읽고 GIF·HTML·PNG·Godot 리소스를 다시 만든다. `.verification/f25-staff-playback-godot/`에 별도 실시간 비교 프로젝트도 준비한다. 이 폴더에서 Godot 4.6을 `--script review.gd`로 실행하면 1배 재생이 시작된다. 기본 사용자 폴더 쓰기가 제한된 환경에서는 `APPDATA`와 `LOCALAPPDATA`를 해당 검증 폴더 안으로 지정한다. 라이브 기록과 화면 캡처는 실제 실행 결과이므로 제작 명령만으로 새로 만들지는 않는다.

HTML에서는 재생/일시정지·처음부터·0.5/1/2배·정지 자세 비교를 제공한다. 실제 게임의 작업실 직원 배치와 역할 아이콘은 기존 결정을 유지한다.
