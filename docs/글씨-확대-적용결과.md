# 글씨 확대 적용 결과

> 후속 변경: 글씨 크기는 유지하며 하단 여백을 추가했다. 현재 본540×300·최소256×172·정보320×124다. 아래 크기는 글씨 확대 당시 기록이며 [최신 하단 적용 결과](하단-UI-여백-적용결과.md)를 따른다.

2026-10-10 · **구현 완료 / 격리된 글꼴·배치 검사 완료 / 실제 화면 조작 미실시**

사용자의 글씨 확대 요청에 따라 Pretendard Regular·SemiBold를 유지하며 크기를 높였다.

| 화면 | 변경 |
| --- | --- |
| 관리 | 본문·탭·버튼 14→16px, 항목 제목 16→18px, 상단 제목 22→24px, 게이지·보조 글씨 12→14px. |
| 작업실 | 상태 글씨 10→14px, 하단 골드 14→17px, 관리·원정 숫자 11→13px. |
| 최소 모드 | 골드 12→15px, 코인 12→16px. 큰 수는 표시 공간에 맞춰 축약하며 정확한 값은 툴팁으로 확인한다. |
| 정보 모드 | 골드 18→22px, 진행과 최근 1분 수입 11→14px. 짧은 제조 상태와 실제 수량을 표시하고 물약 이름·자세한 내용은 툴팁에 유지한다. |
| 전체 실내 | 골드 27→30px, 보조 글씨 10/12→12/14px. 설비 카드 제목 13→16px·본문 10→14px·버튼 11→13px. 획득 표시 13→16px와 아이콘 18→20px. |

관리 폭은 520px로 유지하고 약초·포션 두 게이지 행은 98→110px, 추천 상자는 68→76px로 늘렸다. 긴 설비 상태는 카드 아래 전체 폭으로 표시한다. 본 작업실 540×288·최소 256×160·정보 320×112·실내 440×704 크기와 하단 버튼 순서는 유지한다.

작업실 약초 상태 상자만 위로 8px 늘려 `(16,202,104,42)`로 조정했다. 큰 글씨 두 줄과 게이지를 분리하면서 재배 받침·성장 그림·상세 버튼 위치를 유지한다. 승인된 디자인 파일 자체는 수정하지 않았으며 이번 사용자 글씨 요청이 이전 상태 상자 좌표보다 우선한다. 실제 Font 상속 후 Label 크기를 지정하여 임시 기본 글꼴의 최소 높이가 남는 문제도 수정했다.

경제·구매·강화·제조·FIFO·원정·저장·로그인/단일 실행 동작은 변경하지 않았다.

검사 로그는 작업 공간 루트 `.verification/`에 있다.

- `large-management-readable.log`: 실제 모든 탭·추천·조건·버튼·게이지·열린 상세·보상 코인 칩의 글자 크기와 배치 검사.
- `card-type.log`: 실제 Pretendard 줄 높이·긴 설비 상태·최대 강화 금액과 카드 간격 검사.
- `mini-readability.log`: 0부터 int64 최대 금액까지 15px 글리프·축약·코인·버튼 간격과 경제/RNG 불변 검사.
- `large-font-verify_wide_workshop.log`: 실제 모델 7상태의 14px 글자 너비/높이·공용 노드·입력 영역 검사.
- `large-font-verify_wide_workshop_motion.log`: 확대 상태판과 제조/판매/FIFO 병 동선이 겹치지 않음.
- `large-font-verify_toolbar_spacing.log`, `large-font-verify_three_stage_modes.log`, `large-font-verify_currency_display.log`: 하단 간격·단계 전환과 실제 큰 골드/코인/정보 문구의 가로·세로 잘림 검사.
