# 게임 기능 정리와 다중 원정 제안

작성일: 2026-10-08

**제작 요청 반영:** 사용자가 이 기능을 제작하고 개발에 구현·Computer Use 전체 테스트를 요청했다. 구체 개발 범위·지역별 출발비·보상·자동 대기·저장 이전·검사 기준은 [다중 원정 구현과 전체 테스트 명세](다중-원정-구현과-전체-테스트-명세.md)를 따른다. 아래의 금액 미정·세부 제안 표는 기능을 논의한 초기 기록이며 해당 명세의 개발 초기값이 우선한다. 32물약·11재료·8지역·125투자·4직원을 이번 연결 범위로 채택했고 꾸미기·단골·4탭·새 미니 화면은 별도다.

자동으로 물약을 만들고 팔아 얻은 골드로 레시피·설비·직원·지역을 늘린다. **2026-10-08 확정 변경: 여러 해금 지역에 원정을 동시에 보내며, 해금 후 회차 출발비를 자동 결제하고 반복한다.** 비용 부족 시 해당 원정은 대기하고 충분해지면 자동 재개한다. 기존 가게의 자동 운영도 유지한다. 지역별 비용·보상·영구 개방비와의 관계, 재출발 우선순위와 완료 지역의 보관 대기는 세부 제안이다.

## 여러 원정과 지역 개방

**제안: 한 지역에 원정 하나, 해금한 지역끼리는 동시에 진행한다.** 8지역을 해금했다면 최대 8지역 원정을 함께 운영할 수 있다. 같은 지역에 여러 팀을 중복 투입하거나 손님 4종을 필수 원정 파티로 배정하지 않는다. 별도 팀 슬롯 구매와 필수 직원 고용도 이번 안에 추가하지 않는다. 원정 길잡이는 효율을 높이는 직원으로 둔다.

기존 단일 원정의 목적지를 교체하는 구조는 지역마다 독립 상태를 가진 구조로 바뀐다. 각 지역의 탐색·귀환·누적 조사·재출발 대기·미입고 보상을 각각 기록한다. 이미 출발한 회차는 가게의 다른 투자나 다른 지역 출발로 초기화하지 않는다.

다음 지역은 이전 지역 조사 완료 후 접근한다. 완료한 옛 지역은 재료 보충을 계속하고 신규 지역은 발견을 진행한다. 이 조건을 유지하면 여러 지역이 동시에 운영되어도 새 지역의 조사 순서는 유지된다. 기존 지역 동시 운영만으로 최종 지역 조사가 8배 빨라지는 것은 아니다. 중간 발견부터 다음 지역을 열거나 같은 지역에 여러 팀을 보내려면 별도 성장 시간 계산이 필요하다.

## 출발 비용과 반복 방식

**확정: 최초 지역 해금 후 자동 출발·자동 재출발하며 회차 출발비를 자동 결제한다.** 매회 직접 보내기와 보상 수령은 요구하지 않는다. 지역별 금액·예비금·재출발 우선순위·보관 대기 조건은 아래 세부 제안으로 구분한다.

| 상황 | 기본 제안의 동작 |
| --- | --- |
| 지역 해금, 출발비 충분 | 해당 지역의 첫 원정 자동 출발 |
| 탐색 시작 | 회차 출발비를 한 번 차감, 시간·보상 조건 고정 |
| 탐색과 귀환 | 다른 지역 원정·물약 가게와 동시에 자동 진행 |
| 귀환 | 조사 기록·발견·재료를 자동 반영, 보상 수령 클릭 없음 |
| 재출발비 충분 | 해당 지역 다음 회차 자동 출발 |
| 출발비 부족 | 해당 지역은 비용 대기, 가게와 다른 출발 가능한 원정은 진행 |
| 골드가 다시 충분해짐 | 대기 원정 자동 출발, 별도 재개 버튼 없음 |
| 조사 완료 지역의 보상 재료가 모두 가득 참 | 다음 재료 원정은 대기하여 반복 지출 낭비 방지 |
| 조사 미완료 지역의 재료가 가득 참 | 조사·발견은 계속 진행, 재료 입고와 조사 분리 |

출발비는 귀환 시 다시 차감하지 않는다. 저장·재실행·결과 재열기·날씨 변경으로 같은 회차를 다시 결제하거나 보상을 두 번 지급하지 않는다. 이미 비용을 낸 진행 중 원정은 골드 부족이나 보관량 변화로 취소하지 않는다. 보관을 초과한 귀환 재료는 종류별 대기 수량으로 보존한다.

**지역 접근 조건, 영구 개방비, 회차 출발비를 구분한다.** 기존 1회 개방 구매에 출발비를 추가할지, 개방비를 낮추거나 조건 해금으로 바꿀지는 검토 항목이다. 현재 숲 400 G 개방비를 반복 출발비로 재사용하지 않는다. 가격표의 기존 지역 금액은 영구 개방비 후보이며 회차 비용이 아니다.

지역을 살 때 첫 출발비가 별도라면 구매 화면에 함께 안내하고, 돈이 부족해 출발이 대기하는 상태도 설명한다. 기본 재료 자동 구매를 보호하는 예비금을 남긴다. 예비금과 지역별 출발비 금액은 추가 경제 계산 후 정한다.

동시 재출발 시 조사 중인 미완료 지역을 우선하고, 같은 우선순위에서는 오래 대기한 원정을 우선하는 규칙을 검토한다. 값싼 옛 지역이 계속 돈을 써서 새로운 지역이 영구 대기하는 상황은 검증 대상이다. 사용자에게 원정별 예산·대기 우선순위 설정을 필수 조작으로 요구하지 않는다.

## 돈을 쓰는 곳

| 지출 | 얻는 것 | 지출 방식 |
| --- | --- | --- |
| 자동 재료 구매 | 기본 생산용 재료 | 기존 반복 운영비 |
| 원정 출발 | 발견 진행·원정 재료 | 새 반복 운영비 제안 |
| 레시피 구매 | 영구 제작 가능 품목 | 1회 구매 |
| 설비·계열 강화 | 영구 속도·품질·보관·가치 개선 | 단계별 투자 |
| 직원 고용·훈련 | 영구 자동 운영 효과 | 고용·단계별 투자 |
| 지역 개방 | 새로운 조사·보상 접근 | 기존 1회 구매 유지 여부 검토 |
| 꾸미기 | 외형과 수집 | 후속 1회 구매 제안 |

원정 재료는 그 회차의 비용을 쓰는 이유가 있어야 한다. 자동 재배가 이미 충분한 품종만 계속 가져오는 원정은 보관 대기로 지출을 줄이고, 첫 발견·희소 표본·추가 재료의 가치는 보상표에서 검토한다. 재료 원정과 영구 공급 설비 중 무엇이 현재 부족을 해결하는지 구분한다.

## 원정 화면과 복귀 결과

작업실은 **지도 아이콘 + 진행 중 원정 수**로 요약한다. 각 원정 상태판을 작업실에 여러 개 띄우거나 여러 원정의 평균 진행률을 하나의 게이지로 표시하지 않는다. 남은 시간을 표시한다면 가장 가까운 귀환까지의 시간이라는 뜻을 함께 명확히 한다. 새 발견에만 작은 표시를 남기고 일반 귀환마다 팝업을 띄우지 않는다.

원정 탭의 각 지역 카드는 아이콘·이름, 이번 보상, 회차 출발비, 진행 또는 대기 이유를 우선 표시한다. 조사 목표·다음 발견·상세 계산은 펼치면 보인다. 여러 원정의 카드 순서는 진행할 때마다 바꾸지 않고 지역 순서를 유지한다. 다음 해금 지역과 조사 완료 목록은 별도 구역에서 접을 수 있다.

복귀 결과는 지역별 귀환 횟수·획득 재료·발견과 **원정 출발비 합계**를 묶는다. 순영업수입은 물약 매출에서 자동 재료 구매비와 원정 출발비를 뺀 값으로 정의한다. 영구 투자 지출은 별도로 보여줘 운영 적자와 설비 구매를 혼동하지 않게 한다. 결과를 열어야 보상을 받는 구조는 추가하지 않는다.

## 정할 항목과 개발 순서

| 결정 | 현재 검토안 |
| --- | --- |
| 동시 원정 범위 | 해금 지역마다 1개, 서로 동시 진행 |
| 반복 조작 | 자동 출발비 결제·반복 확정, 매회 보내기·수령 조작 없음 |
| 영구 개방비 | 유지·축소·조건 해금 중 선택 전 |
| 출발비와 보상 가치 | 지역별 금액 미정, 원정 자체의 새 소모품은 추가하지 않음 |
| 예비금과 재출발 우선순위 | 기본 구매 보호, 미완료 조사 우선 제안 |
| 완료 지역 반복 | 재료 보관 여유가 있을 때 자동 반복 제안 |

동시 진행·자동 반복·회차 자동 결제 방향은 확정했다. 다음은 출발비·보상·보관 대기를 반영한 경제 계산이다. 그 뒤 지역별 상태·지출 장부·저장 이전·UI를 개발에 전달한다. 진행·보상·출발비의 중복 방지, 동시 귀환, 낮은 골드, 보관 가득 참, 기존 숲 저장 이행을 검증한다.

기존 저장의 진행 중 숲 원정은 추가 비용 없이 해당 회차를 마치고, 다음 출발부터 새 비용 규칙을 적용한다. 과거 귀환 횟수에 비용을 소급 청구하지 않는다. 지역 보유·진행·조사·미입고 보상과 골드는 보존한다.

**기존 후보 C의 4시간대 레시피 완성·6시간대 투자 완료 계산은 단일 원정·회차 비용 없는 모델 결과다.** 새 구조의 완료 시간이나 순수익으로 재사용하지 않는다. 판매대와 조제 훈련의 후보 수치는 출발점으로 유지하되 원정 재료 증가와 반복 비용을 포함해 다시 확인한다. 이번 정리는 확정 기능과 세부 제안을 구분한 기획이며 게임 코드·저장·현재 개발 적용 범위는 아직 변경하지 않았다.
