## 클릭과 이동 좌표

540 기준 입력 예외는 약초 **[100,224,18,18]**, 포션 **[132,114,18,18]**, 원정 **[504,84,18,18]** 세 개다. 520/560에서는 중앙/오른쪽 버튼도 해당 사물과 같이 이동하며 정확한 값은 layouts 배열에 있다. 그림 전체는 클릭 통과, 세 버튼만 기존 관리 탭을 연다.

하단 이동 [4,254,28,28], 원정 [212,254,44,28]은 그대로다. 골드/시간/날씨도 기존 x 좌표·표시 크기·Pretendard를 유지했다. 오른쪽 관리/축소/확대/종료는 x=폭−142, 폭−96, 폭−64, 폭−32이며 4px 간격이다. 본 모드 확대 슬롯의 비활성 상태도 보존한다. 새 페이지·설정·수령 버튼은 없다.

손님 발 y=245, 구매 x=폭−48, 화면 밖 x=폭+56. 따라서 전체 96px 캐릭터의 왼쪽도 화면 오른쪽보다 8px 밖에 있어 완전히 퇴장한다. 기존 464를 그대로 쓰지 않는다. 손 끝은 기존 +23,−46 오프셋으로 540 기준 [515,199]. 실제 이동 중에는 현재 customer x와 같은 오프셋을 사용한다.

솥 병 출발은 [188,160], 선반 중심은 첫 줄 [338,57],[362,57],[386,57],[410,57], 둘째 줄 y=91이다. reserve는 [422,151]. 기존 병 20×28과 실제 재고 순서를 유지한다. 솥→실제 자리→손 연결 끝점을 제공했으며 **실제 이동 곡선·가림 순서·동시 입퇴장 애니메이션 회귀는 개발 연결 시 검증해야 한다**. 프리뷰의 안내선은 경로 끝점을 잇는 검수 표식이며 확정된 비행 곡선이 아니다.

모드 전환은 기존 window_mode_layout의 우측 변·하단 바 중앙 기준을 재사용한다. 256×160과 320×112는 변경하지 않는다.

## 상태·액체·조명

일곱 예시: 낮/맑음 제조, 밤/비 제조, 보관 가득, 일부 작업 대기, 대표만 대기+다른 작업 진행, 전체 활동(10종/8곳), 활동 0개. 예시 골드는 25,908이다. 어떤 값도 실제 저장에서 읽거나 쓰지 않았다.

약초 herb/원정 forest_edge는 모든 예시에서 고정이다. N은 실제 활동 수를 가정한 fixture이고 해금 총수·숨긴 개수가 아니다. 0은 재배 대기/원정 대기로 표시한다. 대표 대기 때 기존 진행과 성장 프레임을 유지하고 별도로 이유를 보여준다. 제조는 단일 현재 배치만 표시한다.

액체는 이미 구현된 potion_visual.gd의 151픽셀 LIQUID_RUNS를 재사용한다. 새 원본/마스크가 필요하지 않다. 브라우저 CPU 비교에서 health→mana 변경은 정확히 151픽셀이며 마스크 외부 RGB/알파 변경은 0이다. 처음의 외부 1픽셀 차이는 브라우저 CPU/GPU 캔버스 변환의 반올림으로, CPU 경로와 마스크 영역 갱신으로 제거했다. 런타임 파일은 수정하지 않았다.

조명은 기존 픽셀 감쇠·불/물약 발광·단계형 halo를 CPU로 근사했다. 실제 게임에서는 기존 셰이더를 유지한다. 프리뷰는 실제 Godot 셰이더 검증 결과가 아니다. 포스터 활동 수/상태는 조명 처리 **이후** #281f33 바탕에 #efc77c로 그리며 낮밤 같은 대비(9.84:1)를 유지한다. 상태·게이지·버튼은 소품에 구워 넣지 않는다.

## 검수 결과와 남은 확인

- 신규 원본 네 개와 논리 파생 네 개 모두 실제 알파 투명 픽셀 확인. 논리 PNG 크기와 manifest 일치.
- 모든 개별 장면 알파 유지 및 1배/2배 크기 확인.
- 520/540/560 모두 세 상세 버튼 화면 내·상호 비겹침, 캐릭터 96×128 유지, 하단 버튼 간격 [4,4,4], 손님 화면 밖 기준 통과.
- Pretendard 로드 확인. 10px 기준 최대 약초 문구 49.93px, 원정 문구 45.65px로 각각 영역 안에 들어감.
- 액체 maskSize=151, changed=151, outsideChanged=0, alphaChanged=0.
- headless 브라우저 오류 0. 최종 1배·2배와 상태 보드를 시각 검수했고, 비교 보드 오른쪽 잘림도 수정했다.

게임·에디터·Computer Use·화면 입력·포커스 변경·창 이동·실제 저장 접근은 하지 않았다. 실제 클릭 통과, 모드 전환, 움직이는 병/손님, Godot 광원과 환경 연결은 아직 실행 검증하지 않았다. 분리 파일·좌표를 기획이 검수한 뒤 개발에 적용할 단계다. 디자인 담당은 개발 채팅에 지시하지 않았다.

재생성 순서: output 폴더에서 `node build-preview.cjs` → `node render-preview.cjs` → `node finalize-handoff.cjs`. render는 별도의 임시 프로필을 쓰는 headless Edge다. 새 소품 원본/기존 에셋/런타임은 덮어쓰지 않는다.
