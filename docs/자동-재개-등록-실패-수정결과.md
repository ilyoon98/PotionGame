# 자동 재개 등록 실패 수정 결과

2026-10-12 · **코드 수정·현재 사용자 등록 복구 완료 / 실제 재부팅 미실시**

사용자가 컴퓨터를 켠 뒤 게임이 자동으로 열리지 않았다고 보고했다. 읽기 진단에서 현재 사용자의 `MoonshadePotionShop` Run 항목과 `login_resume.json`이 없음을 확인했다. 등록이 시도됐던 시각의 오류 기록은 없어 이번 부팅의 전체 과정을 재현했다고 단정하지 않는다.

등록 코드에는 실제로 실패하는 버그가 있었다. 약 12KB 로그인 도우미를 JSON/Base64로 넣고 다시 PowerShell UTF-16 Base64 명령으로 감싸면서 등록용 명령이 약 51,800자가 됐다. Windows CreateProcessW의 32,767자 한도를 넘으며, Run 값 자체의 260자 검사만으로는 이 문제를 잡지 못했다. 또한 Godot Windows `OS.execute`의 ACP 출력 디코딩 때문에 PowerShell UTF-8 응답의 한글 경로가 손상되는 문제를 실제 전달 검사에서 확인했다.

- 큰 요청은 PID/인스턴스/시각으로 구분한 완성된 UTF-8 JSON 파일로 전달한다. 명령에는 요청 파일 경로만 넣는다.
- 실제 생성 명령에 길이 검사를 적용하고 요청 파일 저장·게시·PowerShell 실패 원인을 구분한다. 처리가 끝나거나 실행에 실패하면 해당 요청만 정리한다.
- 응답은 ASCII Base64 봉투로 전달하고 GDScript에서 UTF-8 JSON으로 복원하여 내부 `ok`와 경로·오류를 확인한다.
- 등록 경로 경고를 일반 “켜짐”으로 덮던 관리 표시도 수정했다.
- 기존 로그인 도우미 원문·게임 실행 인수·명시적 설정 정책·headless/격리 검사 보호는 유지한다.

기존 가짜 등록 검사와 로그인 실행기 dry-run은 큰 설치 payload를 실제 프로세스에 전달하지 않아 이번 결함을 놓쳤다. 현재 검사는 생산 코드와 같은 인수 생성기로 전체 요청을 실제 PowerShell에 넘겨 한글·원문·배열·오류·정리까지 확인한다.

## 현재 PC 복구와 검사

사용자의 자동 재개 요청에 따라 이 게임의 현재 사용자 Run 값·도우미·별도 로그인 설정만 복구했다. 다른 시작 항목·StartupApproved·게임 진행 저장은 변경하지 않았고 게임을 실행하거나 컴퓨터를 재부팅하지 않았다. 기존 설정이 생기면 덮어쓰지 않도록 했다.

실제 복구 명령은 **7,118자**, Run 명령은 **217자**다. 등록 조회가 정확한 현재 경로와 일치하며 설치된 도우미 원문도 확인했다. 새 설정은 `enabled=true, was_running=false`다. 불명확한 과거 게임 실행을 추정하지 않는다. **수정된 게임을 한 번 다시 실행해 두어야** 실행 중 표시가 기록되어 다음 로그인부터 조건에 맞게 재개된다. 게임을 직접 종료하면 다시 열지 않는 정책은 유지한다.

작업 공간 루트 `.verification/`의 근거:

- `windows-startup-transport-final.log`: 30개 실행기 dry-run + 5개 실제 PowerShell 전달/파싱 probe PASS. 명령 한도·전체 한글 payload 왕복·완성 파일·정리·오류·격리 보호 확인.
- `login-warning-controller.log`: 경로 경고/정상/등록 없음과 실제 관리 표시·종료/설정 실패·경제/RNG 불변 PASS.
- 프로젝트 `.verification/startup-repair-20261012/repair-result.json`: 실제 등록·설정·도우미 읽기 검증 완료.
- 프로젝트 `.verification/startup-repair-20261012/verification.json`: 실제 등록 조회, 설치된 도우미의 닫힌 상태 건너뛰기와 실행 중 fixture의 준비 여부 PASS. `-DryRun`으로 검사하여 게임을 실행하지 않았고 실제 설정은 유지됐다.

실제 PC 로그오프·재부팅 시나리오는 사용자 확인이 남는다. Windows 세션 종료가 수동 닫기 신호를 반드시 발생시킨다고 단정하지 않으며, 이번 수정은 확인된 등록/전달 문제에 한정한다.
