# 달그늘 물약상점 성장과 골드 사용처

> 판매 재고 보호와 작업실 운영 확장 · 2026-10-20 · **F20 기획 확정·개발 반영 요청·구현/검수 전**: 재고 보호를 무료 기본 운영으로 먼저 적용한다. 기존 성장을 마치고 확장하면 메인 솥은 판매용·보조 조제대는 납품용으로 동시 제작하며 기존 일괄 조제 효과를 이어받는다. 초기 검증 비용은 확장300만 G(기본 보조 조제대 포함), 개선150만/300만 G이다. 저축 구간·효과·저장 이관을 측정한 뒤 최종 수치를 검수한다. [최신 F20 제작 명세](판매-재고-보호와-작업실-운영-확장-명세.md).

2026-10-19 **F19 구현·격리 검사·기획 검수 완료**: 흥정 훈련은 미래 기회가 있을 때만 구매·추천하며 기존 가격을 유지한다. 후반 투자는 각15만/30만/45만 G, 두 갈래 총180만 G으로 적용·검수했다. 기존 성장 완료와 거래2/3/4등급 조건은 유지한다. [최신 명세](후반-투자와-흥정-훈련-개선-명세.md) · [가격 비교와 검수](후반-투자와-흥정-훈련-개선-기획검수.md).

작성 기준일: 2026년 10월 7일 · 상태: 현재 기반과 후속 기획 안내

2026-10-15 후반 수주 첫 버전 구현·격리 검수 완료: 첫 계약·거래 등급 상승 때의 흥정 성패, 3거래처 자동 납품과 **흥정 성공률 훈련**을 연결했다. 가구·직원의 훈련 3단계는 개발용 초기 가격 8,000/20,000/50,000 골드로 일반 성공률 60→70→80→90%를 올린다. 최종 등급 협의 100%는 별도 보장이다. [개발 결과](조건-흥정과-자동-납품-개발결과.md)의 실제 수치·검사와 제한을 따르며 최종 밸런스 승인이나 실제 Windows 조작 완료를 뜻하지 않는다.

2026-10-08 장기 콘텐츠 확대 방향을 반영했다. **물약·레시피 32종, 원정 8지역, 재료 11종, 투자·강화·훈련 125회**와 2시간 이후 성장 목표는 [장기 콘텐츠 확장안](장기-콘텐츠-확장-기획안.md)을 우선 검토한다. 아래 초기 후속표의 3지역·신규 3물약은 전체 규모의 최종안이 아니다. 개별 콘텐츠·수치는 제안이다.

**자동 영업으로 번 골드로 품목·설비·직원·지역·외형을 늘린다.** 플레이어가 한 번 선택한 뒤의 재배·제작·판매·활성 원정은 계속 자동으로 진행된다.

명성·단골 기록·발견 진척은 소비성 재화가 아니다. 투자란 가게 설비와 탐색 지역의 영구 확장을 뜻하며 예금·이자·주식 같은 금융 시스템은 포함하지 않는다.

반복 원정 보급비·직원 급여·피로 관리·수동 보상 수령·연구 타이머는 현재 후속안에 넣지 않는다. 꾸미기를 사지 않아도 운영에 불이익이 없고, 보유 장식의 교체에는 비용이 없다.

## 각 성장의 역할

| 성장 | 쌓이는 계기 | 여는 것 | 플레이어의 선택 |
| --- | --- | --- | --- |
| 골드 | 자동 판매에서 재료비 등을 뺀 영업 성과 | 구매·강화 여력 | 무엇을 살지 선택 |
| 명성 | 실제 일반·선호 거래 | 가게 전체의 구매 조건 | 열린 상품을 골드로 구매 |
| 단골 기록 | 손님별 실제 구매 | 이야기·기념품 | 확인·무료 장착 |
| 원정 발견 | 지역별 누적 귀환 | 새 재배·레시피 구매 후보 | 레시피·다음 지역 구매 |
| 소장품 | 직접 구매·단골·발견 | 가게 외형 선택 | 원하는 소품 장착 |

손님은 여행자·여마법사·엘프·고양이 도적 4종을 유지한다. 기존 손님을 고용 대상으로 바꾸거나, 명성과 단골을 동일한 잠금 조건으로 중복 사용하지 않는다.

## 후속 순서

1. 숲의 첫 발견과 이슬풀·활력 물약으로 원정에서 가게 생산까지의 연결을 검토한다.
2. 영업 결과의 주요 변화, 판매대 강화와 작은 소품 소비를 연결한다.
3. 네 손님의 단골 기록·기념품과 판매 보조 훈련을 추가 검토한다.
4. 온실·집중 물약과 재배 보조를 다음 콘텐츠로 다듬는다.
5. 유적·야행 물약·모자 등 상위 외형을 장기 후보로 남긴다.

각 단계는 후속 제안이며 한꺼번에 구현하라는 지시가 아니다. 가격과 획득 시점은 실제 운영에서 첫 구매 시점·순수익·재료 부족·진열 가득 시간을 확인한 뒤 확정한다. 현재 개발값과 제안 가격을 혼합해 확정 밸런스라고 표시하지 않는다.
