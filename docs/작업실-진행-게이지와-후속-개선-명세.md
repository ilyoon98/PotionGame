## 작업실 게이지

| 위치 | 초기 표시 | 실제 연결 |

| 솥 위 또는 바로 아래 | 현재 물약 아이콘과 얇은 제조 게이지 1개 | 현재 배치의 실제 제조 시간·상태. 기다릴 때 같은 자리에서 대기 표현 |
| 화분 가까운 작은 묶음 | 서로 다른 약초 그림과 각자의 게이지 최대 3개 | 품종별 실제 재배/채집 경과와 환경 효과. 공용 타이머를 복사하지 않음 |

3개·2개와 위치는 현행 408×288에서 가독성을 확인할 초기 배치다. 캐릭터·손님·진열 병·창틀·날씨·하단 버튼과 겹치지 않게 사물 주변 빈 공간에 배치한다. 기존 작업실 크기와 하단 기준점·버튼 순서를 유지한다. 크기를 늘려야 해결된다면 임의 확대하지 않고 배치 한계를 보고한다. 큰 상태판과 긴 품목별 성장 문구는 추가하지 않는다.

### 대표 항목과 대기

- 기본 약초와 먼저 해금한 재배 품종 순서로 대표 슬롯을 채운다. 원정은 열린 지역 순서다. 신규 해금으로 빈 슬롯은 채우되 수확 완료·진행률·보관 대기마다 순서를 바꾸지 않는다. 그림이 계속 바뀌는 자동 회전 표시는 사용하지 않는다.
- 화면에 없는 작업도 계속 진행한다. `+N`은 숨긴 공급원/지역 수이며 진행 중 개수로 오해시키지 않는다. 서로 다른 작업의 평균을 하나의 가짜 진행률로 합치지 않는다.
- 출발비 부족·보관 가득·재료 충분 대기에서도 대표 슬롯을 유지하고 막대 진행을 멈춘다. 짧은 대기 마커로 구분하고 정확한 이유는 관리에서 확인한다.
- 버섯은 자동 구매다. 성장 그림이 없는 버섯에 가짜 화분·재배 게이지를 만들지 않는다. 초기 재배 묶음에는 넣지 않고 실제 발주 진행은 관리에서 확인한다.
- 원정으로 재료만 보유하고 공급원은 미해금인 품종에 재배 게이지를 붙이지 않는다. 원정 해금과 자동 재배 해금은 구분한다.

### 약초 디자인 활용

`assets/content_expansion_v1/catalog.json`의 재료 아이콘은 11종, 버섯을 제외한 `growth_path`는 10종이다. `ItemArt.growth_path(id)`로 찾고 아이콘·성장 그림·실제 공급원을 같은 품종 ID로 연결한다.

승인된 대표 화분 소품을 유지하고, 가까운 작은 약초 슬롯에는 **해당 품종의 성장 그림과 게이지**를 함께 표시한다. 한 화분의 생산량을 늘리는 기능은 아니다. 실제 품종별 진행값에 따라 어린 잎→성숙→수확 그림을 사용한다. 정수 배율·최근접 필터·정확한 프레임 영역을 사용하며 원본 PNG를 수정하지 않는다. 작아서 읽히지 않으면 품종 아이콘을 우선 사용하고 관리 상세에서 성장 그림을 활용한다. 보관 가득일 때 수확 효과를 반복하거나 외형 갱신이 재료를 지급하지 않는다.

### 클릭 통과와 작은 모드

- 막대·약초·지역 그림은 입력을 받지 않아 그림 영역 클릭 통과를 보존한다. `+N`의 직접 진입은 하단의 실제 조작 가능한 영역 등 기존 입력 구조 안에서 구현한다. 하단에 공간이 없으면 숫자는 표시 전용으로 두고 관리 버튼을 통한 전체 확인을 보존한 뒤 직접 진입의 한계를 보고한다. 그림 전체를 입력 차단 영역으로 만들지 않는다.
- 밝은 문서·어두운 바탕에서도 읽히도록 작은 픽셀 받침을 사용하되 작업실 전체를 불투명하게 만들지 않는다.
- 대표 묶음은 본 작업실에 먼저 적용한다. 256×160 최소 작업실은 기존 제조 게이지·관리 진입을 유지하고 약초 3개·원정 2개를 강제로 압축하지 않는다. 320×112 정보 화면도 유지한다. 실내·작은 화면은 공간이 허용하는 사물 주변 제조/재배 표시만 적용하고 같은 실제 상태를 읽는다.

## 확인 기준

1. 솥 배치와 약초·원정 대표들이 서로 다른 실제 값으로 움직인다. 실제 해금 항목만 표시하고 대기·완료·재개 때 슬롯 위치가 유지된다.
2. 10종 성장 그림 경로·프레임과 품종 ID를 검사한다. 버섯 구매와 미해금 재배는 구분한다.
3. UI 표시·탭 진입·결과 열기 전후 제조·채집·원정 결제·보상·RNG·저장이 같다. 재실행·모드 전환에도 추가 보상이 없다.
4. 본 화면 408×288, 최소/정보 모드, 밝은/어두운 배경, 낮밤/비, 손님 구매·퇴장·병 이동에서 겹침과 하단 버튼 손실을 검사한다. 클릭 통과 구조와 하단 기준점을 보존한다.
5. 결과와 상세의 실제 진입 신호 경로를 검사한다. 약초/포션 상태 변경 시 행 높이·뒤 행 위치·스크롤·구매 대상이 안정적이다.
6. Computer Use·입력·포커스 변경·눈에 보이는 게임/에디터 실행은 금지한다. 격리된 headless 상태·레이아웃·이미지 검사를 사용하고 실제 조작은 미실시로 기록한다. 플레이어 저장은 테스트에 사용하지 않는다.
