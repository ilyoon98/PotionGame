## 플레이 느낌

평소에는 벽과 바닥이 빠진 픽셀 작업실을 작게 띄워 둔다. 마녀는 솥에서 물약을 만들고, 화분은 자라며, 진열된 물약을 손님이 사 간다. 밤에는 소품에 달빛이 내려앉고 솥의 불빛이 도드라진다. 비가 오면 작은 창틀과 작업실 주변의 픽셀 비가 분위기를 바꾼다. 방 안의 물약 가게라는 설정은 유지한다.

관리를 열면 포션·채집·원정이 각자의 속도로 움직이는 게이지 목록을 본다. 숫자와 긴 설명을 읽기 전에 어디가 바쁘고 어디가 기다리는지 알아볼 수 있어야 한다. 성장 추천에서 다음 투자를 한 번 선택하고 다시 작업실만 남긴다.

성장의 재미는 새로운 생산 품목과 원정이 늘어나는 데 있다. 솥을 강화하면 물약이 쌓이기 쉬워지고, 판매를 강화하면 손님이 기다리는 구간이 생긴다. 상황에 맞는 투자로 이 균형을 바꾸고 다음 발견을 기다린다. 특별 레시피는 그 흐름에 드문 수집의 즐거움을 더한다.

| 자동으로 이어지는 일 | 플레이어가 선택하는 일 |

| 해금한 재료 공급과 레시피의 자동 운영 합류 | 원정 지역의 최초 해금 |

기본 순환은 **재료 조달 → 제조 → 판매 → 골드와 명성 획득 → 직접 성장 투자 → 자동 운영 확장**이다. 원정은 이 순환과 동시에 진행되어 재료와 새 레시피의 발견 기회를 제공한다. 기본 영업에는 자동 켜기·끄기나 매회 제조·출발·수령 버튼을 요구하지 않는다.

구매·강화·고용은 선택했을 때만 결제한다. 명성은 해금 조건으로 사용하며 소비 재화로 바꾸지 않는다. 원정 최초 해금 비용과 매회 출발비는 구분한다. 자금이 부족하면 해당 원정이 기다리고 기본 가게 운영은 계속한다.

축소는 본 → 최소 → 정보, 확대는 정보 → 최소 → 본 순서다. 공통 하단 조작은 `이동 / 관리 / 축소 / 확대 / 종료`다. 축소·확대할 때 오른쪽 하단 조작 위치를 기준으로 그림 영역이 줄거나 펼쳐진다. 항상 위를 유지하고 화면 단계 변경·관리 닫기로 진행을 멈추거나 초기화하지 않는다.

사물 사이 빈 공간은 투명하고 작업실의 그림 영역은 뒤 프로그램으로 클릭을 전달한다. 하단 버튼과 관리 패널은 조작 가능해야 한다. 실제 배율·연속 이동·클릭 통과 조합의 최종 조작 검증은 남아 있다.

### 작업실 대표 게이지와 제작 대기 확정

작업실에는 솥·약초·원정 게이지를 하나씩 표시한다. 솥은 실제 현재 제조 물약을 따라 아이콘과 내부 색상이 바뀐다. 약초는 기본 약초, 원정은 첫 지역으로 대표를 고정하고 실제 전체 진행 수를 `N종 재배 중`, `N곳 탐사 중`으로 표시한다. 대표가 기다려도 다른 항목으로 교체하지 않는다. 제조는 한 종류씩 진행하므로 `N종 제작 중`이라고 표시하지 않는다.

게이지는 해당 약초의 한 수확 주기, 현재 물약의 한 제조 배치, 해당 지역의 한 원정 회차 진행도다. 전체 평균·해금 수·재고량이 아니다. 약초 성장 그림은 같은 진행도를 사용하고 날씨·투자 효과는 실제 성장 속도를 따른다. 실제 정지 상태에서 막대를 장식용으로 반복하지 않는다.

전시 병 그림이 가득 보이는 것과 실제 보관 한도 도달은 별개다. 실제 물약 보관이 가득 차면 다음 제작이 기다리고, 진행 중 배치가 정지했다면 경과를 유지한다. 솥은 마지막 물약 색상과 아이콘을 유지하고 `보관 가득`을 표시한다. 판매로 공간이 생기면 기존 조건에 따라 자동 재개한다. 약초와 원정은 각자의 조건대로 움직이거나 기다린다.

작은 진입 버튼으로 기존 해당 관리 탭을 연다. 약초 관리에는 각 품종의 성장 그림과 실제 게이지를 유지하고, 작업실의 대표 자리 수는 콘텐츠가 늘어도 늘리지 않는다. 그림 영역 클릭 통과·공통 하단 조작·작은 모드를 보존한다. [작업실 대표 게이지와 제작 대기](작업실-대표-게이지와-제작-대기-명세.md)의 확정 기능과 [540 작업실 연결](작업실-확장과-단일실행-적용결과.md)은 구현/격리 검사 완료다. 실제 클릭·드래그·GPU 조명 검증은 남는다.

충분히 해금된 운영 첫 화면에서는 포션·채집·원정 세 구역과 실제 작업 막대 6개 이상을 함께 보는 것을 목표로 한다. 게이지는 부드럽게 갱신하고 대기 이유는 `재료 부족`, `보관 가득`, `출발비 부족`처럼 짧게 남긴다. 제조·판매 행 높이와 목록 순서는 상태 변경으로 흔들리지 않게 한다.

현재 제조는 한 번에 한 배치다. 여러 공급원과 여러 지역 원정은 병렬로 움직이지만, 제조 중이 아닌 포션에 같은 타이머를 복제하지 않는다. 포션별 병렬 제작은 별도 설계가 필요한 제안이다.

## 낮밤 날씨와 손님

게임 속 하루는 4분, 날씨는 90초마다 바뀐다. 낮밤과 맑음·흐림·비는 독립적으로 조합된다. 현실 시간이나 지역 날씨를 연결하지 않는다.

| 환경의 역할 | 화면과 게임 반영 |
| --- | --- |
| 분위기 | 해·달·구름·비, 사물의 색감과 국소 픽셀 조명 |
| 약초 공급 | 해당 품종의 실제 성장 속도에 영향 |
| 물약 제조 | 해당 레시피의 실제 성공률에 영향 |
| 손님 | 캐릭터별 출현 비중에 영향 |
| 관리 표시 | 영향을 받는 약초·포션 행만 하이라이트 |

작업실 밖에 `달꽃 성장` 같은 품목별 문구는 나열하지 않는다. 바탕화면 전체를 어둡게 하거나 불투명 하늘 배경을 덧씌우지 않는다. 비와 조명은 게임 영역 안에서 사물·버튼을 읽기 쉽게 유지한다.

손님은 **여행자·여마법사·엘프·고양이 도적 4종**이다. 여기사는 현재 제외한다. 시간·날씨에 따라 방문 경향이 달라지고 각자의 선호 물약이 있으면 자동 우선 구매한다. 선호품이 없을 때도 일반 판매가 이어져야 한다.

## 레시피 원정과 보상

일반 레시피는 지역 조사·명성·선행 레시피 조건을 충족하면 1회 구매한다. 구매 후 재료가 준비되면 자동 제조에 합류하고 부족하면 만들 수 있는 기존 물약으로 이어간다. 별도 연구 대기 시간과 수동 조합을 추가하지 않는다.

원정은 숲 가장자리 → 버려진 온실 → 물안개 계곡 → 수정 광산 → 안개 늪 → 잊힌 탑 → 달빛 유적 → 별의 정원으로 확장한다. 여러 해금 지역이 동시에 진행되며 각 지역은 회차마다 출발비를 자동 결제한다. 조사·보관·예비금 규칙에 따라 필요한 지역이 대기하거나 재개한다.

| 화면 표현 | 의미 |
| --- | --- |
| 원정 열기 | 지역을 처음 영구 해금하는 구매 |
| 탐색 중 | 해당 지역에서 재료와 발견물을 찾는 단계 |
| 재료 가져오는 중 | 탐색 후 가게로 돌아오는 단계 |
| 조사 진행 3/6회 | 조사 목표까지 완료한 원정 횟수의 예시 |
| 재료 보관 대기 | 완료 보상 중 아직 보관하지 못한 재료가 있음 |

잠긴 원정 버튼에는 `이전 지역 조사 완료 필요`, `명성 N 필요`, `N G 부족`처럼 실제 부족 조건을 표시한다. 조건이 충족되면 `원정 열기 · 비용`, 이미 해금했다면 `열림`으로 표시한다.

### 랜덤 재료 보상

**지역별 보상 풀에서 여러 재료와 각각의 수량을 가져오는 방향은 확정이다.** 주재료 1종 보장 + 보조 재료 1~2종, 총 2~3종 구성은 초기안이다. 구체적인 풀·수량·가중치는 [보상 명세](원정-랜덤-보상풀과-특별-레시피.md)를 따른다.

원정 결과는 `[해당 아이콘] 이슬풀 ×3`, `[해당 아이콘] 별잎 ×2`처럼 실제 가져온 각 항목을 표시한다. 재료마다 아이콘을 붙이고 좁으면 줄바꿈한다. 가능한 보상 후보와 실제 완료 결과를 구분하며 별도 수령 버튼은 두지 않는다.

추첨은 회차 출발 시 한 번 저장하고 완료 때 공개·반영하는 초기 설계다. 화면 갱신·날씨 변화·재실행으로 다시 뽑지 않는다. 보관 초과 결과는 삭제하지 않는다. 현재 고정 보상 기준의 공급량·창고·반복 판단과 경제는 랜덤 구조에 맞춰 다시 검증한다.

### 특별 레시피

**낮은 확률로 특별 레시피를 발견하는 방향은 확정이다.** 일반 레시피와 다음 지역의 필수 진행은 확률 보상에 의존하지 않는다. 이미 발견한 특별 레시피는 다시 뽑지 않는 안이다.

디자인 제작 후보는 숲숨결 물약·물안개 물약·월광봉인 물약·성운 증류액 4종이다. 각 후보의 레시피 아이콘·포션 아이콘·작은 진열 병 총 12개 PNG는 제작·검증 완료했고, 원정 예상 결과에 특별 레시피 아이콘을 `추가 예정`으로 연결했다. 이름·배합·판매가·제조 시간·실제 획득과 자동 제조 연결은 아직 확정되지 않았다. [제작 요청서](특별-레시피와-포션-디자인-제작요청.md)에 범위를 정리했다.

사용자가 **발견 후 골드로1회 구매하고 자동 제작에 합류**하는 방식을 확정했다. 발견 전에는 지역의 공용 지도?로 존재를 알리고 실제 이름·그림·배합을 숨기며 발견 뒤 공개한다. 완료당3%와30번째 유효 완료 보장은 조정 가능한 개발용 초기값으로 검증한다. 재료가 충분하여 일반 원정이 쉬면 미발견 목적의 유료 특별 탐색으로 전환하고 그 회차는 일반 재료를 추가 지급하지 않는다. 출발 때 회차 종류를 저장하며 발견 후 특별 탐색을 멈춘다. [최신 제작 기준](특별-발견과-배합-효과-표시-명세.md)을 따른다.

## 성장 속도와 생산 판매 균형

**20분 만에 끝나는 게임을 피하고 2시간 이후에도 새 목표가 남아야 한다.** 주요 콘텐츠 3~5시간, 전체 성장·수집 5~8시간은 조정 목표다. 초기에는 기본 영업과 첫 투자, 중반에는 레시피·원정·직원 확장, 후반에는 여러 계열의 투자와 발견·수집을 이어가는 흐름을 지향한다.

재고가 쌓이는 구간과 손님이 기다리는 구간이 강화·새 레시피·환경 변화에 따라 바뀌어야 한다. 생산만 빨라져 장기 적체가 고착되지 않도록 판매·보관·소비와 함께 검토한다. [현재 고정 보상의 실제 엔진 측정](다중-원정-구현과-전체-테스트-결과.md)에서는 9개 경로 모두 120분에 전체 성장이 끝나지 않았지만 긴 재고 적체 구간도 남았다. 이 결과가 새 랜덤 보상의 균형까지 검증한 것은 아니다.

새 보상 적용 뒤에는 30·60·120분과 8시간 기준으로 새 콘텐츠 도달, 재료 대기, 재고 적체, 손님 대기, 원정 지출과 순수입을 비교한다. 수량·판매가·제조 시간·강화 효과를 한쪽만 늘리지 않는다.

## 후반 수주 확정

거래처의 첫 계약과 거래 등급 상승 때만 **조건 흥정**을 한다. 합의한 조건으로 납품 회차를 자동 반복하고 제작·출고·정산을 매번 직접 누르지 않는다. 등급 상승 협의를 미뤄도 기존 계약은 계속되며 새 조건은 진행 중 회차를 완료한 뒤 다음 회차부터 적용한다.

**흥정에는 성공·실패가 있고 훈련으로 성공률을 높인다.** 개선 조건 요청에 성공하면 더 유리한 조건으로 계약할 수 있다. 실패하면 첫 계약의 기본 제안을 수락하거나 기존 계약을 유지할 수 있다. 시도 전 실제 확률을 보여주고 결과는 저장하며 강화·재접속으로 이미 나온 결과를 다시 뽑지 않는다. 첫 버전은 일반 60%·훈련 3단계의 상한 90%·최종 등급 100% 보장과 기회당 1회 판정을 개발 초기값으로 구현·검사했다.

납품은 완성한 병을 분할 출고하므로 주문 전체를 창고에 동시에 모을 필요가 없다. F18 기본은1배치1병이며 F19 납품 일괄 조제를 구매하면 같은 배치에서 최대2/3/4병을 실제 재료만큼 제조한다. 기존 한 솥과 일반4배치 대 납품1배치를 유지하고, 일반 영업과의 경제 비교를 수행한다. 투명 작업실의 크기는 늘리지 않는다.

첫 버전은 별의 정원 최초 개방, 거래처 3곳·4등급, 기본/대금/거래 관계 조건과 흥정 훈련으로 연결했다. 계열별 분할 출고와 완료 일괄 정산, 물량 기반 실적·승급·다음 회차 적용·저장 이전을 검사했다. 수입 비교 후 조정한 배율과 경제 수치는 개발 검증용 초기값이다. 재료 보상·장식·특별품 납품은 후속 제안으로 남긴다. **F18 첫 버전은 구현·격리 검사·파일 검수 완료이며 실제 Windows 조작은 미검증이다.** [제작 명세](조건-흥정과-자동-납품-제작명세.md) · [개발 결과](조건-흥정과-자동-납품-개발결과.md).

## 확정 후반 투자

기존 일반32종·8지역 조사·기존16갈래125단계·4직원 성장을 마치면, 거래처 중 한 곳의2/3/4등급에 맞춰 각 투자의1/2/3단계를 구매한다. 특별4종 수집과 흥정 훈련 완료는 요구하지 않는다.

| 투자 | 1/2/3단계 초기 비용 | 구매 후 자동 효과 |
| --- | --- | --- |
| 흥정 훈련 | 8천/2만/5만 G 유지 | 미래 확률 협의가 남았을 때60→70→80→90%. 기회0이면 구매·추천 불가 |
| 보급 지원 | 15만/30만/45만 G | 60초마다 부족한 특수 재료1종을 최대7/12/24개 보급 |
| 납품 일괄 조제 | 15만/30만/45만 G | 한 납품 배치 최대2/3/4병. 남은 요구와 실제 재료만큼 예약 |

신규 영구 투자의 최신 총액은180만 G이다. 최초210만 G안보다 고액 단계 대기를 줄이며, 실제 코드와24개 성장 경로에서 총액·결제·저장 보존을 확인했다. 완료는 시작 후10시간36분~11시간45분, 기존 성장 완료 이후 약4시간43분~5시간이었다. 다음 투자 간격은 표본 최대75분이며 실제 사용자·모든 시드의 상한은 아니다. 새 가격은 다음 정상 실행부터 반영된다. 세부 처리·저장·검증은 [F19 명세](후반-투자와-흥정-훈련-개선-명세.md)를 따른다.

## 돌아왔을 때의 결과

게임을 켜둔 동안의 기간과 판매 수입·재료비·원정비·순영업수입, 직접 투자, 제조·손님·원정의 주요 결과를 요약한다. 원정 보상은 아이콘·이름·수량으로, 특별 발견은 레시피 아이콘·이름으로 읽히게 한다. 긴 장부는 상세에 둔다.

보상은 이미 실제 상태에 반영된 결과다. 결과를 열거나 닫아도 다시 지급하지 않는다. 최근 1분 수입은 판매 매출이며 순이익과 구분한다. **앱을 완전히 종료한 동안의 오프라인 수익은 2026년 10월 8일 사용자 지시로 보류**한다. 켜둔 동안의 자동 운영 누적과 별도 잠수 보너스를 혼동하지 않는다.

관리 UI와 랜덤 재료 보상의 완료 보고는 반영했다. 특별 레시피의 발견 후 구매·미발견 유료 특별 탐색·재료 적체 방지와 포션 배합/최대 효과 표시를 최신 명세로 제작한다. 실제 연결·저장·자동 제조·경제 검증 결과를 확인해 구현 완료와 기획 확정을 구분한다. 현재 사용자 요청에 따라 **Computer Use와 사용자 화면 조작 없이 파일·코드·headless 검사를 사용한다.**

## 개선 검토 순서

2026년 10월 8일 사용자가 개선 진행을 승인했다. 결과 진입·목록 압축·추천 설명·장기 경제 검증과 솥·약초·원정의 작업실 게이지를 [후속 개선 명세](작업실-진행-게이지와-후속-개선-명세.md)에 제작 기준으로 정리했다. 특별 레시피의 미정 선택과 오프라인 보상 보류는 유지한다. 아래 표의 초기 검토 이유는 보존하며 명세의 최신 제작 기준을 따른다.

| 우선순위 | 개선 후보 | 이유와 검토 범위 |
| --- | --- | --- |
| 1 | 돌아왔을 때 결과 확인 경로 | 하단 결과 버튼 제거 후 결과 페이지는 코드에 남아 있지만 현재 확인한 화면 진입 경로가 보이지 않는다. 상단의 작은 결과 진입 등으로 기간·순영업수입·주요 재료·새 발견을 짧게 확인하는 흐름을 검토한다. 강제 수령은 추가하지 않는다. |
| 2 | 약초·포션 목록의 정보량 | 최신 조건 표시로 약초·포션 접힌 행은 102px다. 여러 막대를 함께 보는 목표에 맞춰 대표 대기 이유 한 줄과 접힌 상세로 줄이는 안을 검토한다. 실제 부족 조건과 비용은 계속 확인 가능해야 한다. |
| 3 | 랜덤 보상 이후 장기 균형 | 현재 새 풀의 검사는 1시간이다. 30·60·120분과 8시간, 레시피·설비 우선 및 간헐 확인 경로에서 재료 대기·재고 적체·손님 대기·지출을 비교한다. 이전 고정 보상의 8시간 결과로 대체하지 않는다. |
| 4 | 성장 추천의 이해도 | 추천 대상·비용 옆에 `손님 대기 줄이기`, `새 물약 해금` 같은 짧은 효과를 우선한다. 추천 구매와 실제 정식 탭의 효과가 일치하는지 확인하고 긴 선정 규칙은 상세에 둔다. |
| 5 | 특별 발견 이후의 연결 | 습득 방식과 유료 탐색 반복·보관을 정한 뒤 희귀 추첨→레시피 보유→재료 소비→자동 제조→판매→결과까지 연결한다. 아트·예상 결과만 있는 상태를 완성된 특별 콘텐츠로 표시하지 않는다. |
