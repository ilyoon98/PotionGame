# 작업실 가로 확장 디자인과 검수

2026년 10월 10일 · **디자인 검수 통과 / 540×288 구현 완료 / 격리 검사 완료 / 실제 화면·GPU·조작 미실시**

[최종 검수와 승인 파일](작업실-가로-확장-검수결과.md)의 수정본을 사용해 본 작업실 540×288을 실제 코드에 연결했다. 약초 32×40·받침 104×24·포스터 문구·151픽셀 액체·실제 8개 FIFO 진열·대표/개수·동선·입력 rect와 하단을 적용하고 격리 검사를 완료했다. 520·560은 비교 자료로 남긴다. [작업실 확장과 단일 실행 적용 결과](작업실-확장과-단일실행-적용결과.md)에 최신 로그와 실제 draw 파일 렌더 증빙을 기록했다. 실제 화면·GPU 셰이더·클릭/드래그 검사는 사용자가 확인한다.

이 문서의 제작/인계 절은 승인 이력을 보존한 기준이다. 현재 구현 상태는 이 최신 완료 기록을 따른다. 경제·저장·특별 레시피·오프라인 등 다른 기능 상태를 이번 완료로 바꾸지 않는다.

본 작업실을 좌우로 넓혀 솥·약초·원정을 구분하고 손님 이동 공간을 확보한다. 사용자가 기존 가로 확장안의 디자인 제작과 완료 후 검수·개발 적용을 요청했다. 디자인은 「투명 배경과 내부 디자인 조화」 채팅에서 제작하고, 기획은 완성본을 검수한 뒤 통과한 산출물을 「개발」 채팅에 전달한다. 같은 런타임 파일을 두 담당이 동시에 수정하지 않는다.

이 지시는 이전 가로 확장 채택 대기 기록보다 우선한다. 가로 확장 방향과 제작 순서는 승인되었으며 최종 폭·좌표는 완성본 검수로 결정했다. 이미 구현된 [고정 대표와 제작 대기](작업실-대표-게이지와-제작-대기-명세.md)는 그대로 사용한다.

## 디자인 범위

| 요소 | 제작 기준 |
| --- | --- |
| 본 작업실 크기 | 540×288을 중심으로 520·560 폭 비교. 캐릭터·글자·픽셀을 통째로 확대하지 않고 좌우 공간을 늘림 |
| 왼쪽 | 기존 창틀·낮밤·픽셀 날씨와 작은 약초 재배 공간 |
| 중앙 | 기존 솥·마녀·러그와 제조 표시, 제조 병의 이동 공간 |
| 오른쪽 | 축소한 판매대·독립 물약 선반·원정 포스터, 손님 구매·퇴장 동선 |
| 투명 영역 | 사물 사이 실제 알파 유지. 벽·전체 불투명 배경 추가 없음 |
| 하단 | 기존 이동·골드·시간/날씨·원정/관리 진입·축소·확대·종료를 현재 기능과 간격 기준으로 유지 |
| 작은 모드 | 최소 256×160·정보 320×112의 크기와 역할, 단계 전환과 오른쪽 하단 기준점을 보존 |

배치 참고는 [A 판매대 유지와 가로 확장](reference/workshop-layout-preview-a-20261008.png)이다. 그림은 참고이고 정식 소품·정확한 병 수·게임 데이터가 아니다. 책상 전체 제거안 B를 병행 구현하지 않는다. 세 대표를 여러 행이나 자동 페이지로 바꾸지 않는다.

## 확정된 표시와 상호작용

- 솥은 실제 현재 물약 아이콘·제조 게이지 하나와 물약별 액체 색상을 표시한다. 보관 가득이면 마지막 표시와 실제 진행값을 유지하며 대기하고 판매 후 조건대로 자동 재개한다.
- 약초는 기본 약초 하나의 성장 그림과 실제 게이지, `N종 재배 중`을 표시한다. 원정은 첫 지역 하나의 아이콘과 실제 게이지, `N곳 탐사 중`을 표시한다.
- 대표는 고정하고 전체 활동 수는 실제 상태를 따른다. 대표만 대기하면서 다른 작업이 진행하는 경우 대표의 짧은 이유와 전체 개수가 함께 읽혀야 한다.
- 작은 돋보기/진입 버튼은 기존 포션·약초·원정 관리 탭을 연다. 그림 전체 클릭 통과와 하단 조작을 유지한다.
- 각 품종의 성장 그림·다중 진행은 관리 목록에서 계속 확인한다. 선반 병 그림 자리 수는 실제 보관 한도와 별개이며 디자인으로 경제·제작 순서·병렬 제조 수를 바꾸지 않는다.

## 디자인 산출물

새 디렉터리와 이름을 사용하여 기존 승인 에셋과 원본을 보존한다. 런타임 scripts/scenes는 디자인 담당이 수정하지 않는다.

선반·판매대 소품에는 실제 재고 병을 구워 넣지 않는다. 소품은 빈 진열 자리이고 미리보기의 병은 기존 실제 병 에셋으로 별도 배치한다. 식물 성장 그림·원정 대표 아이콘·진행 막대·상태 글자·버튼도 소품 PNG와 분리하여 런타임 상태에 따라 갱신할 수 있게 한다.

1. 전체 배치의 실제 논리 크기 PNG와 최근접 정수 확대 미리보기, 폭 비교 이미지.
2. 새 판매대·선반·원정 포스터·재배 받침 등의 투명 PNG. 기존 소품을 재사용하는 경우 원본 경로와 표시 영역을 기록한다.
3. 논리 크기·앵커·좌표·레이어 순서·클릭 버튼 영역·기존 에셋 참조가 담긴 manifest 또는 연결 명세.
4. 낮/맑음, 밤/비, 제작 중/보관 가득, 일부 대기/대표만 대기, 활동 수 0개/전체 활동의 비교 미리보기. 숫자는 디자인 예시로 표시한다.
5. 투명도·프레임·좌표/영역 검사 결과와 기존 대비 변경점, 알려진 제약.

솥 액체 변경은 현재 구현을 우선 재사용한다. 새 마스크가 필요할 때만 액체 영역을 분리하여 제공하고 솥 외곽·불·조명·알파를 보존한다. AI 이미지 생성/편집은 imagegen 스킬과 도구를 사용하고 납품 PNG의 최종 알파·크기·사용 영역은 따로 확인한다.

## 기획 검수와 개발 인계

| 검수 | 통과 기준 |
| --- | --- |
| 원본과 픽셀 | 기존 캐릭터·솥의 크기와 픽셀 스타일 유지, 최근접 표시와 정확한 프레임 영역, 새 파일의 투명 알파 확인 |
| 배치와 읽기 | 1배 크기에서 아이콘·짧은 상태·게이지 구분. 캐릭터·창틀·날씨·병 이동·진열 병과 겹치지 않음 |
| 동선 | 손님 등장·구매·퇴장, 제작 병의 솥→진열 이동, 바닥/러그 기준이 새 소품 위치와 맞음 |
| 상태 | 색상·물약·게이지 의미가 일치. 대기 중 막대 반복이나 모든 포션 동시 제조 암시 없음 |
| 입력 | 세 작은 진입 영역과 하단 조작 좌표가 manifest와 일치하고 그림 클릭 통과를 유지할 수 있음 |
| 모드 연결 | 확장 본 화면만 변경하고 최소/정보 화면 및 오른쪽 하단 기준점 보존 가능 |
| 개발 자료 | 분리 PNG·참조 경로·논리 좌표·레이어가 실제 존재하고 manifest 값과 파일 크기가 일치 |

기획은 완료 보고와 실제 파일을 읽고 비교 이미지를 검수한다. 필수 항목이 부족하면 디자인 채팅에 구체적인 수정 요청을 보내고 다시 확인한다. 통과한 최종 폭·manifest·에셋만 개발에 적용하도록 요청한다. 개발은 사물 좌표뿐 아니라 게이지·손님 동선·병 진열·하단·클릭 영역·모드 전환의 연결을 함께 수정하고 회귀를 확인한다.

### 개발 연결 대상

2026년 10월 10일 현재 본 작업실은 540×288, 그림 영역 540×248, 하단 40px다. 최종 manifest의 w540을 `workshop_layout.gd`에 공유해 아래 연결을 완료했다. 실내 440×704의 그림 408×248, 최소 256×160·정보 320×112는 확장하지 않았다.

- `workshop_assets.gd`·`shop.gd`: 본 모드 크기·그림 높이·content scale·toolbar 폭. 하단 오른쪽 조작과 `window_mode_layout.gd`의 기준점·화면 경계 보정.
- `shop_art.gd`·`shop_sky.gd`: 솥·액체/증기/불/halo·화분·마녀 발·러그·창틀·날씨 pane와 clip. 조명 계산과 상태는 보존.
- `potion_display.gd`: 실제 병 진열 자리와 솥→선반→손님 이동 좌표. 소품과 병을 분리하고 실제 FIFO 재고를 표시.
- `shop_motion.gd`: 본 화면 구매 발 (492,245)·화면 밖 발 (596,245)·손 (515,199)을 연결했다. 실내는 기존 `OFFSCREEN_X=464`와 동선을 유지한다. 전달 중 모드 변경은 시각 전달만 마쳐 실제 판매 종류를 새 손에 표시한다.
- `workshop_gauges.gd`·`desktop_input`: 실제 표시 좌표와 세 작은 상세 버튼의 `DETAIL_RECTS`/`click_regions()` 일치, 새 본 화면 크기와 그림 높이를 입력 bridge에 전달. 사물 전체 클릭 통과는 보존.
- 관련 검사 도구: 본 작업실의 크기·배치·버튼과 입력 경계를 승인 540 manifest와 실제 노드/draw 명령으로 대조했다. 작은/실내 모드·로그인 자동 재개·직접 종료·관리·저장 복원과 오른쪽 하단 기준점 회귀는 통과했다.

현재 **Computer Use·화면 입력·포커스 변경·창 이동·보이는 게임/에디터 실행은 금지**다. 파일·격리된 headless 상태/배치 및 Windows 단일 실행 도우미 검사만 진행했고 실제 플레이어 저장을 사용하지 않았다. 디자인 검수·런타임 구현·격리 검사 완료를 기록하되 실제 클릭·드래그·GPU 조명·로그오프/재부팅은 미실시로 구분한다. 공용 실제 draw export로 만든 540×288/2배 파일 렌더는 GPU 화면 캡처나 셰이더 검증이 아니다.

특별 레시피 습득 방식·희귀 탐색 반복·오프라인 수익의 기존 미정/보류와 최근 로그인 자동 재개·Pretendard·관리 아이콘 확대·관리 창/행 크기는 그대로 유지한다.
