# 증분 성장과 흥정 비용 검토

> 2026-10-19 후속 제작 요청 반영: 아래 검토를 바탕으로 흥정 적용 기회 차단과 보급 지원·납품 일괄 조제를 [F19 제작 명세](후반-투자와-흥정-훈련-개선-명세.md)에 확정했다. 이 검토의 후보·예산은 당시 분석 기록이며 실제 제작 범위와 초기값은 최신 명세를 따른다. 구현 완료를 뜻하지 않는다.

- 검토일: 2026-10-19
- 상태: **현행 구현 검토 및 개선 제안. 아래 신규 기능·가격은 미확정이다.**
- 범위: 현재 성장 구조, 완성 이후 골드 사용처, 수주 해금과 흥정 훈련의 비용·효과
- 이번 작업: 코드 읽기와 격리된 실제 경제 계산. 게임 코드·기존 확정 명세·플레이어 저장은 변경하지 않았다.

## 판단

초중반의 증분 성장 기반은 작동한다. 재료 공급 → 레시피 → 제조·판매 → 다음 투자로 이어지고, 성장에 따라 순수입과 병목이 바뀐다. 다만 기존 성장 목표를 완수한 뒤에는 늘어난 골드를 다시 투자할 대상이 적다. 이 구간에서 흥정 훈련 3단계만 추가하는 것으로는 다음 성장 주기를 만들기 어렵다.

**9시간 정도 운영한 완성 가게를 기준으로 흥정 훈련 7만 8천 골드는 작다. 하지만 가격만 크게 올리면 효과가 끝나는 훈련을 비싸게 파는 문제가 생긴다.** 훈련의 남은 적용 기회와 후반의 지속 투자 대상을 먼저 정리해야 한다.

9시간에 유한한 콘텐츠를 완수하는 것 자체가 결함은 아니다. 완수 이후에도 성장을 이어가려는 방향이라면, 다음 투자로 운영 방식이나 실제 생산·납품량이 바뀌는 목표가 필요하다는 판단이다. 재미의 최종 평가는 플레이 관찰이 필요하며, 이번 검토는 경제와 구조에 관한 근거다.

## 현재 코드로 다시 계산한 성장

새 가게를 **0골드**에서 시작해 실제 `ShopState.advance()`로 9시간씩 9회 계산했다. 레시피 우선·설비 우선·15분마다 복귀하는 구매 정책과 3개 난수 시드를 조합했다. 정책은 사람이 돌아왔을 때 강화·해금을 구매하는 모형이며 제품에 자동 강화를 추가한 것이 아니다.

이 측정의 완료 범위는 **일반 물약 32종·원정 8곳 조사·기존 설비와 직원 강화·직원 4명**이다. 특별 레시피 구매, 수주 수락, 흥정 훈련 구매는 제외해 기존 성장 종료 후의 구매 여력을 분리했다. 실제 플레이어의 잔고나 전체 콘텐츠 완수 시간을 측정한 결과로 해석하지 않는다. 재료 구매비와 원정 출발비는 차감했다.

| 관측 항목 | 9회 결과 | 의미 |
| --- | ---: | --- |
| 마지막 지역 최초 개방 | 195~267분 | 현행 수주 해금 시점 |
| 그 시점의 구매 후 잔고 | 235~7,306 G | 해금 직후에는 반드시 부유하지 않음 |
| 기존 성장 목표 완료 | 364~405분 | 약 6시간 4분~6시간 45분 |
| 완료 직후의 잔고 | 114~54,517 G | 마지막 투자에 돈을 쓴 직후와 이후 방치한 상태는 다름 |
| 9시간 시점 잔고 | 705,708~854,239 G | 추가 투자처가 없으면 골드가 크게 누적됨 |
| 8~9시간의 분당 운영 순수입 | 4,810~4,890 G | 재료비·원정비 차감, 신규 투자 제외 |
| 훈련 3단계 합계가 9시간 잔고에서 차지하는 비율 | 9.1~11.1% | 이 시점에는 세 단계 모두 즉시 구매 가능 |

성장 중의 변화도 있다. 각 시점 직전 5분의 9회 평균 순수입은 30분 약457 G/분 → 2시간 약1,558 → 4시간 약2,870 → 7시간 약4,873으로 증가했다. 매 순간 일정하게 증가한다는 뜻은 아니며, 투자·레시피 해금의 결과로 수입 규모가 커진다는 근거다.

재고 줄타기도 일부 작동한다. 예를 들어 레시피 우선·시드73129는 55~60분에 평균 재고96.2%·손님 대기0%였고, 235~240분에는 평균 재고1.0%·손님 대기11.7%였다. 전체 9회의 8~9시간에는 5분 표본에서 재고 점유가 높은 상태와 손님 대기0%가 이어졌다. 성장이 끝나면 다시 안정 상태에 들어가며, 그 뒤 무엇을 개선할지 목표가 약해진다.

## 흥정 훈련의 가격과 적용 기간

| 단계 | 현행 가격 | 일반 흥정 성공률 | 기존 성장 완료 후 순수입으로 모으는 시간 |
| --- | ---: | ---: | ---: |
| 1 | 8,000 G | 60% → 70% | 약1.6~1.7분 |
| 2 | 20,000 G | 70% → 80% | 약4.1~4.2분 |
| 3 | 50,000 G | 80% → 90% | 약10.2~10.4분 |
| 합계 | **78,000 G** | 60% → 90% | **약16분** |

위 시간은 구매 여력이며 훈련의 투자 회수 시간이 아니다. 성공률 +10%p가 가게 전체 수입 +10%를 의미하지 않는다.

기존 F18 경제 비교에서도 비슷한 규모다. 현재 코드 해시와 일치하는 완성 가게·특별 레시피 보유 fixture의 최종 등급 2시간 현금 순수입은 계약 없음 평균616,595 G, 대금형645,636 G였다. 분당 약5,138~5,380 G이므로 전체 훈련은 약14.5~15.2분 수입이다. 이 fixture의 시작100만 골드는 실제 도달 잔고로 사용하지 않았다. 훈련3단계를 미리 보유한 비교이므로 훈련 단계별 효과나 회수는 검증하지 않는다.

가격보다 먼저 해결해야 할 사실은 다음과 같다.

- **해금 시점이 사용자 설명과 다르다.** 현재는 `별의 정원 최초 개방`만 검사한다. 모든 강화·직원·레시피 완료는 요구하지 않는다. 기존 제작 명세와 코드는 일치하며, 이번에 말씀한 ‘모든 강화 이후’ 방향과는 차이가 있다.
- 훈련 효과가 있는 협의는 거래처3곳 × 1~3등급으로 **최대9회**다. 기본안 수락이나 등급 건너뛰기 때문에 실제 적용 기회는 더 적을 수 있다. 최종4등급의 협의는 별도로 존재하며 훈련 없이100%다.
- 이미 판정한 협의 결과는 훈련을 사도 바뀌지 않는다. 모든 거래처가 최종 등급이면 추가 성공률의 효과는0이다.
- 현재 `training_view()`는 남은 적용 기회를 확인하지 않는다. 별의 정원 개방·최대 훈련 여부·골드만 충족하면, 효과가 남지 않아도 구매할 수 있고 추천 후보에도 들어간다.

따라서 기존 가격을 단순히10배로 바꾸는 안은 권하지 않는다. 비싼 훈련을 위해 기다리는 동안 협의가 끝나면, 돈을 벌어 구매해도 효과가 사라질 수 있다.

## 성장 구조에서 보완할 부분

| 항목 | 현재 평가 | 개선 방향·미확정 |
| --- | --- | --- |
| 자동 운영과 투자 | 구매·제조·판매 자동화 위에 일회성 해금·강화가 있어 기반은 맞음 | 수동 납품이나 반복 클릭을 늘리지 않고 투자 결과를 강화 |
| 재고와 손님 대기 | 성장 단계에 따라 서로 다른 병목이 관찰됨 | 특정 구간의 병목을 해결하면 다음 문제가 드러나도록 유지. 항상 재고가 넘치거나 항상 부족하게 맞추지 않음 |
| 기본 화분 후반 | 11단계부터 이론상 기본 약초2개/0.8초. 12~15단계에는 수확량·보관 증가에30,400 G 추가 지출 | 이미 충분한 기본 약초를 더 만드는 단계보다 부족한 상위 재료에 영향을 주는 보상 검토 |
| 여과기 마지막 단계 | 14,400 G로 성공 보너스9→10%p. 기본 성공률80% 품목에는 유효하지만100%에 도달한 품목에는 증가 없음 | 강화 설명에 적용되는 품목을 짧게 표시. 모든 물약이 같은 만큼 좋아지는 것으로 보이지 않게 함 |
| 레시피 수와 운영 변화 | 같은 계열에서 제조 가능한 최고 순서 품목을 우선 선택. 종류가 늘어도 제조 솥은 하나 | 단순히 종류만 추가하기보다 해금이 수입·재료 소비·납품에 미치는 변화를 명확히 표시 |
| 완성 이후 골드 | 수주가 수입을 늘려도 훈련 외의 새 투자 연쇄가 부족 | 거래처 성장으로 다음 시설·공급·제조 목표를 열어 골드를 다시 쓰게 함 |

화분 비교는 한솥·제조 하한0.8초·기본 약초 최대2개/배치라는 현재 규칙으로 계산한 이론적 소비 상한이다. 실제 공급량 측정이나 모든 재료의 과잉을 뜻하지 않는다. 특별 물약 등은 기본 약초를 쓰지 않는 경우도 있다.

솥 후반이 전부 속도 하한에 막히는 것은 아니다. 현재 솥은 후반에 품질 효과로 전환된다. 판매대 마지막1.55→1.50초도 재고가 충분하면 처리량 상한을 약3.33% 높인다. 무효인 강화와 상황에 따라 효과가 작은 강화를 구분해야 한다.

## 제안하는 작업 순서

### 1. 효과 없는 훈련 추천·구매 정리

현재 협의를 끝냈는지만 보지 말고 **미래 등급까지 포함해 훈련이 적용될 미판정 협의가 남았는지** 확인한다. 다음 등급이 남아 있으면 구매 가치를 유지하고, 모두 끝났다면 추천에서 제외하고 ‘적용할 흥정 없음’을 표시하는 안이다. 기존 구매 내역이나 이미 판정한 성공·실패는 바꾸지 않는다.

### 2. 후반 콘텐츠의 시작점을 명시

‘별의 정원 최초 개방부터 기존 성장과 병행’과 ‘기존 강화 완료 후 시작’은 서로 다른 경제다. 사용자가 말한 후반 전용 방향을 채택하면 해금 조건부터 수정해야 한다. 이번 검토에서는 변경하지 않았다. 향후 조건 변경 시 이미 열린 수주나 진행 중 계약을 다시 잠그지 않는 저장 호환 원칙도 필요하다.

### 3. 흥정 훈련과 별도로 지속되는 후반 투자 만들기

핵심은 돈을 지출한 뒤 실제 운영 결과가 달라지고, 그 결과로 다음 투자 목표가 생기는 것이다. 기존 건조대·재배 보조·솥 품질의 이름만 바꾼 퍼센트 강화를 반복하는 방식은 피한다.

| 후반 투자 후보 | 현재와 구분되는 변화 | 자동 운영 원칙 |
| --- | --- | --- |
| 거래처 지원 공급 | 특정 거래처의 실적을 달성하면 부족한 상위 재료의 별도 공급 경로를 열 수 있음. 기존 전체 성장속도 증가와 구분 | 한 번 투자하면 자동 공급 |
| 계약 전용 일괄 조제 | 납품용 한 배치에서 여러 병을 생산하는 단계 보상. 실제 재료도 병 수만큼 소모하며 기존 일반 판매와 배분 검증 필요 | 해금 후 자동 조제·납품 |
| 거래처 투자 목표 | 등급·누적 납품 실적으로 다음 시설을 차례로 개방. 최종 계약에 도달해도 후속 투자 목표가 보임 | 매 회차 새 흥정을 요구하지 않음 |

위는 신규 제작 승인이나 확정 기능이 아니다. 먼저 실제 병목 하나를 선택해 투자 전후 납품량·일반 판매·재료 소모·순수입을 비교할 후보들이다. 현재 계약 출고는 즉시 처리되므로, 존재하지 않는 출고 대기시간을 줄이는 ‘물류 속도 강화’는 투자 후보로 삼지 않는다.

지속 효과가 있는 후반 투자의 **초기 시험 예산**은 분당 약5천 G을 기준으로30분·60분·120분 수입, 즉 약15만·30만·60만 G 규모에서 검토할 수 있다. 이는 흥정 훈련의 새 가격이 아니며 수치 확정도 아니다. 효과·해금 등급·실제 잔고·구매 후 수입 증가를 같이 계산해야 한다. 세 비용의 단순 합계가 플레이 시간을 보장하지도 않는다.

### 4. 그 다음 흥정 훈련비 재산정

남은 협의 수와 구입 가능한 등급을 정한 뒤0~3단계 구매 전략을 비교한다. 훈련을 너무 늦게 구매해 효과가 사라지는 경우, 기존 강화 대신 훈련을 먼저 산 경우도 포함한다. 비용을 다 지출한 직후와 이미 몇 시간 누적한 복귀 플레이어를 모두 봐야 한다.

관리 화면에는 긴 경제 설명 대신 `다음 목표`, `비용`, `현재 → 다음 효과`를 간결하게 표시한다. 상세 비교는 펼쳤을 때만 제공한다.

Godot4.6 headless에서81시간 분량의 게임 시간을 계산했고, 매 초 새 가게의 `보유 골드 = 판매 누계 − 재료비 − 원정비 − 일회성 구매비` 일치를 검사했다. 9회 모두 완료했다. F18 완성 가게 비교의 소스9개도 현재 파일과 해시가 일치했다.

재실행은 별도 `APPDATA/LOCALAPPDATA`를 이 검토 폴더 아래에 지정한 뒤 `--headless --path <프로젝트> --script res://.verification/incremental-review-20261019/probe.gd`로 실행하고 `analyze.py`를 수행한다. 원래 경제 보고서를 덮어쓰는 기존 측정기의 `_run()`은 실행하지 않는다. 실제 Windows·GPU·입력·플레이어 저장·오프라인 수입·주관적 재미 검증은 이번 결과에 포함하지 않는다.
