## 표시 수정

이전 `ManagementArt.readable_icon()`은 투명 여백을 잘라 그림마다 다른 크기를 만들고 48px 목록 칸에 비정수 배율로 늘렸다. 직원 아이콘의 실제 배율은 약 1.297·1.5·1.6배였고, 32×40 재료를 32px 배합 칸에 넣으면 0.8배로 줄었다.

`PixelIcon`은 새 32×32 그림을 48px 목록 칸 안에서도 1배로 표시한다. 배합·보상 32px 칸은 1배, 기존 16px 소품의 48px 표시는 3배, 캐릭터 32×48·성장 32×40은 원본 크기다. 작은 명성·가격용 동전은 16px 전용 그림을 쓴다. 새 자산에는 used-rect crop을 하지 않는다.

Godot가 기본 TextureRect를 그린 뒤 스크립트 `_draw()`를 호출하는 순서도 고려했다. 텍스처 교체로 배율 방식이 달라지면 지연 재그리기를 예약하여 이전 배율이 화면에 남지 않게 한다. 검사에서 사용하는 `drawn_rect()`는 표시 상태를 바꾸지 않는다. 매 프레임 실행하는 별도 루프는 추가하지 않았다.

`UiPixel`은 표시 전용 경로와 텍스처를 캐시한다. 새 파일이 없으면 기존 자산으로 돌아간다. 희귀 레시피를 공개할 수 있는지는 기존 로직이 먼저 판단하며, 모르는 레시피의 이름·물약을 새 아이콘 때문에 노출하지 않는다.

## 보존한 기준

- 주인공·손님 5명: 104개 시트와 6,656프레임의 크기·캐릭터별 승인 색상·알파·외곽선 검사 모두 통과하여 재생성하지 않았다.
- 직원: 작업실 캐릭터를 추가하지 않고 이전 D안의 역할 아이콘 표시를 이어간다.
- 화분 성장 그림 11종: 최근 여명초 v2를 포함한 기존 승인 예외를 보존했다. 이 그림들이 새 5색 규칙을 통과했다고 주장하지 않는다.
- 물약 병: 원본 RGBA를 바꾸지 않았다. 코르크의 외부 경계에 갈색이 남는 기존 2픽셀 예외도 그대로 보존했다. 새로 생긴 경계 위반은 없다.
- 저장 형식·재화·진행·경제 수치·실행 중인 플레이어 게임은 변경하지 않았다.

F26 검사는 이전 UI 경로·32×40 크기 기대를 새 32×32 카탈로그에 맞추고 승인 원본의 픽셀·성장·병·솥 검증을 보존하여 221개 모두 통과했다. 특별 레시피 검사도 기존 12개 원본 해시와 미발견 지도 SHA, 액체색·마스크 검사를 유지한 채 새 UI 경로를 확인해 통과했다.

실제 GPU 캡처와 proof의 보관용 복사본은 `art/mockups/ui-pixel-v2/runtime/`에 있다. 이 화면은 완성된 가게의 격리 검증 상태이며 사용자의 실제 플레이 화면이나 저장 데이터가 아니다.
