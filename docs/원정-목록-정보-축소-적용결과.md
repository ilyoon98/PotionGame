# 원정 목록 정보 축소 적용 결과

2026-10-13 · **이번 범위 구현 완료 / 격리 검사 완료 / 실제 게임 화면 미검증**

원정 목록의 전체 보상과 레시피 설명을 기존 `상세`로 묶었다. 기본 카드는 지역, 실제 상태·게이지·남은 시간, 보장 주재료 하나와 매회 비용만 표시한다. 일반적인 접힌 카드는 실제 472×148px이며 제목18px·본문16px·지역 아이콘48px·재료 아이콘32px를 유지한다. 비용은 기존 코인 표시를 사용한다.

열린 지역은 과거 개방비와 비활성 `열림` 버튼을 숨긴다. 잠긴 지역은 해금 버튼에서 현재 부족 조건 하나 또는 실제 개방 금액을 표시하며 긴 조건은 줄바꿈할 수 있다. 대기 상태는 실제 이유를 보여 주고 멈춘 회차는 남은 저장 경과값을 바꾸지 않으면서 막대를0으로 표시한다. 주기 갱신에 카드 높이가 바뀌지 않는다.

상세에서는 보장 재료와 추첨 후보를 공통 구획으로 구분하고, 후보별0~2개 범위를 유지한다. 일반 레시피는 미구매 항목만 남기고 조사 진행을 목표까지 표시한다. 공통 제목에서 조사 해금과 이후1회 구매를 설명하므로 항목마다 설명을 반복하지 않는다. 이미 구매한 레시피·미구현 특별 레시피 후보·가중치/확률·원시 타이머·누적 완료 횟수는 이 카드에서 제외한다. 특별 후보 데이터·아트와 실제 완료 결과/결과 페이지는 유지한다.

상세 출발 조건은 아직 부족한 조건과 대기 이유를 표시한다. 출발에 필요한 골드에는 예비금과 다른 원정에 남겨둘 비용, 먼저 출발하는 원정 비용을 실제 우선순위에 맞춰 반영한다. 이 계산은 읽기 전용이며 자동 원정·결제·지급·해금·가격·RNG·저장 규칙을 바꾸지 않는다. 게임 운영의 짧은 원정 표시와 추천의 직접 해금 구매도 유지한다.
