# 메인 작업실 픽셀 조명 적용 결과

2026-10-08 · **구현 완료 / 엔진 렌더·자동 검사 통과 / 실제 사용자 조작 검사 대기**

사용자가 디자인 채팅에서 확정한 “저 모양을 메인 모드에서도 적용” 요청에 따라 B형 미니 작업실의 돌 받침, 마녀 발밑 러그, 주황 불빛과 분홍 물약 반사를 투명 작업실·실내·작은 화면에 적용했다. 메인 화면의 창틀·시간과 날씨·판매대·대표 화분·손님·하단 관리 UI는 유지한다.

## 적용

- 승인된 솥·마녀 원본과 애니메이션, 화면별 기존 크기 유지. 돌 받침은 솥 아래, 러그는 마녀 발밑에 두고 서로 겹치지 않게 했다.
- 화면별 실제 솥 Rect2를 기준으로 빛 중심과 범위를 계산한다. 실내 화면의 16,64 오프셋과 미니의 2배 확대를 포함해 셰이더 좌표를 보정한다.
- 메인·미니가 `pixel_workshop_light.gd`의 같은 환경 계산과 게임 시계를 사용한다. 60% 밝기 하한, 날씨 강도 설정, 주황 빛의 3Hz 약한 깜박임이 공유된다.
- 5단계 픽셀 감쇠와 한 번 생성해 재사용하는 래스터 후광을 적용했다. 부드러운 벡터 블러, 매 프레임 이미지 생성·GPU 이미지 읽기는 사용하지 않는다.
- 솥 전용 레이어에서 불·분홍 액체의 발광을 보존한다. 실내 바닥의 비슷한 색상이나 보상 문구에는 발광 마스크가 적용되지 않는다.
- 골드·재고·제작 예약·원정·자동 운영·저장 구조는 변경하지 않는다.

## 검사

`tools/verify_main_pixel_light.gd`가 실제 GPU 렌더로 투명 작업실·실내·작은 화면 각각 낮 맑음 / 밤 맑음 / 낮 비 / 밤 비를 검사했다. 돌 받침·러그 비겹침, 솥 원본의 불·물약 픽셀 발광, 화면 오프셋, 빈 공간 투명도, 미니 전환 전후 환경 값·골드·제작·원정·RNG의 동일성을 확인했다.

추가 통과: `verify_asset_integration.gd`(손님 원본·걷기·퇴장·제조 판매 FIFO), `verify_companion.gd --render`(5환경·3관리 화면·복귀), `verify_environment.gd`(창밖 날씨 변화·실내 누출 없음), `verify_desktop_lifecycle.gd`(모드별 native helper 시작·종료·미니 그림 높이 복원).

스크린샷은 `.verification/main-pixel-light/`에 저장했다. `desktop-background-comparison.png`는 엔진 이미지에 밝고 어두운 바탕을 합성한 시각 비교 자료다. 실제 바탕화면 캡처나 클릭 통과 실사용 증거는 아니다.

Windows 잠금 상태에서 Computer Use 입력 검사는 하지 않았다. 기존 잠금 해제 요청이 해결되기 전까지 실제 클릭·드래그 최종 검증은 대기 상태로 유지한다.

현재 실행 중인 플레이어 게임(PID 45292)은 CloseMainWindow 정상 종료 요청이 불가능하여 강제 종료하지 않았다. 이번 조명 변경은 다음 정상 재실행 시 적용된다. 테스트는 별도 APPDATA를 사용했고 플레이어 저장을 수정하지 않았다.
