# 원정 목록 정보 축소

2026년 10월 13일 · **이번 범위 구현 완료 / 격리 검사 완료 / 실제 게임 화면 미검증**

[적용 결과·검사·파일 미리보기](원정-목록-정보-축소-적용결과.md). 기본 카드148px, 전체 부가 영역의 상세 토글, 미구매 일반 레시피·실제 출발 조건과 기존 글씨/아이콘을 적용했다. 최종 상세 레시피는 공통 조사/구매 설명과 항목별 `N/목표회`만 표시한다. 아래 내용은 구현 기준이며 다른 기능의 완료를 뜻하지 않는다.

원정 목록은 어디가 움직이는지, 무엇을 가져오는지, 얼마가 드는지 빠르게 확인하는 화면이다. 지역별 전체 보상과 레시피 설명을 기본 카드에서 접고 기존 `상세`로 묶는다. 글씨·아이콘을 줄여 압축하지 않는다. 자동 반복·해금·가격·재료 추첨·진행·저장은 유지한다.

## 기본 카드

| 정보 | 표시 규칙 |
| --- | --- |
| 지역 | 기존 48px 지역 아이콘·이름·상세 버튼. 제목18px, 본문16px 유지 |
| 상태와 진행 | 실제 상태 한 개와 실제 원정 게이지·남은 시간. 별도 `원정` 설명과 같은 상태를 중복 표시하지 않음 |
| 주재료 | 보장 주재료 하나의 아이콘·이름·수량 범위. 전체 보상 중 대표임을 `주재료`로 명시 |
| 반복 비용 | `매회 8 G`처럼 회당 실제 비용 하나. 숫자는 현재 모델에서 읽음 |
| 해금 버튼 | 잠긴 지역에서만 표시. 가능한 경우 `원정 열기 · 금액`, 부족하면 대표 미충족 조건 하나 |

열린 지역에는 과거 개방비와 비활성 `열림` 버튼을 표시하지 않는다. 잠긴 지역의 조건은 해금 버튼에서 한 번만 보여 주고, 제목 아래에서 같은 조건을 반복하지 않는다. 긴 조건은 읽을 수 있게 줄바꿈하고 상세에만 숨기지 않는다.

접힌 카드는 제목, 상태/게이지, 주재료/회당 비용 중심으로 구성한다. 일반 상태는 약140~160px를 목표로 하되 긴 필수 조건 때문에 글자·아이콘·버튼을 잘라내지 않는다. 모든 지역을 같은 순서로 읽을 수 있게 하고 주기 갱신으로 카드가 흔들리지 않게 한다.

## 상태별 표시

| 상태 | 목록에 남길 내용 |
| --- | --- |
| 잠김 | 지역·주재료·매회 비용·조건/해금 버튼. 움직이는 원정 게이지 없음 |
| 탐색 중 | `탐색 중`·실제 게이지·남은 시간 |
| 재료 가져오는 중 | 기존 의미의 상태·실제 게이지·남은 시간 |
| 완료 보상 보관 대기 | `재료 보관 대기`. 실제 보상을 보존하고 가짜 진행을 재생하지 않음 |
| 다음 출발 대기 | 실제 원인 하나. 보관 가득·재료 충분·출발비 부족을 구별 |
| 조사 완료 후 반복 | 현재 진행/대기 상태를 유지. 누적 `조사 완료` 문구는 상세로 이동 |

주재료와 매회 비용은 열린 지역에서도 유지한다. 누적 조사 횟수·조사 완료 여부는 기본 카드에서 제외하고 상세에서 확인한다. 회차 게이지의 분모는 기존 실제 회차이며 조사 횟수로 대체하지 않는다.

## 상세

기존 상세 토글이 전체 부가 영역을 함께 열고 닫는다. 새 창·탭·페이지는 만들지 않는다. 처음에는 접혀 있고 갱신·다른 탭 이동 때문에 임의로 열리지 않는다.

1. **획득 재료:** 보장 주재료와 추가 재료 후보의 아이콘·이름·수량. `보장`/`추첨`을 구획 제목으로 묶어 항목마다 반복하지 않는다. 보조 후보는 `0~2개` 범위를 유지하고 후보 전체를 매회 받는 것으로 표현하지 않는다.
2. **레시피:** 이 지역 조사로 해금할 수 있는 미구매 일반 레시피와 필요한 조사 횟수. 이미 구매한 항목은 기본 상세 목록에서 생략한다. 조사 횟수는 목표까지만 표시하고 실제 내부 누적값은 유지한다. 조사 해금과 레시피 1회 구매를 구별해 무료 지급으로 표현하지 않는다.
3. **출발 조건:** 아직 부족한 선행 지역·명성·골드 조건과 현재 대기 원인을 설명한다. 예비금 규칙이 실제 출발을 막을 때는 필요한 총액과 원인을 여기서 확인할 수 있게 한다.

선택 가중치 `60/30/10`, `2종 선택 확률 25%`, 내부 경과/회차 원시값, 이미 충족한 조건의 반복 설명은 사용자 카드에서 제외한다. 기존 경제 검토·개발용 규칙은 문서와 모델에 유지한다. 실제 완료 결과와 획득 수량은 기존 `결과`에서 계속 확인한다.

아직 지급하지 않는 특별 레시피의 `추가 예정` 항목은 원정 사용자 UI에서 제외한다. 후보 아트·획득 방식 보류 상태는 유지하며, 이번 작업으로 실제 희귀 보상이나 획득 규칙을 추가하지 않는다.

## 예시

열린 숲 가장자리의 대기 카드:

```text
[지역 아이콘] 숲 가장자리                 [상세]
재료 보관 대기             [실제 정지 게이지]
[재료 아이콘] 주재료 이슬풀 1~3개 · 매회 8 G
```

잠긴 별의 정원 카드:

```text
[지역 아이콘] 별의 정원                   [상세]
[재료 아이콘] 주재료 별씨 5~7개 · 매회 100 G
[          달빛 유적 조사 완료 필요           ]
```

수량·비용은 현재 카탈로그 기준의 예시다. 개발은 실제 데이터로 연결한다.

## 개발 연결과 검수

현재 `management_panel.gd`의 원정 갱신 영역은 상세 문구와 별도로 전체 `RewardIcons`를 상시 표시한다. 이 보상 영역도 기존 상세 토글에 연결하고 반복 문구를 제거한다. `management_status.gd`의 실제 원정 상태·구매 판정·보상 카탈로그를 재사용한다. 공용 데이터에서 후보를 삭제하거나 다른 탭·결과의 실제 재료 표시까지 지우지 않는다.

잠김·해금 가능·탐색·운반·두 종류 보관 대기·출발비 부족·조사 완료·전체8지역을 격리 상태로 확인한다. 기본 카드에서 전체 보상/레시피/내부 가중치가 숨겨지고 상세는 한 번에 열리고 닫혀야 한다. 520px 관리 폭에서 기존 폰트·아이콘·필수 조건이 잘리지 않아야 한다. 실제 시간 막대는 계속 갱신하고 UI 갱신·상세 토글·탭 전환으로 가격·예약·회차·재료 지급·골드·RNG·저장이 바뀌지 않아야 한다. 게임 운영 카드의 짧은 원정 표시와 성장 추천의 해금 구매도 보존한다.

Computer Use·보이는 게임/에디터 실행·사용자 화면 입력·포커스 변경은 금지한다. 실제 플레이어 저장·실행 중인 게임은 조작하지 않고 격리된 headless 및 파일 기반 배치 증빙으로 확인한다.
