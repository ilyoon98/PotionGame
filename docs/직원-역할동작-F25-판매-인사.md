# 직원 역할 동작 3 — 판매 보조 손 인사

2026-11-06. 기존 판매 보조가 한 손을 들어 가볍게 인사한 뒤 원래 대기 자세로 돌아오는 동작을 제작했다. 정렬 원본의 머리·가슴·다리와 기존 외형을 유지하는 사용자 요청에 따라 Pixelbolt 0.11.0을 사용했다.

**대기 → 준비 → 손 들기 → 좌우 인사 2회 → 천천히 내리기 → 원래 대기**의 6초 동작이다. 고유 자세 5개를 14개 타이밍 구간으로 사용한다. Godot 리소스는 한 번 실행한 뒤 정지 자세로 끝나고, 비교 화면과 GIF는 반복한다.

[기존 캐릭터와 함께 보기](../art/mockups/f25-staff-greeting-v1/together-1x.gif) · [대기와 인사 비교](../art/mockups/f25-staff-greeting-v1/comparison-1x.gif) · [재생·속도 조절](../art/mockups/f25-staff-greeting-v1/review.html)

## 제작 기준

- 정렬된 32×48 원본을 3배로 표시한다. 목·가슴·허리·골반·양다리·발 y46과 반대 손은 원본을 보존한다.
- 기존 머리띠·올림머리·장밋빛 원피스·앞치마와 원본 5색을 유지한다. 눈이나 얼굴, 신발을 다시 디자인하지 않는다.
- 화면 오른팔과 손만 움직인다. 손을 얼굴 높이까지 과하게 뻗지 않고 원래 팔 길이에 맞는 작은 인사로 만든다. 머리 옆의 빈 공간과 어깨–팔꿈치–손목 연결을 확인한다.
- 기존 팔·손을 새 자세로 바꾸므로 내려둔 손이 중복으로 남아 있지 않아야 한다. 마지막 그림은 정렬 원본의 정지 자세와 같아야 한다.

첫 포즈는 수치 검사에는 맞았지만, 수평으로 뻗은 팔이 물건을 건네는 모습으로 읽혔다. 최종 포즈에서는 팔꿈치를 아래로 굽히고 손을 몸 쪽으로 줄였다. 열린 손의 피부는 4픽셀로 정리했다. [수정 전 포즈](../art/mockups/f25-staff-greeting-v1/reviews/rejected-long-arm/keyposes.png)와 레시피·출력은 보존했다.

## 비교와 재현

기존 캐릭터 5명은 현재 게임의 `idle-fine.png` 원본을 96×144·1배로, 직원은 32×48·3배로 표시한다. 기존 캐릭터의 실제 `motion_index()`에 따른 18초·152구간 시간표를 사용한다.

두 비교 GIF는 20fps·360프레임·18초의 공유본이다. HTML과 별도 Godot 비교 화면은 원래 밀리초 단위 시간표를 사용한다. GIF의 50ms 간격은 원본 동작 시간표와 구분한다.

## 검증 결과

- 고유 자세 5개와 타이밍 출력 14개 모두 원본 5색·이진 알파·공통 외곽선, 보호 부위의 동일성을 확인했다. 기존 재질 후처리 전후 변화는 0픽셀이다.
- 어깨–팔–손목의 연결, 머리와의 틈, 열린 손 4픽셀, 기존 내려둔 손의 제거를 검사했다. 시작·끝은 정렬 원본과 같다.
- Godot 4.6에서 14구간·6초·반복 꺼짐으로 리소스를 로드했다. 기존 fine 시트 5장과 추출 320프레임, 18초 시간표도 원본과 일치했다. 두 비교 GIF의 모든 시점에서 캐릭터 픽셀 불일치는 0건이었다.
- 별도 Godot 1배 재생은 36.215초 기록했다. 기존 5명은 각각 152/152구간·2회, 판매 대기는 21/21구간·2회, 손 인사는 14/14구간·6회를 관측했다. 72개 시점 × 7개체, 총 504개체 표본에서 접지·정수 위치 오류는 각각 0건이었다.
- Computer Use로 27.58초의 손 내리는 화면을 확인하고, 엔진이 저장한 2.7초의 손을 흔드는 화면도 검토했다. 다른 창에 가린 캡처는 근거에서 제외했다. 이는 특정 시점의 화면과 엔진 재생 기록을 함께 확인한 결과이며 연속 영상 전체를 시각 분석했다는 뜻은 아니다.
- 제작 스크립트·HTML 스크립트·Godot 플레이어의 구문 검사를 통과했다. 플레이어에는 `--quit-after`를 추가해 지정한 재생 시간을 기록하고 자동으로 닫히게 했다. 이번 실행의 정상 종료도 확인했다.

## 파일 사용

프로젝트 루트에서 실행한다.

```powershell
node tools/build_f25_staff_greeting_v1.mjs
```

`--prepare-live` 옵션은 `.verification/f25-greeting-live/`에 별도 Godot 비교 프로젝트도 준비한다. 원본은 후보 폴더의 `source/*.txt`, Pixelbolt 레시피는 `recipes/staff.json`, Godot SpriteFrames는 `exports/staff/staff_sales_greeting.tres`다.

리소스를 사용할 때는 `.tres`와 같은 폴더의 PNG 시트를 함께 가져오고 `AnimatedSprite2D`에서 `greet`를 실행한다. [레시피](../art/mockups/f25-staff-greeting-v1/recipes/staff.json) · [시트](../art/mockups/f25-staff-greeting-v1/exports/staff/staff_sales_greeting.png) · [아틀라스](../art/mockups/f25-staff-greeting-v1/exports/staff/staff_sales_greeting.atlas.json).

직원 배치 D안과 기존 역할 아이콘은 유지한다. 이 동작은 비교용 후보이며 게임 런타임 연결은 포함하지 않는다.

재배 물 주기·조제 플라스크·판매 인사까지 제작했다. 다음은 원정 길잡이의 등불 동작이다.
