# 관리 먹색·세이지 적용 결과

2026년 10월 13일 · **관리 팔레트 구현 완료 / 격리 headless·파일 미리보기 검사 완료 / 실제 Windows 입력 미검증**

사용자가 확정한 먹색·세이지 팔레트를 관리 창 전체에 적용했다. 여섯 탭, 결과와 펼친 장부·상세, 추천·구매·조건 버튼, 직원·화면 설정, 체크 버튼·슬라이더·스크롤바·툴팁과 키보드 포커스에 같은 색을 사용한다. 적용 범위는 관리 UI다.

`management_palette.gd`가 관리 전용 Theme를 만들고 `management_panel.gd`가 실제 노드의 색을 연결한다. 일반 버튼의 hover·pressed·disabled와 미러 상태도 같은 계열로 맞추고, 포커스는 선택 표시와 별도로 유지했다. 기본 체크·슬라이더 UI 그림은 같은 크기와 알파·명암을 유지해 색을 맞췄다. 상품·명성·코인·원정 아이콘, 픽셀아트, 물약 색과 날씨 그림은 원본을 보존한다.

기존 호스트 Theme·폰트, 작업실 배치와 모델·경제·저장·RNG를 보존했다. 관리520px 폭, Pretendard 제목줄24px·제목18px·본문/탭/버튼16px·보조14px, 목록48px·보상32px 아이콘도 유지한다. 투명 구분선 행과 여섯 밑줄 탭, 환경 강조, 실제 작업 게이지,148px 원정 목록·전체 상세, 탭별 스크롤, 추천을 누르기 시작할 때의 구매 대상 고정 동작은 기존 구조를 유지한다.
