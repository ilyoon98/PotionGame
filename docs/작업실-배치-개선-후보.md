# 작업실 배치 개선 후보

> 가로 확장 최종 검수 통과 · 2026-10-10 · **540×288 적용 승인 / 개발 인계**: 분리 소품과 낮밤·대기 수정본을 검수했다. 약초 원본 크기·받침 비율·밤 문구·액체 영역 검사를 통과한 [승인 산출물과 연결 기준](작업실-가로-확장-검수결과.md)을 사용한다. 아래 제작 중/채택 전/배치 선택 대기 기록보다 이 결과가 우선한다. 520·560은 비교 자료다. 실제 런타임 연결과 화면 조작 완료를 뜻하지 않는다.

## 가로 확장 제작과 검수 진행

2026년 10월 10일 사용자가 **좌우로 넓힌 작업실 디자인 제작 → 완성본 검수 → 개발 적용**을 승인했다. 「투명 배경과 내부 디자인 조화」 채팅에 제작을 요청했고 540×288을 중심으로 520·560 폭과 분리 소품을 준비한다. [가로 확장 디자인과 검수 명세](작업실-가로-확장-디자인과-검수-명세.md)를 따른다. 가로 확장 방향은 승인되었고 최종 폭·좌표·에셋은 기획 검수 후 개발에 전달한다. 아래 채택 전·사용자 배치 선택 대기 기록은 이전 이력이며, 검수 전 런타임 개편은 진행하지 않는다.

## 확정된 대표 표시와 제작 대기

2026년 10월 8일 사용자가 승인한 고정 대표와 실제 제작·보관 대기 표시를 **구현 완료**했다. 솥 색·고정 대표·실제 활동 수·세 관리 진입 버튼과 입력 예외 논리는 격리된 headless 검사 통과이며 실제 화면 조작은 미실시다. [작업실 대표 게이지와 제작 대기](작업실-대표-게이지와-제작-대기-명세.md)를 최신 기준으로 사용한다. 아래 책상·포스터 소품·최종 창 너비와 위치는 별도 배치 선택 전까지 후보로 남긴다.

| 기본 화면 | 선택해서 확인할 내용 |
| --- | --- |
| 솥: 실제 현재 포션 아이콘·제조 게이지 1개·해당 물약 색상. 보관 가득이면 마지막 표시와 실제 진행을 유지하며 대기 | 기존 포션 탭의 재고·생산 상태 |
| 약초: 기본 약초 고정 성장 그림과 실제 게이지 1개, N종 재배 중 | 기존 약초 탭의 모든 품종·게이지·보관·환경 영향 |
| 원정: 첫 지역 고정 아이콘과 실제 게이지 1개, N곳 탐사 중. 포스터 외형은 배치 후보 | 기존 원정 탭의 모든 지역·진행·예상 결과 |

약초와 원정은 기본 약초와 첫 지역으로 고정한다. 가장 긴/짧은 작업을 다시 고르거나 랜덤으로 교체하지 않는다. 솥만 실제 다음 배치가 시작될 때 해당 물약 표시로 바뀐다. 제조는 한 번에 한 종류이며 `N종 제작 중`을 사용하지 않는다.

대표는 완료·대기·환경·신규 해금 이후에도 유지한다. 해당 대표가 기다리면 실제 게이지를 멈추고 짧은 대기 이유를 표시한다. 대표가 아닌 작업도 자기 조건에 따라 계속 진행한다. `N종 재배 중`, `N곳 탐사 중`은 현재 실제 실행 중인 전체 수로 대표를 포함하고, 구매 버섯·미해금 공급원·대기 항목은 제외한다. 전체 0개는 재배/원정 대기 표시다. 게이지는 대표 하나의 실제 주기 진행도이며 전체 평균이나 전체 재고량이 아니다.

누르는 행동은 상세 확인이다. 작업 시작·보상 수령·페이지 전환·자동화 설정을 요구하지 않는다. 새 상세 UI를 만들지 않고 기존 관리의 해당 탭을 연다. 사물 전체의 클릭 통과를 막지 않도록 실제 버튼/게이지 진입 영역만 검증하고, 그림은 계속 입력을 통과시킨다. 직접 사물 진입이 불가능한 상태에서는 기존 관리·원정 버튼의 같은 경로를 유지한다.

이전 이미지의 약초 3개·원정 2개 게이지 및 아래 페이지 후보는 비교 이력이다. 최신 확정 규칙은 약초 1개·원정 1개와 전체 진행 개수다. 다중 진행의 자세한 볼거리는 관리 목록에서 제공하고 기존 약초 성장 스프라이트를 유지한다. 솥 보관 대기와 판매 후 자동 재개를 정상적인 가게 흐름으로 표현한다. 선반의 시각적 병 자리 수와 실제 보관 한도는 별개다.

> 사용자 후속 지시: **예시 이미지를 보고 진행 여부를 결정한다.** 이번에는 대표·게이지·대기 규칙의 기획 반영을 승인했다. 새 가구 배치·소품 연결·폭 변경은 선택 전 진행하지 않는다. 기존 승인된 관리·결과·장기 균형 검증은 독립적으로 계속 진행한다.

## 이전 검토 이력 여러 대표와 페이지

아래 약초 3자리·원정 여러 행·페이지 제안은 최신 고정 대표 1개 규칙으로 대체된 검토 이력이다. 신규 제작 기준으로 사용하지 않는다. 사물 자체의 최종 배치는 위 배치 후보에서 결정한다.

### 콘텐츠 증가에 따른 확장 규칙 검토

2026년 10월 8일 사용자가 포션·약초 종류가 늘어났을 때의 확장성을 지적했다. **아래는 배치 후보의 보완 제안이며 채택 전**이다. 예시 이미지를 보고 진행 여부를 정한다는 조건을 유지한다. 품목 하나마다 새 가구와 화면 폭을 추가하지 않고 기존 소품의 고정 표시 자리와 데이터 목록을 분리한다.

| 소품 | 고정 표시 공간 | 종류가 늘어나는 경우 |
| --- | --- | --- |
| 솥 | 현재 제조 1개와 실제 게이지 | 새 레시피도 같은 솥의 자동 제조 순서에 합류. 품목 수 증가가 제조 라인 증가를 뜻하지 않음 |
| 물약 진열대 | 기존 실제 진열 자리 | 현재 재고의 실제 병을 표시하고 나머지는 보관. 포션 전체 종류·수량은 관리에서 확인. 모든 해금 품목을 한 병씩 소품에 억지로 전시하지 않음 |
| 약초 재배대 | 대표 품종 3자리 | 실제 공급원 목록을 3종씩 페이지로 확인하는 후보. 예: 10종이면 4페이지. 공급원이 늘면 페이지 수가 늘고 공간은 그대로 유지 |
| 원정 포스터 | 지역 진행 2~3행 | 열린 지역을 페이지로 확인하거나 관리에서 전체 확인. 지역 수만큼 포스터를 추가하지 않음 |

페이지는 사용자가 넘길 때만 바뀐다. 수확 완료·날씨·대기·진행률 때문에 순서나 그림을 자동 교체하지 않는다. 각 페이지의 숨긴 항목도 실제로 계속 진행하고 표시한 항목은 자신의 실제 게이지를 사용한다. 버섯 구매·원정 재료만 보유한 미해금 재배는 재배 페이지에 넣지 않는다. 포션별 동시 제작은 추가하지 않는다.

작업실에서 페이지를 직접 넘기는 버튼은 기존 투명 그림의 클릭 통과와 구분된 작은 입력 영역이 지원되는지 검증해야 한다. 지원 전에는 관리의 해당 목록에서 표시 페이지/품종을 선택하는 방법을 검토한다. 대표 페이지 선택은 경제·생산·보상에 영향을 주지 않는다. 이번 지적으로 즉시 페이지 버튼이나 자동 회전을 구현하지 않는다.

선반·재배대의 기본/개량/고급 외형은 기존 설비 성장 단계에 연결하는 후속 디자인 후보다. 개별 품종의 아이콘·성장 그림은 같은 고정 자리에 재사용한다. 추가 투자가 필요하지 않은 표시 변경에 새 생산 슬롯 구매나 강화 수치를 임의로 만들지 않는다.

- 약초: 기존 품종별 아이콘과 성장 그림을 작은 재배대에 나란히 놓고 각 그림 아래 실제 게이지를 붙인다. 대표 3종과 숨긴 공급원 수를 유지한다. 큰 화분 위에 별도 아이콘을 다시 쌓아 두지 않는다.
- 솥: 현재 물약 아이콘과 제조 게이지는 솥 바로 위 또는 아래에 둔다. 마녀·솥·불·제조 중 병을 가리지 않는다.
- 원정: 대표 2지역 아이콘·게이지와 숨긴 지역 수를 작은 포스터 안에 모은다. 포스터는 여행·조사의 소품이며 큰 책상이나 별도 인물 원정대를 요구하지 않는다.
- 판매: 현재 실제 진열 병을 유지한다. 책상은 시각적 받침이며 삭제·축소가 보관 한도·판매 속도·투자 수치를 바꾸지 않는다.
- 상호작용: 그림 영역 클릭 통과는 보존한다. 포스터·재배대 전체를 클릭 가능하게 만드는 것은 별도 입력 영역 검증 전 확정하지 않는다. 하단 관리·원정 진입을 계속 사용할 수 있어야 한다.

두 후보 중 하나를 채택한 뒤 소품 아트와 런타임 위치를 한 담당 범위씩 요청한다. 기존 UI·결과·장기 경제 검증은 계속 진행하고 두 배치를 한꺼번에 런타임에 넣지 않는다. 현재 Computer Use 금지와 실제 플레이어 저장 보존은 유지한다.
