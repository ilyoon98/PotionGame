# F25 직원 4명 신체 정렬

후속 요청으로 [실제 속도 검토와 타이밍 수정](직원-애니메이션-F25-실속도-검토.md)을 진행했다. 최신 움직임은 [직원+기존 캐릭터 동시 비교](../art/mockups/f25-staff-playback-v2/review.html)에서 확인한다. 아래는 정렬 작업 당시 기록이다.

2026-11-06 사용자 요청: 직원의 머리·가슴·다리 위치를 기존 기획과 캐릭터 기준에 맞추고 전후를 비교한다. 영상에서 소개된 Pixelbolt 스킬과 프로젝트에 고정한 0.11.0 엔진을 실제 사용했다.

[기존 캐릭터 + 수정 전후 비교](../art/mockups/f25-staff-alignment-v1/review.html) · [전후 PNG](../art/mockups/f25-staff-alignment-v1/comparison-3x.png)

PNG의 **윗줄은 수정 전, 아랫줄은 수정 후**다. 왼쪽부터 판매·재배·조제·원정 직원이며, 모두 같은 3배로 표시한다. HTML에는 기존 캐릭터 5명, 기준선 켜기/끄기, 원본 1배, 대기 움직임 재생도 있다. HTML의 이미지와 프레임은 내장되어 별도 서버가 필요 없다.

## 적용한 기준

| 부위 | 공통 기준 | 근거 |
|---|---|---|
| 원본 크기 | 32×48 | 기존 기획 |
| 머리 / 몸통 / 다리 | y11~26 / y27~39 / y40~46 | 기존 해부 기준표 |
| 눈 / 턱 / 발 | y22~23 / y26 / y46 | 여행자·마법사 원본과 제작 메타 |
| 목 / 가슴 / 허리 / 골반 | (14,27) / (14,31) / (14,35) / (14,37) | 여행자 체간을 참고해 이번에 공통 좌표 확정 |
| 좌우 무릎 | (12,40), (17,40) | 여행자 다리 구조 참조 |
| 좌우 발 접지점 | (11,46), (17,46) | 여행자 다리 구조 참조 |

이 좌표는 정지 기준이다. 기존 기획에 가슴·골반의 단일 XY 좌표까지 확정되어 있던 것은 아니다. 머리 프레임 `[3,11,25,27]`과 여행자의 몸통·다리 중심을 근거로 이번 직원 공통 축을 정했다. 기존 상점 주인은 원본부터 눈이 y19~20이고, 승인된 기존 캐릭터 그림은 수정하지 않았다. 모든 기존 캐릭터의 세부 좌표가 동일하다고 주장하지 않는다.

모자·올림머리·후드·가운 끝·소품의 전체 실루엣과 골격 기준은 구분한다. 방향이 다른 얼굴의 눈 X 좌표, 옷 폭, 신발 모양을 동일하게 만들지는 않았다. 신체 부위가 해당 기준에 실제로 놓이는지 그림과 부위별 마스크를 함께 확인한다.

## 실제 수정

| 직원 | 수정 내용 |
|---|---|
| 판매 보조 | 머리·몸통을 왼쪽 2픽셀 이동해 목과 체간 축 정렬. 치마 밑선을 y40에서 y39로 올리고 다리를 y40부터 배치. 양다리를 골반 아래로 정렬. |
| 재배 보조 | 모자와 눈은 유지. 아래 얼굴의 중복 한 줄을 줄여 턱을 y26에 닫고 목을 y27에 연결. 부츠 사이에 남아 있던 연결 픽셀을 정리해 양발을 분리. |
| 조제 보조 | 머리 구역 y26에 침범한 가운을 정리하고 목을 y27에 연결. 목 왼쪽에 생긴 3픽셀 틈을 기존 가운색으로 보완. 다리·장화를 오른쪽 1픽셀 정렬. |
| 원정 길잡이 | 눈을 3픽셀 내려 y22~23에 맞춤. 기존 17행 머리에서 아래 수염 한 줄을 정리해 머리 y11~26 유지. 목·목수건·가슴 접합 정리, 망토를 y39에서 닫아 y40부터 양다리가 보이도록 수정. |

색과 역할별 외형 콘셉트는 유지했다. 사용자가 이전에 직접 수정하기로 했던 부위도 **이번 위치 정렬에 필요한 이동·접합 수정**만 포함한다. 얼굴·옷·신발을 다른 디자인으로 교체하지 않았다. 원본 v2와 이전 움직임 후보는 그대로 보관한다.

## 제작과 검증

- 편집 원본: `art/mockups/f25-staff-alignment-v1/source/`의 32×48 텍스트 격자와 부위별 수정 기록.
- Pixelbolt로 레시피 검증, PNG·GIF·Godot `SpriteFrames` 출력. 기존 재질별 후처리 파이프라인을 거친 뒤 원본 픽셀 변화가 없는지 검사한다.
- 정지 + 들숨 + 깜빡임 + 들숨/깜빡임, 11개 타이밍 구간으로 9초 루프를 구성한다. 정지 정렬 기준은 호흡 중 머리와 목이 1픽셀 올라가는 것과 구분한다.
- 외곽선·원본 5색·이진 알파·눈 주위 피부 여백·양다리 분리·손과 소품 고정·발 접지·루프 접합을 확인한다. 각 부위의 재질과 영역을 별도로 기록한다.
- **검사 통과:** 4명 × 15프레임(4상태 + 11타이밍 구간), 후처리 전후 변화 0픽셀. 독립 확인에서도 텍스트 원본과 PNG 일치, 목 옆 틈 해결, 부츠 분리, 실제 신체 영역과 기준점의 일치를 확인했다. [validation.json](../art/mockups/f25-staff-alignment-v1/validation.json)
- **Godot 4.6 로드 통과:** 별도 검증 프로젝트에서 `SpriteFrames` 4개를 로드했다. 모두 대기 11프레임·9초·반복 재생과 정지 1프레임, 5색·이진 알파·발 아래 픽셀 없음이 정상이다. [godot-validation.json](../art/mockups/f25-staff-alignment-v1/godot-validation.json)
- 정지 전후 PNG와 프레임을 확인했다. HTML 스크립트 구문과 내장 이미지도 검사했다. 자동 브라우저의 로컬 접근 제한으로 실제 속도 재생의 시각 검증은 완료하지 못했다. 검사 통과와 사용자의 미술적 채택 여부는 별개다.

재현:

```powershell
node tools/build_f25_staff_alignment_v1.mjs
```

처음에는 `tools/pixelbolt`에서 `npm ci --ignore-scripts --no-audit --no-fund`로 고정된 엔진을 설치한다. 기존 후처리에는 Python·Pillow·NumPy가 필요하며 `PYTHON`으로 실행 파일을 지정할 수 있다. 재현 명령은 이 후보 폴더의 생성본을 갱신한다. 수정 원본은 `source`에 보관한다.

실제 게임 배치와 직원 역할 아이콘은 변경하지 않았다. 이번 결과는 정렬 수정과 비교를 위한 새 후보이다.

## 스킬 사용 안내

사용자가 준비할 사항과 요청 예시는 [픽셀아트 스킬 사용 가이드](픽셀아트-스킬-사용가이드.md), 영상의 8개 도구와 추가 3개 후보 비교는 [조사 문서](픽셀아트-스킬-조사와-적용.md)에 있다. 현재 작업에서는 기준 그림과 정렬 요청을 이미 받았으므로 사용자가 추가 설치나 좌표 입력을 할 필요는 없다. 비교 결과를 보고 수정할 인상이나 부위만 알려주면 된다.
