# 성장과 골드 사용처 초기 검토 보관

상태: 과거 검토안 보관. 현재 구현 지시가 아니다. 최신 내용은 [성장과 골드 사용처](../성장과-골드-사용처-테이블.md) 및 연결된 후속 기획안을 따른다. 아래 원정 반복 보급비·연구 타이머·손님 5종 등은 현재 규칙으로 적용하지 않는다.

작성 기준일: 2026년 10월 7일 · 상태: 구현 기준 연결과 상세 검토

**구현 범위의 단일 기준은 [메인 기획서의 확정 사항 F01~F12](../달그늘-물약상점-기획서.md#확정-사항과-구현-지시)다.** 이 파일의 시스템 존재 여부는 해당 ID를 따르되 직원 능력·보급비·지역·금액·시간·보상 수량은 상세 검토안이다. 표에 등장한다는 이유만으로 세부 규칙까지 승인된 것으로 취급하지 않는다.

**재료 조달·제조·판매는 완전 자동으로 유지하고, 플레이어는 번 돈으로 가게의 가능성을 늘린다.** 레시피 1회 구매, 아이템 구매, 설비 투자, 종업원 고용, 원정이 서로 다른 성장 목표를 맡는다. 명성은 새로운 구매·성장 기회를 여는 누적 성과다. 꾸미기의 구체적 품목은 후속 검토다.

현재는 솥·화분 강화와 버섯 자동 발주에 더해 레시피 1회 구매, 여과기, 판매 보조, 명성, 숲 원정, 영업 결과까지 연결되어 있다. 현재 값은 [구현 기록](../구현-임시값.md)의 개발용 임시값이며 출시 밸런스 확정과는 다르다. 최신 관리 UI는 `가게 운영 / 레시피 / 원정`으로 구분하며 레시피 구매 후 연구 대기 시간을 추가하지 않는다.

## 개발 이후의 후속 기획

사용자가 선택한 우선 기획은 **원정·새 레시피 콘텐츠**다. 구체적인 지역·발견·재료·물약·자동 공급·저장 원칙은 [원정과 신규 레시피 콘텐츠 기획안](../원정과-신규-레시피-콘텐츠-기획안.md)에 정리했다. 새 내용은 제안이며 기존 확정 범위를 자동으로 늘리지 않는다.

| 후속 후보 | 얻는 것 | 플레이어의 1회 선택 | 이후 자동 동작 |
| --- | --- | --- | --- |
| 숲 첫 발견 | 이슬풀 재배 표본 | 활력 레시피 구매, 첫 화분 포함 제안 | 재배→제작→여행자 선호 판매 |
| 온실 확장 | 은빛 이끼 표본 | 지역 개방·집중 레시피 구매 | 흐림에 유리한 재배·제조 |
| 유적 확장 | 달꽃 표본 | 지역 개방·야행 레시피 구매 | 밤에 유리한 재배·제조 |

첫 추가 버전은 숲의 발견과 활력 물약 한 종류부터 검토한다. 원정 반복 보급비·직원 필수 배치·연구 대기 시간은 사용하지 않는다. 아래 이전 상세안의 해당 제안보다 최신 후속 기획을 우선한다.

## 이전 성장 후보의 참고 범위

아래는 초기 기획 때 비교했던 소비·고용·지역·출시 범위다. 현재 구현 목록이나 새 확정 지시로 읽지 않는다. 특히 과거의 손님 5종·여기사, 반복 원정 보급비, 연구 완료 타이머, 결과 열기 시 집계 초기화, 종료 중 진행은 현재 적용 규칙이 아니다. 실제 손님은 4종이며 원정에는 반복 비용이 없고 결과 집계는 사용자가 새 집계를 선택할 때만 바뀐다.

| 영업 결과와 도감 | 지난 성과와 다음 목표 확인 | 없음 | 이미 반영된 수익·연구·명성·원정 결과를 요약 | 1차 핵심 |

투자는 우선 가게 시설과 원정 거점에 대한 영구 투자로 정의한다. 금융 상품처럼 골드를 넣고 이자만 받는 기능은 초기 설계에 포함하지 않는다. 같은 기능에 연구비·해금비·구매비를 연달아 붙이지 않고 각 지출이 별도의 결과를 주도록 한다.

## 레시피와 아이템 구매의 구분

| 단계 | 예시 | 결제와 완료 규칙 |
| --- | --- | --- |
| 구매 후보 공개 | 명성 등 조건에 따라 새 레시피 공개 | 공개 조건은 미정. 비용과 해금 결과를 표시 |
| 레시피 구매 | 골드로 새 레시피 구매 | 한 번만 차감하고 보유 저장. 연구 대기 시간 없음 |
| 자동 제작 합류 | 재료가 있는 구매 완료 레시피 사용 | 제조 버튼 없이 자동 사용. 재료가 없으면 기존 생산으로 복귀 |
| 후속 구매 | 여과기, 화분 증설, 더 큰 재료 보관함 | 각자 명시된 성능을 주는 별도 구매 |

레시피 구매는 플레이어가 선택하지만 이후 재료 조달·제조·판매는 자동이다. 첫 재료 공급원을 레시피와 함께 지급하는지는 미정이다. 레시피 구매 화면을 열었다고 자동 제조를 중단하거나 수동 재료 투입을 요구하지 않는다.

구매 화면에는 비용, 보유 여부, 해금 결과를 보여준다. 구매 완료된 레시피에 다시 비용을 청구하지 않는다. 기존 체력·마나 물약을 구매 UI 도입 때문에 다시 잠그지 않는다. 선행 구매·명성 조건은 서로 순환하지 않게 한다.

## 설비 투자와 돈을 쓰는 이유

| 투자 대상 | 바뀌는 수치 | 해결하는 문제 | 다른 소비와의 구분 |
| --- | --- | --- | --- |
| 약초 화분 | 수확 간격·재료 보관량 | 재료 부족 대기 | 특수 계열 최초 해금은 연구에서 처리 |
| 솥 | 제조 시간 | 생산 속도 부족 | 성공률 보정은 별도 도구가 담당 |
| 여과기 | 특수 포션 성공률 | 재료 손실과 연속 실패 | 확률 상한 유지, 날씨 효과를 지우지 않음 |
| 판매대 | 기본 판매 처리량 | 생산은 빠르지만 진열대가 계속 가득 참 | 단순 재고 칸 확장과 구분 |
| 창고·진열 공간 | 재료·완성품 보관량 | 수확·판매 간 시간차로 생기는 일시 대기 | 판매 속도 자체는 증가하지 않음 |
| 가게 확장 | 직원 자리·추가 설비 접근 | 다음 성장 계열의 공간 부족 | 초기에는 기존 한 방 안의 슬롯 확장 |

현행 솥 6·화분 3과 최고 레벨의 지속 수입이 동일했던 병목 분석을 반영해 판매대 확장을 생산 강화와 함께 검증한다. 구매 화면은 무엇이 얼마나 바뀌는지 보여주고, 현재 병목과 무관한 강화의 수입 효과를 과장하지 않는다.

초기 가격은 해당 해금 단계의 안정적인 운영 순수입을 기준으로 맞춘다. 작은 소비는 몇 분, 중간 연구·설비는 수십 분, 큰 가게·원정 확장은 여러 번의 플레이에 걸쳐 모으는 목표로 나눈다. 이는 조정 방향이며 확정 가격표가 아니다. 실제 판매가 정해지면 기본 매출·재료비·실패·해금 순서가 포함된 시뮬레이션으로 고정 가격을 정한다. 사용자가 돈을 더 벌었다고 같은 상품의 가격을 실시간으로 올리지 않는다.

## 명성과 손님의 연결

명성은 누적 영업 성과이며 소비하거나 매일 초기화하지 않는다. 초기 획득원은 실제 판매와 첫 레시피·손님 거래 기록으로 제한한다. 선호 물약 거래에는 작은 추가 명성을 주되, 같은 손님과의 거래 한 번을 일반·선호 거래로 중복 집계하지 않는다.

| 명성 단계 예시 | 다음에 열리는 기회 | 플레이어의 다음 소비 |
| --- | --- | --- |
| 작은 가게 | 첫 환경 레시피 연구 | 연구비 |
| 동네에서 알려진 가게 | 새 도구와 판매대 확장 | 설비 구매 |
| 단골이 생긴 가게 | 첫 종업원과 훈련 | 고용비·훈련비 |
| 소문난 연금술 상점 | 외곽 탐색 거점 | 거점 투자·원정 보급 |

단계명과 해금 순서는 초기안이다. 명성 조건을 구매할 물건과 함께 미리 보여주고, 조건 달성과 실제 구매를 구분한다. 현금으로 명성만 사거나 명성을 소모해 연구하는 구조는 넣지 않는다.

기본 손님 외형은 사용자가 제시한 여행자·여기사·여마법사·엘프·고양이 도적 5종을 기준으로 한다. 이름은 역할명이며 초기 손님을 곧바로 종업원으로 취급하지 않는다.

| 손님 | 방문 경향 | 방문 가능성이 더 높은 날씨 | 선호 품목의 성장 후보 |
| --- | --- | --- | --- |
| 여행자 | 항상 방문 가능 | 모든 날씨 | 체력 → 활력 |
| 여기사 | 낮에 자주 방문 | 맑음 | 체력 → 철피부 |
| 여마법사 | 밤에 자주 방문 | 흐림 | 마나 → 달빛 |
| 엘프 | 낮·밤 모두 | 비 | 정화 |
| 고양이 도적 | 밤에 자주 방문 | 맑음 | 민첩 |

시간·날씨는 초기에는 출현 비중을 바꾸는 조건으로 사용한다. 여행자는 항상 방문 후보에 남긴다. 선호 품목이 없거나 아직 해금 전이면 기존 물약을 구매한다. 선호 거래는 추가 금액과 명성을 주고, 클릭 응대나 손님용 재고 예약은 요구하지 않는다. 정화·활력·철피부·민첩은 새 레시피 후보이며 한 번에 모두 추가하지 않는다.

## 종업원 상세 검토

종업원은 이미 자동인 일을 더 잘하게 하거나 자동 탐색을 담당한다. 직원을 고용하지 않아도 재료 조달·제조·판매는 계속된다. 처음에는 고용비와 훈련비만 사용하고 급여·피로·식사 관리·이탈은 제외한다. 반복 골드 소비는 원정 보급이 맡는다.

| 직원 후보 | 자동으로 하는 일 | 골드를 쓰는 곳 | 첫 구현 범위 |
| --- | --- | --- | --- |
| 판매 보조 | 선호 물약 거래의 추가 보상 향상 | 고용·접객 훈련 | 첫 종업원 1명. 기본 판매 처리량은 판매대 설비가 담당 |
| 연금술 조수 | 실패 잔재의 회수량 향상 | 고용·회수 훈련 | 이후 추가. 여과기의 성공률 효과와 분리 |
| 탐색 담당 | 선택된 지역의 자동 원정 반복 | 고용·탐색 훈련 | 원정 도입 때 전용 1명 |

초기에는 담당별 전용 자리에 배치하고 한 사람이 가게와 원정 양쪽 효과를 동시에 내지 않게 한다. 근무표나 매일 재배치하는 관리 요소는 넣지 않는다. 기존 손님의 고용 가능 전환은 나중의 관계 콘텐츠로 남긴다.

## 원정 상세 검토

원정의 별도 메뉴와 활성화 후 자동 진행은 F06을 따른다. 아래 지역·직원 배치·반복 보급비·연구 단서·수집품 규칙은 상세 후보이며 아직 그대로 구현할 사항이 아니다. 원정 UI와 기본 진행 구조를 직원 고용 시스템 완성까지 막아둘 필요는 없다.

플레이어는 거점을 열고 탐색 담당과 지역을 한 번 정한다. 이후 보급비 차감 → 탐색 → 귀환 → 보상 반영 → 재출발이 자동으로 이어진다. 가게의 기본 생산은 원정 중에도 계속된다. 원정에는 일시정지 기능을 제공한다.

| 지역 후보 | 초기 보상 | 가게에 남는 성장 | 순서 |
| --- | --- | --- | --- |
| 숲 가장자리 | 연구 단서·소량의 범용 재료 | 원정 연구 진척과 첫 기념 소품 | 첫 지역 |
| 버려진 온실 | 특수 화분 개량용 표본 | 기존 자동 재배의 확장 | 후속 지역 |
| 달빛 유적 | 상위 레시피 단서·유물 소품 | 고급 연구와 수집 | 후속 지역 |

원정 전용 단서는 기본 레시피 연구에 요구하지 않는다. 원정에서 가져온 단서는 후속 연구의 진척으로 자동 누적한다. 최소 보상은 보장하고 희귀 발견을 추가한다. 첫 핵심 발견에는 반복 횟수에 따른 보장 조건을 두는 안으로 검증한다. 확률·보장 조건은 출발 전에 보여주며 희귀 재료를 직접 클릭해 수령하지 않는다.

보급비는 매 출발 때만 한 번 차감하고, 예비금을 침범하면 새 출발을 대기한다. 이미 출발한 원정은 추가 차감 없이 끝낸다. 발주와 원정의 자동 지출은 같은 자금 검사 순서를 사용하고 기존 버섯 발주를 먼저 처리해 이중 예약·마이너스 골드를 막는다. 예비금은 초기에는 기존 30 G를 기준으로 검증하고 원정 비용에 맞춰 재조정한다.

귀환 보상의 재료 보관함이 가득 차면 초과분은 완료된 원정 1회분에 보존하고 재출발을 대기한다. 공간이 생기면 자동 입고·재개한다. 보상을 버리거나 무한 임시 창고를 만들지 않는다. 연구 진척과 소품 해금처럼 공간을 쓰지 않는 보상은 즉시 기록한다.

일반 귀환까지 20~40분을 초기 테스트 범위로 검토한다. 이는 확정 시간이 아니다. 초기에는 짧은 원정을 매번 수동으로 보내는 기능과 유료 즉시 완료를 넣지 않는다. 종료 중 진행을 지원할 때는 인정 시간 안에서 보급비·보상·보관 한도를 동일하게 계산한다.

## 돌아왔을 때의 영업 결과

결과 창은 이미 반영된 성과를 요약한다. 확인 버튼이 돈·아이템·명성을 지급하는 조건이 되지 않으며, 완료된 연구와 원정도 수령을 기다리느라 멈추지 않는다. 작은 모드에서는 조용한 기록 표시만 제공하고 사용자가 가게나 기록을 열면 상세 내용을 보여준다.

| 결과 항목 | 보여줄 내용 | 다음 행동 |
| --- | --- | --- |
| 골드 | 판매 매출, 재료비, 원정 보급비, 순영업수입 | 다음 구매까지 남은 금액 확인 |
| 생산 | 약초별 수확량, 포션별 성공·실패·판매 병수 | 부족한 설비 강화 |
| 손님 | 방문 수, 선호 거래, 첫 만남 | 손님 도감과 선호 품목 확인 |
| 연구·해금 | 완료 연구와 새로 열린 상품 | 다음 연구·구매 선택 |
| 명성 | 증가량, 현재 단계, 다음 조건 | 다음 성장 목표 확인 |
| 종업원·원정 | 완료 횟수, 비용, 주요 발견, 대기 사유 | 훈련·지역 변경·보관 확장 |

요약 기간은 마지막으로 결과를 확인한 시점부터 현재까지로 명시한다. 앱을 켜둔 채 다른 작업을 한 기간과 앱 종료 기간을 구분하고 종료 중 인정 시간 상한도 표시한다. 중간에 사용자가 직접 쓴 연구비·강화비·구매비는 별도 항목으로 기록해 보유 골드 변화와 대조할 수 있게 한다.

예시 수치는 화면 설명용이다.

> 지난 30분 영업 결과  
> 판매 매출 3,000 G − 재료비 500 G − 원정 보급비 200 G = 순영업수입 2,300 G  
> 달꽃 18개 수확 · 달빛 포션 12병 완성 · 선호 거래 3건  
> 달빛 연구 완료 · 명성 +24 · 숲 원정 1회 귀환  
> 다음 목표: 판매대 확장 / 첫 종업원 고용

지출과 보상은 발생한 시점에 한 번만 기록한다. 결과 창을 다시 열거나 재실행해도 중복 지급하지 않는다. 기본 운영에는 기록을 다시 보는 것 외의 추가 조작을 요구하지 않는다.

## 장기 확장 순서 검토

아래 표는 장기 검토용이며 이번 구현 순서는 메인 기획서의 확정 절을 따른다. 투명 작업실과 관리 패널을 먼저 연결한다.

| 단계 | 포함할 기능 | 완료 조건 |
| --- | --- | --- |
| 1 환경과 자동 생산 | 환경 저장, 특수 약초·포션 1종, 손님 선호 구매 | 해금 뒤 조작 없이 수확·제조·판매가 이어짐 |
| 2 성장과 성과 | 레시피 1회 구매, 명성, 판매대 투자, 영업 결과 | 번 돈으로 다음 목표를 사고 효과를 확인할 수 있음 |
| 3 상주 경험 | 투명 노점, 첫 장식, 종료 중 진행, 배율·성능 검증 | 작은 화면과 재접속에서도 진행·기록·저장 일치 |
| 4 종업원 | 판매 보조 1명, 고용과 훈련 | 기본 자동화는 유지되고 직원 효과와 비용이 명확함 |
| 5 원정 | 탐색 담당 1명, 지역 1곳, 자동 보급과 귀환 | 예비금·보관 한도·중복 보상 검증, 가게 운영 지속 |

공개 데모의 필수 범위는 1~3단계로 두고, 종업원과 원정은 그 다음 확장으로 둔다. 원정이 더 재미있다는 이유만으로 기존 자동 생산·환경·손님 연결을 미완성 상태로 늘리지 않는다.

검증에서는 연구 완료와 재료 공급의 연결, 자동 제조의 해금 전후 기대 수익, 골드 0에서의 기본 운영 복구, 자동 발주와 원정의 자금 경합, 저장 복원, 보관 한도, 종료 중 중복 보상을 확인한다. 현재 단계는 기획 문서이며 위 시스템의 구현·테스트 완료를 뜻하지 않는다.
