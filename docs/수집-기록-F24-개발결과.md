# 수집 기록 F24 개발 결과

> 2026-11-05 · 브랜치 `feature/f22-regulars` · **구현·격리 검사 완료, 실제 Windows 화면 미검증.** 사용자가 "쭉쭉 진행해봐"라고 해서 [성장과 단골 꾸미기 기획안](성장과-단골-꾸미기-기획안.md)의 "콘텐츠가 한 차례 끝났을 때" 절을 골라 진행했다: *준비된 레시피와 소장품을 모으면 현재 콘텐츠를 완성했다는 기록을 보여준다.*

## 화면

관리 · 통계에서 "주인공 · 숙성" 다음, "단골 손님" 앞에 **수집 기록** 구역을 추가했다.

| 행 | 기준 |
| --- | --- |
| 레시피 | 처음부터 가진 체력·마나를 뺀 일반 레시피 30종 중 보유 |
| 특별 레시피 | 특별 레시피 4종 중 발견·구매 완료 |
| 원정 조사 완료 | 8지역 중 조사 횟수를 채운 지역 |
| 단골 기념품 | 4종 중 받은 것(단골 단계) |
| 판매대 소품 | 2종 중 산 것 |

각 행은 `보유 / 전체`로 보이고, 다 모으면 `· 완료`와 함께 세이지 색이 된다. 다섯 행을 모두 채우면 아래에 "준비된 레시피와 소장품을 모두 모았어요. 가게가 완성됐어요."가 나타난다. 기획안대로 골드를 빼앗거나 새 목표를 강요하지 않는다.

## 원칙

- 읽기 전용이다(`Status.collection` / `collection_complete`). 저장 형식·경제·RNG를 바꾸지 않는다.
- 통계 화면의 기존 17칸(`statistics_values`)과 섞지 않고 별도 `collection_values`에 둔다. 통계 화면에는 버튼을 넣지 않는다.
- 투자 단계(설비·직원·숙성 등)는 "소장품"이 아니므로 넣지 않았다. 필요하면 다음에 추가한다.

## 검증

`tools/verify_f24_collection.gd` 12개 통과: 새 게임 0/전체, 일부 보유 계산, 전부 보유 시 완성, 계산·화면 열람이 모델을 바꾸지 않음, 화면 문구·완성 줄 표시, 통계 화면 버튼 없음.
