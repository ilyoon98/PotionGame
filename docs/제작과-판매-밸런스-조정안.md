# 제작과 판매 밸런스 조정안

작성일: 2026-10-08 · 후보 C · **기획용 비교안, 게임 미적용·최종 수치 확정 전**

> 개발 반영 · 2026-10-08: **현재 게임의 판매대·병목 안내·저장 연결과 실제 로직 측정 완료**. 아래 32종·8지역 독립 모델 전체를 게임에 적용한 상태는 아니다. 판매대는 현재 숲 조사 조건으로 1~3단계까지 구매 가능하고, 신규 레시피와 4지역 조사가 필요한 조제 보조는 전체 확장 연결 대상으로 남는다. 현재 게임의 2시간 완료·장기 재고 적체 한계는 [실제 적용 결과](후보-C-실제게임-적용결과.md)에서 별도로 확인한다.

확정 방향은 [재고와 손님 대기 균형 기준](재고와-손님대기-균형.md)이다. 공급이 부족하면 조제 투자가, 재고가 쌓이면 판매 투자가 도움이 되어야 한다. 아래 수치는 그 방향을 검증하기 위한 후보이며 강화 구매는 계속 플레이어가 선택한다.

## 이번에 조정하는 두 항목

판매대는 거래 간격을 줄인다. 기존 후보 B의 최종 2초는 중반 제조량에 비해 느려 재고가 오래 가득 찼다. 조제 보조는 후반 특수 물약의 제조 시간을 줄여 판매 강화 후 부족해진 공급을 보완한다. 후보 B의 조제 훈련 최종 시간 배율 0.90을 후보 C에서는 0.72로 낮춘다.

가격·손님 선호·원정 시간·레시피 제조 배율·성공률·기존 솥 14회와 화분 11회·창고 용량은 B에서 유지한다. 날씨별 손님 전체 방문 속도나 강제 품절을 새로 넣지 않는다. 2시간 뒤 성장 목표가 남는지도 함께 다시 계산한다.

고용 직후는 ×0.95다. 배율은 누적 곱셈이 아니라 해당 단계 최종값이다. ×0.72는 직원이 없을 때의 신규 물약 제조 시간에서 28% 단축하는 뜻이다. 기존 체력·마나·달빛·정화·민첩에는 이 신규 레시피 시간 효과를 적용하지 않는다. 훈련의 품질 보너스는 B와 동일하다.

## 돌아왔을 때 이해할 상태

| 눈에 보이는 상태 | 짧게 설명할 원인 | 살펴볼 다음 투자 |
| --- | --- | --- |
| 완성품이 쌓여 제작이 멈춤 | 판매보다 제작이 빠름 | 판매대 다음 단계 |
| 재료는 있는데 손님이 물약을 기다림 | 제작보다 판매가 빠름 | 솥 또는 조제 보조 |
| 특정 상위 물약 대신 다른 물약을 제작함 | 해당 품종 재료가 부족함 | 건조대·재배 보조·해당 지역 |
| 거래가 이어지고 재고가 천천히 움직임 | 현재 공급과 판매가 비슷함 | 새 레시피·품질·다음 지역 |

관리 화면에는 현재 이유 한 줄과 관련 투자로 가는 동선만 우선 보여준다. 분당 공급량·성공률·계산식은 상세에 둔다. 구매 조건을 만족하지 못하면 필요한 지역 조건을 표시하고, 최대 단계에는 추가 강화를 추천하지 않는다. 날씨 하이라이트는 약초·물약 목록의 해당 행에 표시한다.

보관장은 변화를 견디는 여유를 늘린다. 제작보다 판매가 느린 원인을 해결하는 설비라고 설명하지 않는다. 추천은 자동 결제가 아니며 창을 닫아도 운영은 계속된다. 구체적인 추천 판정 임계값과 새 화면 구성은 후속 UI 제안이다.

## 계산과 검증

| 원정·레시피 우선의 비교 결과 | B | C |
| --- | --- | --- |
| 120~240분 평균 재고 / 보관 한도 | 98.0~98.1% | 41.8~45.4% |
| 같은 구간 품절 손님 대기 시간 | 0% | 4.0~4.5% |
| 120분 보유 물약 | 이전 후보 기록 참조 | 18/32종 |
| 모든 레시피 구매 | 293.0~297.5분 | 285.0~288.5분 |
| 전체 투자·고용 | 398.5~400.5분 | 383.5~386.5분 |

2시간에 물약 14종과 지역 조사 4곳, 투자 약 절반이 남는다. 주요 레시피는 약 4시간 45분~4시간 49분, 전체 투자는 약 6시간 24분~6시간 27분이다. 설비 우선은 120~240분 평균 재고가 94.9~96.4%로 여전히 높다. 현재 안이 모든 전략의 줄타기를 완성한 것은 아니다.

분리 비교에서는 솥 10→11이 품절 대기 시간을 19.2~27.2%에서 5.3~16.5%로 줄였다. 판매대 5→6은 재고 가득 시간을 19.3~20.1%에서 12.5~13.8%로 줄이고 판매 병 수를 늘렸다. 조제 훈련 4→5는 품절 대기를 5.7~8.9%에서 0~0.2%로 줄였다. 판매대 강화 한 번으로 가득 찬 재고가 반드시 모두 비워지는 것은 아니다.

최신 숫자와 전략별 한계는 [성장 속도 검증](성장-속도-검증.md)에 기록한다. B와 C를 같은 0.05초 계산 간격·3난수·3구매 전략으로 비교했다. 이전 0.25초 결과를 C의 개선 폭 계산에 섞지 않는다.

0.025초로 계산 간격을 더 줄인 1회에서도 적체 감소와 2시간 미완료 방향은 유지됐다. 해당 중반 평균 재고는 약 49%로 달라졌으므로 이 비율을 실제 엔진에서 보장하는 숫자로 사용하지 않는다.

제작·판매·조제 훈련은 같은 진행 상태에서 한 항목의 단계만 바꾸고 다른 구매를 10분간 멈추는 분리 비교도 수행한다. 이는 효과의 방향을 보는 기획 실험이며 실제 비용 결제·저장·창 조작 검증은 아니다. 모든 강화 직후 품절과 적체가 반드시 뒤집힌다고 약속하지 않는다.

재고가 90% 이상이고 품절 대기가 없는 구간이 30분 넘게 이어지면 후속 조정 대상으로 기록한다. 특히 새 레시피보다 솥에 집중 투자하는 경로는 같은 판매대 단계로 기본 물약의 빠른 공급을 모두 소화하지 못할 수 있다. 이 경로를 숨기거나 투자 선택을 막지 않는다.

## 개발 연결 기준

1. `content-data-v1.json`의 `revision=candidate-c`와 대응 계산 결과를 한 쌍으로 사용한다. [콘텐츠 연결표](콘텐츠-연결표와-가격표.md)가 같은 데이터를 펼친 표다.
2. 판매대 `customer_seconds`와 조제 훈련 `new_recipe_time_multiplier`만 이번 B→C 차이다. 기존 물약·재료·진행·골드·원정·보관 재고를 유지한다.
3. 강화해도 현재 손님을 다시 생성하거나 같은 거래를 두 번 결제하지 않는다. 제조 재료를 다시 소모하거나 이미 고정한 성공 판정을 다시 뽑지 않는다. 제작 진행률은 보존하고 남은 시간 표시를 새 속도에 맞춘다.
4. 실제 게임에서 30·60·120분의 제조 수·판매 수·재고·제조 정지·손님 대기를 기록한다. 5분 창도 남겨 평균이 긴 적체를 가리지 않게 한다.
5. 기존 높은 솥 단계 저장과 새 게임을 따로 확인한다. 수치 후보를 적용했다고 저장 이전·전체 에셋 연결·관리 탭 선택까지 완료한 것으로 처리하지 않는다.

모델 재실행 순서는 `build_data.py` → B와 C의 `simulate.py` → `verify_upgrade_effects.py` → `report.py`다. B 비교 입력은 `content-data-candidate-b.json`, B 결과는 `simulation-candidate-b-refined.json`, C 결과는 `simulation-results.json`이다. 과거 B 원본은 `simulation-candidate-b-original.json`으로 보존한다.
