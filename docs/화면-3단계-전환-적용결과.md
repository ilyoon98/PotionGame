2026-10-08 · **구현 완료 / 자동·GPU 렌더 검사 통과**

## 확정 동작

| 현재 화면 | 축소 | 확대 |
| --- | --- | --- |
| 본모드 | 최소모드(마녀·솥) | 최대 단계이므로 버튼 비활성화 |
| 최소모드 | 정보모드(골드·수입·제작 진행) | 본모드 |
| 정보모드 | 마지막 단계이므로 버튼 비활성화 | 최소모드 |

이전 화면 이력에 따라 정보모드에서 본모드로 건너뛰던 동작을 제거했다. 관리의 정보모드 바로가기로 들어간 경우도 확대는 최소모드를 거친다. Esc와 이동 버튼 더블 클릭도 한 단계 확대에 맞춘다. 본모드는 마지막으로 선택한 투명 작업실 또는 기존 실내 화면을 유지한다. 이전 SMALL 화면은 저장 호환용으로 읽되 앱 시작 시 최소모드로 연결하며 별도 화면 버튼으로 노출하지 않는다.

## 하단 UI

본(투명 작업실)·최소·정보 화면에 공통 28×28 이동·축소·확대·종료 버튼과 42×28 금색 관리 버튼을 제공한다. 18px 아이콘과 버튼 배경·테두리·호버 스타일을 공유한다. 이동은 왼쪽, `관리 → 축소(—) → 확대(사방 화살표) → 종료(X)`는 오른쪽에 고정한다. 사용할 수 없는 단계의 버튼도 같은 자리에 회색으로 남긴다. 최소모드에도 종료가 있으며 버튼이 추가되거나 사라져 자리가 바뀌지 않는다. 각 모드의 창 너비·그림 영역·정보 영역은 유지했다.

최소 화면의 기존 256×160 크기, 128px 그림 영역과 3px 제작 게이지를 유지한다. 본모드 408×288과 정보모드 320×112도 유지한다. 실제 창을 작업 표시줄로 숨기는 동작은 이 축소 버튼에 연결하지 않는다. 상시 최상단 동작도 유지한다.

## 저장과 게임 상태

저장 버전 8에 선택적 `main_window_mode` 필드를 추가했다. 기존 버전·해당 필드가 없는 저장도 읽는다. 골드·예약 재료·제작 진행·재고 순서·고객·원정 출발비·보상·RNG는 변경하지 않는다. 잘못된 복귀 모드는 저장 전체를 변경하기 전에 거부한다.

## 검사

하단 간격 후속 검사: `verify_toolbar_spacing.gd`에서 스크린샷의 148,634 G를 포함한 0~999,999,999,999 G와 낮밤·날씨별 아이콘을 사용해 항목 사이 최소 8px, 전체 경계 포함, 골드 문자열이 고정 슬롯 안에 들어감, 정확한 금액 툴팁과 드래그 연결을 확인했다. `verify_three_stage_modes.gd`, `verify_expedition_feedback.gd`, `verify_window_mode_anchor.gd`도 headless 통과. 로그: 워크스페이스 `.verification/toolbar-spacing.log`, `spacing-flow.log`, `spacing-expeditions.log`, `spacing-anchor.log`. GPU 픽셀과 실제 사용자 조작 검사는 하지 않았다.

축소 방향 후속 검사: `verify_window_mode_anchor.gd`에서 본 → 최소 → 정보 → 최소 → 본, 직접 정보 진입, 반복 왕복 시 위치 표류 없음, 최소 창 이동 후 현재 위치 기준 확대, 서로 다른 바 높이 및 너비에서 오른쪽 버튼 중심 보존, 음수 좌표를 포함한 모니터 경계 보정을 확인했다. `verify_three_stage_modes.gd`, `verify_companion.gd`도 headless 통과했다. 로그는 워크스페이스 `.verification/window-anchor.log`, `anchor-flow.log`, `anchor-companion.log`다. 실제 네이티브 창을 움직이거나 사용자 마우스·키보드를 조작하지 않았다.

후속 배치 수정 검사: `verify_three_stage_modes.gd`, `verify_companion.gd`, `verify_management_gauges.gd` headless 통과. 세 화면의 버튼 순서·동일 크기/아이콘/스타일·오른쪽 기준 위치·경계·겹침 없음, 비활성 버튼 무동작, 관리·종료 연결, 3단계 왕복과 저장·경제 보존을 확인했다. 별도 APPDATA를 사용했으며 로그는 워크스페이스 `.verification/toolbar-slots.log`, `toolbar-companion.log`, `toolbar-management.log`에 있다. 실제 화면 조작·GPU 렌더 검증은 이번 후속 수정에서 미실시다.

아래는 이전 전환 기능 구현 시 검사 이력이다.

- `verify_three_stage_modes.gd` 및 `--render`: 투명 본모드와 기존 실내 각각 실제 버튼으로 4회 왕복, 관리 직접 정보 진입, Esc, 저장 후 복원, 상태 보존, 공통 버튼 크기·스타일과 자동 운영 검사 통과.
- `verify_compact_progress.gd`: 정보 화면 골드·수입·제작, 항상 위 유지, 자동 운영, 정보 → 최소 → 본 복귀 통과.
- `verify_companion.gd --render`: 최소 화면 크기·환경 5종·관리 3탭·진행 정보·복귀 통과.
- `verify_desktop_lifecycle.gd`: 본 → 최소 → 정보 → 최소 → 본 단계별 native 보조 프로세스 종료·재시작, 128/248px 그림 영역, 종료 후 남은 보조 프로세스 없음 통과.
- `test_shop.gd`, `test_progression.gd`: 경제·저장·원정·제조 검사 통과.
- `--smoke-test`, `verify_main_pixel_light.gd`: 실제 GPU 렌더·기존 자동 운영·수동 강화·공통 화면 전환·조명 검사 통과.

`.verification/three-stage-modes/mode-3.png`, `mode-4.png`, `mode-2.png`를 확인해 하단 버튼과 골드가 겹치지 않는 것을 확인했다. 테스트는 별도 APPDATA를 사용했다. Computer Use나 실제 마우스·키보드 입력은 사용하지 않았다. 실행 중인 플레이어 게임은 종료하지 않았으며 다음 정상 실행에 변경사항이 적용된다.
