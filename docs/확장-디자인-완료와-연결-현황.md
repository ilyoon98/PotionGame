## 콘텐츠 아트

전체 **67개 품목**이다. 레시피는 물약 아이콘을 공유한다.

| 분류 | 준비 범위 |
| --- | --- |
| 물약·레시피 | 32종: 기존 5종 + 신규 27종. 목록 아이콘과 12×16 병 32개 |
| 재료 | 11종: 기존 3종 + 신규 8종 |
| 원정 지역 | 8곳: 기존 1곳 + 신규 7곳 |
| 설비 | 8계열 × 기본·개량·고급 = 24개 아이콘 |
| 직원 | 4역할: 판매 보조 재사용 + 신규 3역할 |
| 물약 강화 | 활력·비술·자연·기교 4계열 |
| 재배 표현 | 성장 시트 10품종. 자동 발주 달빛 버섯은 재배 시트 대상에서 제외 |

신규 생성 원본 57개, 공용 단계 표시 SVG 8개와 분류별 비교 시트를 함께 보관한다. 투자·훈련 125회는 계열 아이콘과 단계 표시를 조합하며 125개 독립 그림으로 만들지 않는다. 지역 기념품 8종은 이번 제작 범위 밖의 후속 후보다.

[아트 검증 기록](../assets/content_expansion_v1/verification/art-validation.json)은 경로·크기·투명 알파·병 32개 중복 여부·성장 프레임 변화·설비 단계 차이 검사를 통과한 것으로 기록한다. [기존 에셋 보존 기록](../assets/content_expansion_v1/verification/approved-preservation.json)도 제공한다. 기획 담당은 기록과 목록을 확인했으며 제작 담당의 전체 시각 검토를 별도로 다시 수행한 것은 아니다.

## 화면 시안

관리 화면은 각각 460×660이다. 기존 3탭은 가게 운영 안에서 재고와 시설·직원을 구분하고, 제안 4탭은 `가게 / 성장 / 레시피 / 원정`으로 나눈다. 4탭 추천은 **제안**이며 현재 확정 구현 기준은 기존 3탭이다.

레시피 32종을 지역별로 묶고 배운 항목을 접으며 검색한다. 재료는 해금한 품종을 우선 표시하고, 성장은 설비 8계열·물약 4계열·직원 4역할의 다음 단계만 보여준다. 원정은 현재 지역·다음 발견·다음 지역을 우선 표시한다. 소유 레시피 14종과 해금 재료 7종은 미리보기용 샘플 진행 상태다. [화면 검증 기록](../../output/management-expansion-design-v1/verification.json)은 검색·접힘·탭별 스크롤 유지·환경 하이라이트·구매와 목적지 미리보기·가로 넘침 없음·페이지 오류 없음을 기록한다.

미니 작업실 A는 160×112, B는 256×160이다. 기존 마녀 외형을 재사용하고 B에는 골드와 작은 러그를 추가했다. 낮·밤과 맑음·비 조합의 투명 PNG 8종을 준비했다. B는 현재 320×112 최소 모드보다 폭은 좁지만 면적은 약 14% 크다. **기존 최소 모드를 대체하기로 확정한 상태는 아니다.**

## 연결 순서와 작업 범위

1. 관리 탭과 미니 작업실 안을 선택한다. 확정 전에는 시안의 추천을 구현 지시로 취급하지 않는다.
2. 재고·손님 대기 균형을 조정하고 콘텐츠 데이터의 확정 범위를 정한다. 아트 제작 완료가 가격·효과 확정을 의미하지 않는다.
3. 개발 단계에서 정식 `catalog.json`의 ID와 경로로 에셋을 연결한다. 미리보기의 샘플 구매·골드·해금 상태는 저장에 적용하지 않는다.
4. 실제 게임에서 자동 운영·환경 표시·작은 병 가독성·기존 저장 이전·성장 속도를 확인한다.

정식 아트 경로는 `assets/content_expansion_v1/`, 최신 관리 시안은 루트 `output/management-expansion-design-v1/`이다. 미니 시안은 소유 범위 지시 전에 생성된 루트 `output/mini-companion-v1/`에 보존됐다. 향후 신규 미니 산출물은 지정된 `output/mini-workshop-design-v1/`을 사용할 수 있다. 초기 `assets/expansion_v1/`와 `output/management-expansion-v1/`을 정식 최신 목록과 혼동하지 않는다.

두 디자인 담당은 게임 코드·씬·저장·공용 기획서와 상대 소유 폴더를 수정하지 않은 것으로 보고했다. 이번 기획 반영도 문서만 수정하며 게임에 연결하지 않는다.
