# 작업실 대표 게이지와 제작 대기

2026년 10월 8일 · **구현 완료 / 격리된 headless 검사 통과 / 실제 화면 조작 미실시**

작업실은 솥·약초·원정마다 실제 게이지 하나를 보여준다. 솥은 현재 제조 중인 물약을 따라 바뀌고, 약초와 원정은 고정 대표를 유지한다. 전체 작업의 자세한 모습은 기존 관리 목록에서 확인한다. 재고가 차서 제작이 기다리는 모습도 자동 가게 운영의 정상적인 상태로 표현한다.

이 규칙은 이전 약초 3개·원정 2개·숨긴 수 `+N`, 페이지 전환, 가장 긴 작업 선정 및 랜덤 교체 제안보다 우선한다. 아래 대표 표시와 대기 연결은 구현 완료다. 책상 유지/제거, 포스터 소품, 최종 창 너비와 위치는 [배치 후보](작업실-배치-개선-후보.md)에서 별도 선택한다.

## 적용과 검증 완료

- 실제 배치 시작 시 저장되는 물약 ID를 공유해 본/최소 모드 솥의 액체·증기 색, 물약 아이콘과 제조 막대를 연결했다. 32종 기존 병의 액체 색을 사용하며 솥 액체 151픽셀만 변경한다. 외곽·불·알파·원본 PNG·조명은 유지한다. 보관/재료 대기와 저장 복원에서도 마지막 ID를 유지한다.
- 기본 약초 `herb`와 숲 가장자리 `forest_edge`를 고정했다. 기본 약초의 32×40 성장 프레임은 현재 사물 배치에 맞춰 16×20px로 표시하며 실제 진행을 읽는다. 관리 상세에는 품종별 원래 성장 그림을 유지한다. 실제 재배/원정 개수에는 대표를 포함하고 버섯 구매·미해금 공급원·보유 재료만 있는 품종·대기 원정을 제외한다. 복귀 중 원정은 포함한다.
- 보관 가득일 때 제조·약초 막대와 성장 그림을 임의로 완료 상태로 바꾸던 표시를 제거했다. 이미 시작한 배치의 경과와 재료 예약은 기존 모델이 유지하고 실제 판매 후 같은 배치가 이어진다. 최소/정보 모드도 실제 제조 진행만 표시한다.
- 18×18px 돋보기 세 개가 기존 포션/약초/원정 탭을 연다. Windows 입력 브리지는 본 모드에서 이 세 사각형만 그림 영역의 입력 예외로 받으며, 그 밖의 그림 클릭 통과와 하단 조작을 유지한다. 같은 배치 갱신으로 보조 처리를 반복 재시작하지 않는다. 네이티브 소스와 내장 실행 파일은 컴파일·파일 일치만 검사했고 이번 작업에서 실행하지 않았다.
- Pretendard, 48px 관리 아이콘·520px 관리 폭·98px 약초/포션 행, 현재 하단 간격과 408×288/256×160/320×112 세 모드 크기를 유지했다. 경제 수치·제작 순서·저장 형식·RNG·특별 레시피 획득·오프라인 보상은 변경하지 않았다.

`verify_fixed_representatives.gd`는 0개/대표 대기/다른 작업 진행/보관 가득/출발비 부족/복귀 단계, 실제 판매 후 제조 재개·예약 보존·마지막 물약 저장 복원, 탭 진입 신호·조회/모드 전환의 상태와 RNG 불변을 통과했다. `verify_potion_liquid.gd`는 32종 색·151픽셀 액체 마스크·외곽과 알파 보존을, `verify_desktop_regions.gd`는 예외 영역 경계·값 복사·변경 시에만 재설정·headless 네이티브 미실행을 통과했다.

관리 폰트·조건·성장 그림·드래그·하단 간격·3단 모드·최소 모드 검사와 기존 공급/진행/다중 원정 검사도 통과했다. `verify_workshop_followup.gd`는 실제 8개 병의 제조/판매 경로와 대표 표시·세 버튼의 좌표 겹침, 가장 긴 개수 문구의 글자 너비를 검사했다. [배치 검토 이미지](../.verification/workshop-gauge-placement-proof.png)는 실제 데이터·솥 색·좌표와 기존 파일 아트를 조합한 자료이며 실제 화면 캡처나 셰이더 검증이 아니다. 실제 클릭·창 이동·포커스·배율 조합은 사용자가 확인할 항목으로 남는다. Computer Use·화면 입력·플레이어 저장 접근은 하지 않았다. 자세한 기록은 [관리 UI 적용 결과](관리-게이지-UI-적용결과.md)를 따른다.

## 대표와 화면 표시

| 대상 | 대표 기준 | 기본 표시 | 관리 연결 |
| --- | --- | --- | --- |
| 솥 | 실제로 시작된 현재 제조 배치의 물약 | 물약 아이콘·제작 게이지·짧은 상태, 솥 내부는 해당 물약 색상 | 포션 탭 |
| 약초 | 기본 약초 `herb` 고정 | 해당 약초의 성장 스프라이트·게이지, `N종 재배 중` | 약초 탭 |
| 원정 | 첫 지역인 숲 가장자리 고정 | 해당 지역 아이콘·원정 게이지, `N곳 탐사 중` | 원정 탭 |

솥은 한 번에 한 종류를 제조한다. `N종 제작 중`은 사용하지 않는다. 레시피 보유 수를 동시 제조 수로 표시하지 않는다. 다음 배치가 실제 시작되었을 때 아이콘·게이지·솥 색상을 함께 바꾸며, UI에서 다음 물약을 랜덤으로 고르지 않는다.

약초·원정 대표는 수확 완료·원정 완료·환경·남은 시간·신규 해금·보관 대기로 바꾸지 않는다. 대표가 기다려도 같은 그림을 유지하고 짧은 이유를 표시한다. 다른 약초·원정이 진행 중이면 전체 진행 개수는 계속 표시한다. 기본 약초는 기존 게임의 채집 주기를 사용하며, 장식 화분에 별도 성장 타이머를 만들지 않는다. 첫 지역 미해금 시에는 잠긴 지역 상태를 표시하고 진행 막대를 움직이지 않는다.

`N`은 대표를 포함한 **현재 실제로 진행하는 전체 종류/지역 수**다. 해금 총수와 숨긴 개수가 아니다. 재배 수에는 자동 구매 버섯과 공급원 미해금 품종을 넣지 않는다. 원정 수에는 탐색과 재료 가져오는 단계 모두를 포함하고 출발비 부족·재료 충분·보관 대기는 제외한다. 약초 수는 실제 성장/채집이 진행 중인 공급원만 센다. 전체 진행이 0이면 `재배 대기` 또는 `원정 대기`로 표시한다.

대표 게이지는 대표 하나의 진행도이며 전체 평균이 아니다. 약초·원정의 개수 문구는 전체 활동 요약이다. 관리 탭에서 대표 외 작업도 모두 확인할 수 있게 한다.

## 게이지의 기준

| 대상 | 0% | 100% | 읽는 값 |
| --- | --- | --- | --- |
| 약초 | 해당 수확 주기 시작 | 다음 수확 완료 | 해당 품종의 누적 성장량 / 수확에 필요한 성장량. 기본 약초는 실제 채집 경과 / 실제 수확 주기 |
| 솥 | 현재 제조 배치 시작 | 해당 배치 제조 완료 | 실제 제조 경과 / 현재 제조 소요 시간 |
| 원정 | 해당 회차 출발 | 탐색과 복귀를 마치고 완료 처리 | 해당 회차 실제 경과 / 그 회차에 저장된 전체 소요 시간 |

제조 20초 중 10초가 진행되었다면 50%다. 제조 게이지 100%는 한 회차 완료를 뜻하며 성공 확률이나 물약 보관량이 아니다. 원정 조사 횟수와 재고 비율은 각각 별도 정보이며 작업 게이지로 대체하지 않는다.

약초의 낮밤·날씨·설비·직원 효과는 실제 성장 속도를 따른다. 환경이 바뀌었다고 누적 성장을 초기화하거나 표시용 진행을 새로 만들지 않는다. 성장 스프라이트의 프레임도 같은 품종의 같은 진행도를 사용한다. 제조 강화 등 기존 로직이 진행 비율을 보존하는 경우 UI도 보존된 값을 읽는다.

실제 완료로 다음 주기가 시작되면 게이지를 다시 시작한다. 화면에 보이기 위해 가짜 완료·수확·보상을 만들지 않는다. 보관 때문에 정지하면 실제 진행값을 유지하고 막대도 멈춘다. 대기를 표현하려고 임의로 100%를 채우지 않는다. 프레임 사이의 부드러운 표시 보간은 실제 진행 범위 안에서만 한다.

## 솥의 제작과 대기

| 실제 상태 | 아이콘과 솥 내부 색상 | 게이지와 짧은 문구 |
| --- | --- | --- |
| 제작 중 | 현재 배치의 실제 물약 | 실제 제조 진행, `제작 중` |
| 물약 보관 가득 | 마지막으로 제작한 물약 표시 유지. 진행 중 배치가 있다면 그 배치 표시 유지 | 실제 진행값에서 정지, `보관 가득` |
| 재료 부족 | 마지막 물약 표시 유지. 실제 제조 시작 전 다른 물약으로 바꾸지 않음 | 실제 대기 값, `재료 부족` |
| 판매 후 공간 확보 | 기존 제작 조건을 자동으로 재확인. 새 배치 시작 시 해당 물약으로 변경 | 실제 제조가 재개될 때만 진행 |
| 새 게임에서 아직 제작 이력 없음 | 기본 솥 색상과 기본 물약 아이콘 | 실제 시작 전 대기 표시 |

새 배치는 실제 물약 보관 한도가 찼으면 시작하지 않는다. 진행 중 배치가 기존 로직상 일시 정지되어 있다면 경과와 이미 투입한 재료를 보존하고, 조건 해소 시 같은 배치를 이어간다. 제작 대기·관리 열기·화면 전환 때문에 재료를 다시 소비하지 않는다.

솥 색상은 현재 물약의 기존 아이콘/진열 병 색상에 대응하는 표시 정보로 관리한다. 액체 영역만 바꾸고 솥 외곽·불·캐릭터·날씨 조명은 유지한다. 색상·아이콘 갱신은 제작 선택, 재료 소비, 성공 추첨, 지급과 분리한다. 재실행 시 현재 배치가 있으면 그 배치 표시를 우선 복원한다. 제작 이력이 없으면 기본 표시를 사용한다.

## 진열과 생산 판매 균형

전시대의 병 그림 자리 수와 실제 물약 보관 한도는 별개다. 병 그림이 모든 자리를 채웠다는 이유만으로 제조를 중단하지 않는다. 실제 보관량이 실제 한도에 도달했을 때 제작이 대기한다. 선반이나 책상 외형을 바꿔도 보관 한도·판매 속도·제조 시간은 바뀌지 않는다.

손님 구매로 보관 공간이 생기면 별도 조작 없이 제작 조건을 다시 확인해 자동으로 이어간다. 손님이 재고를 기다리는 구간과 솥이 판매를 기다리는 구간 모두 유지한다. 보관 제한을 없애거나 실제 대기 중인 게이지를 장식용으로 반복하지 않는다.

약초와 원정은 솥과 독립적으로 움직이되 각자의 보관·자금·공급 조건을 따른다. 모든 막대가 항상 움직일 필요는 없다. 재고 적체와 재료 부족을 보여주고, 기존 판매·제조·보관 투자가 흐름을 바꾸게 한다. 이번 표시 확정으로 경제 수치나 물약별 생산 순서를 변경하지 않는다.

## 약초 에셋과 전체 목록

약초 스프라이트를 유지한다. 작업실에서는 고정 대표 약초 하나의 성장 그림을 사용하고, 관리 약초 탭에서는 기존 각 품종의 성장 그림과 실제 개별 진행을 확인한다. 재료 아이콘과 성장 그림은 기존 카탈로그의 품종 ID·`growth_path`로 연결한다. 버섯 구매와 재배가 없는 재료에 가짜 성장 그림을 붙이지 않는다.

관리 포션 탭은 전체 포션 재고와 현재 실제 제조 상태를 보여준다. 제조 중이 아닌 포션에 공용 제조 타이머를 복제하지 않는다. 원정 탭은 지역별 독립 진행과 대기·보상을 보여준다. 종류가 늘어나도 작업실 대표 자리 수는 늘리지 않는다.

## 상세 진입과 화면 유지

작은 돋보기/진입 버튼으로 기존 포션·약초·원정 탭을 연다. 상세 확인은 작업 시작·수령·대표 선택 설정이 아니다. 자동 페이지 전환이나 새 상세 페이지를 추가하지 않는다. 기존 관리 버튼으로도 같은 목록에 들어갈 수 있어야 한다.

사물 그림 전체의 클릭 통과를 유지하고 실제 버튼의 작은 입력 영역만 사용한다. 직접 진입 영역은 기존 투명 창 입력 구조 안에서 검증한 후 연결하며, 하단 이동·관리·축소·확대·종료를 보존한다. 본 작업실의 최종 사물 배치는 별도 선택한다. 최소 256×160과 정보 320×112 모드에 세 대표를 억지로 압축하지 않고 기존 제조 표시를 유지한다.

## 반영 확인 기준

1. 실제 제조 시작 때 물약 ID·아이콘·색상·게이지가 일치하고 제조 중 임의 교체되지 않는다. 대기 후 재개 때 재료가 중복 소비되지 않는다.
2. 화면상 전시 병이 가득해도 실제 보관 여유가 있으면 기존 조건대로 제작한다. 실제 보관 가득에서는 정지하고 판매 후 자동 재개한다.
3. 약초와 원정 대표는 수확·완료·대기·날씨·신규 해금 이후에도 고정된다. 관리에서는 대표 외 항목도 독립적인 실제 값으로 움직인다.
4. `N`은 실제 진행 수다. 0개, 대표만 대기, 일부 보관 가득, 원정 출발비 부족, 미해금 지역, 구매 버섯에서 수가 맞는다.
5. 약초 성장 그림과 막대는 같은 품종의 진행도를 사용한다. 보관 가득일 때 수확 효과를 반복하지 않는다.
6. 관리 진입·색상 변경·보간·모드 전환·재실행으로 생산·원정 결제·보상·RNG가 추가 실행되지 않는다.
7. 기존 하단 조작과 클릭 통과를 보존한다. 현재 사용자 요청에 따라 Computer Use와 화면 입력 없이 파일·격리된 headless 검사로 확인하고 실제 조작은 미실시로 기록한다.
