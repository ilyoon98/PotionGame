# 직원 역할 동작 2 — 조제 보조 플라스크 흔들기

2026-11-06. 재배 보조의 물 주기에 이어, 조제 보조가 같은 손으로 플라스크를 받쳐 들어 올리고 좌우로 세 번 흔든 뒤 원래 자세로 돌아오는 후보를 제작했다. Pixelbolt 0.11.0으로 정렬된 기존 원본의 오른팔·손·병 영역을 편집했다.

[기존 캐릭터와 함께 보기](../art/mockups/f25-staff-flask-v1/together-1x.gif) · [대기와 동작 비교](../art/mockups/f25-staff-flask-v1/comparison-1x.gif) · [재생·속도 조절](../art/mockups/f25-staff-flask-v1/review.html) · [주요 자세](../art/mockups/f25-staff-flask-v1/reviews/keyposes.png)

동작은 **대기 → 준비 → 들어 올리기 → 좌우 흔들기 3회 → 내려놓기 → 원래 대기**다. 고유 자세 5개를 18개 타이밍 구간으로 사용하며 총 6초다. 출력 리소스는 한 번 재생한 뒤 원래 정지 그림에서 끝나고, 검토 HTML·GIF·별도 엔진 비교 화면은 반복한다.

## 유지한 기준과 수정 범위

- 32×48 원본, 기존 5색, 공통 외곽선, 원래 시점과 재질 배치를 유지했다. 머리·목·가슴·허리·골반·양다리·발 y46과 반대 손은 원본 픽셀 그대로다.
- 화면 오른쪽 손이 병목이 아닌 둥근 병몸체의 왼쪽을 받치는 기존 관계를 유지했다. 손·소매·병을 연결한 채 준비에서 2픽셀, 들어 올림에서 최대 3픽셀 상승한다.
- 초기 4픽셀 상승에서는 병마개가 머리 끝에 붙어 보였다. 최종 후보는 마개 y28, 머리 하단 y26 사이에 빈 y27 행을 확보했다. 병을 제외해도 손이 고정 소매에 연결되는지, 병과 머리가 대각선으로도 붙지 않는지 검사했다.
- 좌우 자세에서 병목과 바닥 윤곽이 조금씩 기울어진다. 닫힌 마개와 와인색 내용물 13픽셀을 유지하며, 새 색이나 외부 효과는 추가하지 않았다. 마지막 그림은 정렬 원본의 정지 자세와 같다.

## 기존 캐릭터와의 비교

기존 5명은 현재 게임의 `idle-fine.png`를 그대로 사용한다. 이미 96×144인 fine 그림을 1배로, 직원 32×48을 3배로 그려 표시 크기를 모두 96×144로 맞췄다. 기존 fine 그림을 native 그림의 단순 3배 확대본으로 대체하지 않았다.

기존 캐릭터는 `scripts/pixel_art_catalog.gd`의 실제 `motion_index()`에 따라 18초·152개 시간 구간으로 재생한다. 64개 프레임을 순서대로 재생하는 방식이 아니다. 직원 대기는 기존 18초·19구간을, 새 동작은 6초·18구간을 사용한다.

두 비교 GIF는 각각 **360프레임·20fps·18초**이며 50ms 간격으로 표본화한 공유본이다. HTML과 Godot 비교 화면은 원래 밀리초 단위 시간표를 사용하므로, GIF의 표본 간격을 원본 동작 시간표로 해석하지 않는다.

## 검증과 관찰 범위

- 프레임 검사: 원본 5색·이진 알파·외곽선, 보호 부위의 픽셀 동일성, 손–병 접촉, 병목·닫힌 마개, 액체 13픽셀을 확인했다. 기존 재질 후처리 전후 변화는 0픽셀이다.
- Godot 4.6 리소스 검사: 18구간·6초·반복 꺼짐으로 로드했으며 실패 항목은 없다.
- 별도 Godot 1배 엔진 재생은 **60.077초** 기록했다. 기존 5명은 각각 152/152구간·3회 반복, 직원 대기는 19/19구간·3회 반복, 플라스크 동작은 18/18구간·10회 반복을 모두 관측했다.
- 117개 시점 × 7개체, 총 819개체 표본에서 접지 오류와 정수 위치 오류는 각각 0건이었다. 엔진 재생 13.5초 시점의 viewport PNG와 주요 자세·겹침·실루엣 이미지를 시각 검토했다.
- Computer Use로 재생 창을 활성화하려 했으나 두 번 모두 `failed to activate captured window`로 실패해 중단했다. 따라서 이번 확인은 **엔진 재생·시간/위치 기록과 렌더 캡처에 근거한 검토**다. 연속 재생 화면을 끝까지 눈으로 관찰했다고 주장하지 않는다.
- 제작 스크립트와 HTML 내 스크립트의 구문 검사도 통과했다.

## 재현과 적용 상태

프로젝트 루트에서 실행한다.

```powershell
node tools/build_f25_staff_flask_v1.mjs
node tools/build_f25_staff_flask_v1.mjs --prepare-live
```

첫 명령은 리소스와 비교 자료를 생성한다. `--prepare-live`는 같은 제작 과정에 더해 `.verification/f25-flask-live/`에 별도 Godot 비교 프로젝트를 준비한다. 이 옵션 자체가 60초 재생 검사나 창 활성화의 성공을 뜻하지는 않는다.

원본은 `art/mockups/f25-staff-flask-v1/source/*.txt`, 출력은 같은 폴더의 `exports/staff/`에 있다. 아직 사용자 검토 후보이며 게임 런타임에 연결하지 않았다. 작업실 직원 배치와 관리 화면의 기존 역할 아이콘도 유지한다.

재배 물 주기와 조제 플라스크 흔들기 후보까지 제작했다. 다음 순서는 **판매 보조의 인사 → 원정 길잡이의 등불 동작**이다.
