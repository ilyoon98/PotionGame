| 이미 해당 지역 해금 | `열림` | 개방 구매는 비활성, 중복 결제 없음 |

- 조건이 여러 개 부족하면 현재 구매 가능 판정에서 확인한 대표 미충족 조건 하나를 버튼에 표시하고 나머지는 접힌 상세에서 확인하게 한다. 항상 가격만 적힌 비활성 `개방` 버튼을 남기지 않는다.
- 원정 이름과 조건이 길면 버튼 폭 또는 줄바꿈으로 실제 문구를 읽을 수 있게 한다. 필수 조건을 말줄임이나 툴팁에만 의존하지 않는다. 조건 충족/미충족으로 주변 행이 흔들리지 않도록 버튼 영역 높이를 유지한다.
- 명성·조사 완료·골드가 바뀌면 버튼 문구와 활성 상태도 현재 값으로 갱신한다. 실행 직전 조건·비용을 다시 검사한다.
- 가게 운영의 성장 추천에서 원정 열기를 제시할 때도 같은 용어·구매 판정을 쓴다. 추천을 누르기 시작한 뒤 조건이 바뀌면 해당 부족 조건을 표시하고 결제하지 않는다.
- 지역 개방비와 매회 출발비는 다른 비용이다. 이미 열린 원정이 출발비 때문에 기다린다고 지역을 다시 잠그거나 개방비를 다시 요구하지 않는다.

## 최신 확정 · 화면 압축·가구 직원 탭·성장 추천 확장

2026-10-08 사용자 지시 반영. **이번 추가 변경은 구현 완료 / headless 자동·배치 검사 통과 / 실제 화면 조작 미실시**다. 아래 이전 다섯 탭 구현 완료 및 설비·직원 하위 페이지 기록보다 이 절을 우선한다. 기존 자동 운영·가격·해금 조건·제작과 판매 균형·저장을 유지한다. **이번에도 Computer Use와 사용자의 화면 조작은 금지하고 headless 검사로 확인한다.**

### 확정 관리 메뉴

**`가게 운영 / 약초 / 포션 / 레시피 / 원정 / 가구·직원`** 여섯 탭으로 구분한다. 가구와 직원은 같은 탭 안에서 두 목록으로 나눈다. 가구는 우선 이미 구현된 솥·화분·보관장 등 설비를 뜻하며, 이번 지시만으로 새 장식·배치 시스템을 추가하지 않는다.

- 가구·직원 탭에서 설비 구매·강화, 직원 고용·훈련을 직접 실행할 수 있다. 단계 막대, 핵심 전후 효과, 비용, 필수 조건을 보여준다. 기존 계열 투자도 이 성장 관리 영역에서 접근 가능하게 유지한다.
- 기존 설비·직원 하위 페이지의 기능을 이 탭으로 옮긴다. 하단 진입 버튼을 남기면 같은 탭을 열게 하며 별도 복제 페이지를 만들지 않는다. 영업 결과와 기존 화면 설정에 계속 접근할 수 있어야 한다.
- 여섯 탭은 글자를 더 작게 줄이거나 가로 스크롤을 강요하지 않는다. 내용에 맞는 탭 폭·간격으로 현행 관리 창에 배치하고 겹침을 검사한다.

### 확정 화면 압축과 움직임

1. **운영 본문의 행과 추천 영역을 압축한다.** 현재 104px 추천 영역과 88~106px 제조·판매 행을 줄여 한 화면에 더 많은 작업 막대를 보여준다. 상단 추천은 이름/행동·짧은 효과·비용 위주로 구성하며 긴 이유는 상세로 옮긴다. 첫 화면에서 포션·채집·원정이 함께 보이도록 배치한다. 목표는 충분한 작업이 해금된 상태에서 스크롤 전 실제 작업 막대 6개 이상이며, 행 약 44~56px·추천 약 56px은 글자와 내용이 잘리지 않는 범위의 초기 치수다. 대기 중 제조·판매 행을 사라지게 하지 않는다.
2. **포션 탭의 실제 제조 중 품목에 제조 막대를 표시한다.** 현재 제작률·시간을 글자로만 표시하고 `row.work.box.hide()`로 숨기는 부분을 수정한다. 재고 막대와 작업 막대를 구별한다. 제조 중이 아닌 품목에는 같은 타이머를 복제하지 않고 보유량과 짧은 대기 상태를 표시한다.
3. **작업 막대와 텍스트 갱신을 나눈다.** 0.2초 간격의 전체 정보 갱신과 별도로 화면에 보이는 실제 작업 막대는 매 프레임 또는 충분히 부드러운 주기로 갱신한다. 막대의 값은 실제 경과·전체 시간에 연결한다. 완료·대기·재개·탭 전환 시에도 실제 값과 일치해야 하며, UI에서 타이머를 추가 진행하거나 보상을 지급하지 않는다. 글자·목록·추천은 기존 낮은 갱신 빈도를 사용할 수 있다.

### 확정 성장 추천의 직접 실행

가게 운영 최상단의 추천은 **강화 전용에서 성장 행동 추천으로 확장**한다. 추천과 별개로 각 정식 탭에서 같은 행동을 직접 실행할 수 있어야 한다. 추천에서 누르면 현재 화면을 유지하며 기존 구매 경로로 한 번만 결제·반영한다.

| 추천 종류 | 표시할 핵심 내용 | 버튼 | 성공 후 반영 |
| --- | --- | --- | --- |
| 가구·설비 강화 | 대상·핵심 전후 효과·강화 비용 | `강화 · 비용` | 해당 설비 단계와 실제 효과 증가 |
| 직원 고용·훈련 | 역할 또는 훈련 효과·비용 | `고용 · 비용` / `훈련 · 비용` | 기존 자동 운영에 효과 적용 |
| 원정 개방 | 지역·주요 해금/보상·영구 개방 비용 | `원정 열기 · 비용` | 기존 규칙대로 지역 해금, 출발비 충분 시 자동 출발·부족 시 대기 |
| 레시피 획득 | 물약·새 제작/공급 효과·구매 비용 | `레시피 구매 · 비용` | 1회 영구 구매 후 기존 자동 제작 대상에 합류 |

- 원정 발견·조사·명성·선행 지역·보유 골드 등 기존 조건을 충족하는 행동을 추천 후보로 사용한다. 미발견 레시피를 즉시 주거나 발견 조건을 우회하지 않는다. 레시피 획득은 현재 게임의 1회 구매를 의미한다.
- 화면만 갱신되거나 추천이 나타난 것만으로 결제하지 않는다. 사용자가 표시된 추천의 버튼을 눌렀을 때만 실행한다.
- 누르기 시작한 **행동 종류와 대상 ID**를 함께 고정한다. 클릭 중 추천이 다른 종류로 바뀌어도 원래 행동만 시도하며 실행 시 최신 비용·조건을 다시 검사한다.
- 이미 구매·고용·개방한 단발 항목, 최대 단계, 자금·조건 부족은 중복 결제하지 않는다. 성공 후 다음 추천으로 갱신하고, 실패 시 짧은 이유를 보여준다.
- 한 번에 한 개의 간결한 추천을 우선한다. 추천 후보에는 강화·고용·원정·레시피가 모두 포함되어야 한다. 구체 순위·수치 임계값은 현재 병목과 새 콘텐츠 진행을 고려한 구현 초기값으로 기록하며, 모든 투자 완료까지 강화만 고정 추천하는 구조로 축소하지 않는다.

### 이번 추가 변경 확인 기준

1. 여섯 탭이 겹치거나 잘리지 않으며 가구·직원 탭의 실제 구매·강화·고용·훈련이 작동한다.

## 최신 확정 · 여러 리스트가 동시에 움직이는 운영 화면

2026-10-08 후속 사용자 지시의 핵심은 **포션·채집·원정 리스트의 게이지들이 동시다발적으로 움직여 바쁘게 돌아가는 가게를 보여주는 것**이다. 단순히 숫자 옆에 막대 하나를 붙이는 작업으로 축소하지 않는다. 성장·재고·제조 중 상태는 게이지 중심으로 바꾸고 긴 시스템 설명은 기본 화면에서 제거한다. 아래 이전의 `원정은 운영에 복제하지 않는다` 기준은 이 지시로 대체한다.

| --- | --- | --- | --- |
| 확정 | 포션 제조 | 실제 해당 배치의 경과 시간 / 전체 시간 | 픽셀 아이콘·이름·제조 막대·남은 시간 |

### 화면과 정보량

- 가게 운영은 상단 강화 추천 아래에 **포션 / 채집 / 원정**의 짧은 구역 제목과 진행 행들을 모은다. 서로 다른 작업들이 각자의 속도로 채워지고, 완료되면 결과 수량을 갱신하고 다음 주기를 시작하는 것이 주된 볼거리다.
- 약초 전체 목록은 별도 약초 탭에, 지역 해금·보상 상세는 원정 탭에 남긴다. 가게 운영에도 진행 행을 보여주되 같은 실제 상태를 참조한다. 탭별로 타이머를 따로 돌리지 않는다.
- 행은 아이콘·이름, 작업 게이지, 짧은 시간 또는 상태, 필요한 경우 얇은 재고 게이지로 구성한다. 반복되는 `자동 운영 중`, 상세 배율, 구매 주기 설명, 긴 해금 조건·시스템 소개는 접힌 상세로 옮긴다.
- `재료 부족`, `보관 가득`, `출발비 부족`은 해당 행에 짧게 남긴다. 구매 비용·강화 전후 효과·미충족 필수 조건은 행동할 때 확인할 수 있어야 한다.
- 해금한 진행 항목부터 보여주며 미해금 32종·8지역 모두를 빈 막대로 채우지 않는다. 행이 많아지면 게임의 목록을 스크롤하되 상단 메뉴와 강화 추천 위치는 유지한다.
- 재고 막대와 성장 단계 막대는 수량·단계가 변할 때만 움직인다. 시간만 흘러도 저절로 채워지는 막대는 작업 진행에만 사용한다. 막대에는 의미를 구별할 짧은 표기를 둔다.
- 완료 표현은 막대 끝의 짧은 강조와 해당 수량 변경 정도로 제한한다. 매회 팝업·소리·긴 결과 문구를 추가하지 않는다. 화면 갱신으로 행 순서·스크롤·열린 상세가 초기화되지 않는다.

### 포션 동시 제작 · 구조 변경 상세안은 제안

현재 `shop_state.gd`의 `brew_active`, `brew_elapsed`, `progression.active_recipe`는 한 제조 배치를 처리한다. **포션 종류별 제조 막대를 동시에 진행시키는 권장 화면을 실제로 구현하려면 포션별 독립 배치 또는 복수 제조 슬롯이 필요하다.** 현재 단일 배치 타이머를 모든 물약에 복사해서 동시 제작처럼 표시하지 않는다.

UI의 목표와 게이지 중심 표시 변경은 확정이다. 독립 제작 라인 수·해금 조건·원재료 배분·공유 설비 효율·저장 이전은 별도 제작 명세로 정해야 한다. 종류가 늘었다는 이유로 총 생산량까지 단순히 배수로 늘리면 기존 재고와 손님 대기 균형 및 2시간 이후 성장 목표가 바뀌므로 생산·판매 경제를 함께 검증한다. 이번 기획 정리만으로 생산 로직 변경이나 구현 완료로 기록하지 않는다.

### 추가 확인 기준

1. 채집·제조·여러 지역 원정이 서로 다른 실제 진행률로 동시에 갱신되며 반복된다.
2. 재고와 성장 단계는 각각의 실제 값과 막대가 일치한다. 재고는 소비·판매에 따라 줄어든다.
3. 포션별 동시 제조 구조를 적용한다면 재료 예약·결과·결제·저장이 배치마다 한 번만 반영된다. 단일 배치 유지 시 제조 중이 아닌 품목에는 가짜 제조 타이머가 없다.
4. 기본 리스트를 읽을 때 긴 설명 블록이 필요하지 않으며, 조건과 비용을 알아야 하는 구매는 계속 이해할 수 있다.
5. 관리 창을 닫거나 탭을 바꾸어도 작업은 같은 상태로 이어지고 중복 생산·입고가 없다.

## 확정 가게 운영과 약초 탭 · 2026-10-08

| 상태 | 영역 | 보여줄 내용과 동작 |
| --- | --- | --- |
| 확정 | 가게 운영 상단 | 강화 추천 영역. 추천 대상 이름·짧은 이유·강화 효과·비용을 보여준다. `강화하기`를 선택하면 비용을 지불하고 해당 항목을 즉시 강화한다. |
| 확정 | 가게 운영 본문 | 실제 진행 중인 채집·재배·구매·제작·판매의 게이지 모음. 아이콘·품목 이름·작업 종류·진행 막대·남은 시간을 우선한다. 각 막대는 해당 작업의 실제 진행값을 사용한다. |
| 확정 | 약초 탭 | 약초·버섯 등 재료 목록, 보유량/한도, 조달 방식과 진행, 실제 환경 효과 하이라이트. 약초 전체 목록은 가게 운영에서 이 탭으로 옮긴다. |
| 확정 | 제거 영역 | 가게 운영의 별도 `현재 흐름` 도식과 `자동 운영` 설명/요약 블록을 제거한다. 품목별 상태와 필요한 대기 이유는 해당 항목 안에 남긴다. |
| 확정 | 강화 추천 실행 | 현재 페이지에서 바로 강화한다. 누르기 시작한 대상을 고정하고 실행 시 최신 자금·해금·최대 단계 조건을 다시 검사한다. 실패 시 결제하지 않는다. |

설명 영역을 없애는 것이 자동 진행 기능을 제거하는 뜻은 아니다. 실행 즉시 자동 시작, 비용·예비금·보관 제한, 조건 해소 시 자동 재개, 이전 저장과 진행 보존은 유지한다.

### 진행 게이지 기준

- 제작은 현재 진행 중인 배치를 보여준다. 아직 시작하지 않은 32종 물약 모두에 빈 게이지를 만들지 않는다. 탭 이동으로 진행 중 배치의 재료·판정·타이머를 바꾸지 않는다.
- 채집·재배·구매는 실제 동시에 돌아가는 해금 공급원마다 표시한다. 약초 탭에서도 같은 진행을 확인할 수 있다. 운영의 게이지 모음과 약초의 전체 목록은 역할이 다르다.
- 판매 행과 막대는 항상 표시하며 상태 줄을 같은 높이로 유지한다. 실제 거래 중에만 타이머 진행률을 표시하고 손님·완성품 대기 및 영업 휴식 때는 0과 대기를 표시한다.
- 재료 부족·보관 가득·골드 부족 등으로 멈춘 작업은 해당 행에 짧은 대기 이유를 표시한다. 대기를 채워지는 게이지로 표현하지 않는다. 원인이 해소되면 자동 재개한다.
- 원정의 지역별 게이지는 원정 탭과 가게 운영 모음에서 같은 상태를 표시한다. 해금·보상 상세는 원정 탭에 둔다.
- 실제 환경 효과는 약초와 물약 항목에서 강조한다. 시간·날씨 변경으로 행 순서와 열린 상세가 초기화되지 않는다.

### 추천 배치 · 전체 탭 구성과 선정 수식은 제안

메뉴는 **`가게 운영 / 약초 / 물약·레시피 / 강화 / 원정`**의 다섯 탭을 추천한다. 약초 분리와 운영 본문 재구성은 확정이다. 강화를 독립 탭으로 둘지 기존 하위 페이지를 쓸지, 레시피 탭의 이름을 바꿀지는 아직 배치 제안이다. 탭 수가 늘었다는 이유로 글자를 작게 줄이지 않는다.

```text
가게 운영
  강화 추천: 대상 · 이유 · 효과 · 비용  [강화하기]
  진행 항목: 아이콘 / 이름 / 작업 종류 / 게이지 / 남은 시간
             멈춘 작업은 해당 행에 대기 이유
  [지난 영업 결과]
```

추천은 한 번에 한 항목을 보여주는 안을 우선한다. 완성품이 쌓이고 판매가 느리면 판매대, 손님이 기다리는데 제조가 느리면 솥, 재료 때문에 제조가 멈추면 해당 공급 설비, 실제 보관 제한에 자주 막히면 보관 설비를 검토한다. **이 기준은 추천 로직의 제안**이며 수치 임계값·우선순위는 실제 운영 데이터로 정한다. 최대 단계 설비는 추가 강화를 추천하지 않는다. 구매 가능한 추천이 없으면 반복 설명으로 빈자리를 채우지 않는다. 누르는 도중 추천이 바뀌더라도 클릭한 대상 기준으로 비용을 지불하고 강화한다.

### 이번 변경 확인 기준

1. 별도 약초 탭에서 전체 재료 목록과 실제 환경 하이라이트를 확인할 수 있다.
2. 가게 운영에서 실제 작업의 게이지를 모아 확인한다. 없는 타이머나 대기를 가짜 진행률로 표시하지 않는다.
3. `현재 흐름`과 별도 `자동 운영` 설명 블록이 없다. 자동 진행과 대기·재개는 유지된다.
4. 추천의 강화하기는 비용을 지불하고 즉시 강화한다. 클릭 중 대상 변경·자금 부족·최대 단계 조건을 검사한다.
5. 추천 강화는 기존 강화 로직으로 한 번만 결제·반영한다. 탭 전환·관리 닫기로 골드·재고·배치·원정·저장이 초기화되지 않는다.

## 이전 구현 상태 · 아이콘과 즉시 자동 시작

구현 완료: 관리·전체·작음·최소 화면의 영업/발주 전환, 원정 활성화/일시정지 조작을 제거했다. 원정은 최초 해금 결제 즉시 자동 시작한다. 이전 저장의 꺼짐 상태는 불러올 때 자동 운영으로 전환하되, 자산·제조와 발주 시간·진행 중 배치 판정·원정 시간·미입고 보상은 그대로 보존한다. 새 게임, 이전 저장 이전, 해금 자동 출발, 보관 대기/재개, 관리 창 닫기/재열기 검사를 통과했다. 신규 지역 선택은 지역이 추가될 때 구현할 규칙이며 이번에는 기존 숲 원정에 적용했다.

## 확정 아이콘과 즉시 자동 시작

2026-10-07 사용자 지시를 반영한다. 아래 요구사항은 확정이며 게임 코드 적용 여부와 구분한다.

- 재료·물약·레시피·설비·직원·원정 항목의 이름 왼쪽에 의미가 맞는 아이콘을 둔다. 기존 픽셀 에셋을 우선 재사용하고 같은 품목은 화면마다 동일한 아이콘을 쓴다. 이름은 유지하며 아이콘만 보고 의미를 추측하게 하지 않는다.
- 게임을 실행하면 기본 재료 조달·구매·제작·판매가 바로 자동 시작한다. 처음 한 번도 영업 시작이나 자동 켜기를 누르게 하지 않는다.
- 레시피는 사용자가 한 번 구매하면 재료 공급과 자동 제작에 합류한다. 원정은 최초 해금 구매 직후 자동 탐색·귀환·입고·재출발을 시작한다. 설비·직원 효과도 구매 직후 적용한다.
- `영업 쉬기 / 영업 재개`, `자동 구매 켜기 / 끄기`, `원정 활성화 / 일시정지` 조작을 제거한다. 필요하면 `자동 영업 중`처럼 상태만 표시한다.
- 재료 부족·골드 부족·보관함 가득 참에 따른 대기는 유지하며, 조건이 풀리면 자동 재개한다. 예비금·재료비·보관 한도는 기존 규칙을 따른다. 자동 시작을 위해 재료를 무료 지급하거나 잔액을 음수로 만들지 않는다.
- 기존 저장에서 영업·자동 구매가 꺼져 있거나 해금한 원정이 비활성 상태여도 다음 실행부터 자동 진행으로 전환한다. 미해금 원정은 시작하지 않고, 보유·골드·제조 진행·원정 진행·미입고 보상은 보존한다. 해금 비용을 다시 차감하지 않는다.
- 추가 지역 도입 시 목적지 선택은 유지하되 별도 시작 버튼은 두지 않는다. 지역 변경은 현재 회차 완료 후 적용한다. 신규 지역을 해금했다는 이유로 진행 중 목적지를 임의 교체하지 않는다.
- 새 레시피 구매·설비 강화·직원 고용·원정 해금 비용은 플레이어가 선택해 지불한다. 자동 운영이 미구매 콘텐츠까지 자동 결제하는 것은 아니다. 앱 종료 중 수익은 별도 기획으로 남긴다.

## 기본 방향

관리 화면을 열면 현재 가게 상태를 확인하고, 원하는 성장 행동을 찾을 수 있어야 한다. 처음부터 모든 수치와 시스템 설명을 읽게 하지 않는다. 구매·제작·판매는 계속 자동으로 진행되며, 페이지를 나누는 것은 관리 의무를 추가하는 일이 아니다.

현재는 가게 운영에 재고, 제조 상태, 재료 발주, 설비 강화, 직원, 손님 방문 비중, 화면 효과 설정이 길게 이어진다. 확인할 정보와 비용을 지불하는 행동을 분리하고, 각 항목의 정확한 수치는 상세에서 확인하도록 바꾼다.

대안은 기존 `가게 운영 / 레시피 / 원정`을 유지하고 가게 운영 안에 `재고 확인 / 시설·직원` 두 하위 페이지를 두는 방식이다. 기존 구조 변경은 적지만 강화에 도달하는 단계가 늘어난다. 이번 불편에는 네 탭으로 역할을 바로 구분하는 안을 우선 추천한다.

환경 하이라이트는 유지한다. 단순히 밤이나 비라는 이유로 모든 행을 강조하지 않고, 해당 품목에 실제 변화가 생겼을 때만 이유를 한 줄 표시한다. 글이 길어지면 `비 덕분에 성장 빨라짐`처럼 짧게 쓰되 효과의 원인은 유지한다.

구매 판단에 필요한 비용, 필수 조건, 얻는 효과는 상세로 숨기지 않는다. 버튼은 `강화`, `고용`, `배우기`, `원정 해금`처럼 결과를 구분한다. 구매 완료와 명성 부족, 골드 부족을 같은 비활성 버튼 문구로 처리하지 않는다.

재고는 아이콘·이름·수량을 우선한다. 기존 아이템 에셋을 유지하고, 해당 행을 누르면 의미와 수치가 펼쳐지게 한다. 마우스 올리기만으로 열리는 설명에 필수 정보를 의존하지 않는다.

## 동작과 범위

- 창 크기와 글자 크기를 먼저 줄여 정보량을 맞추지 않는다. 기본 목표는 현행 460×660 관리 창에서 핵심 내용을 읽을 수 있는 구성이다. 시안 높이는 검토용이며 최종 치수가 아니다.
- 콘텐츠가 늘어나면 목록 영역 안에서 스크롤한다. 상단 탭과 하단 영업 결과·닫기 등 주요 이동은 유지한다.
- 탭마다 스크롤과 펼침 상태를 별도로 유지한다. 처음 열 때 가게를 보여주고, 같은 실행 중 재진입은 직전 페이지를 복원하는 안을 제안한다.
- 설정·결과 화면에서는 돌아갈 위치를 알 수 있도록 제목과 뒤로 가기를 제공한다. 실제 관리 창의 닫기 기능과 전체 실내 화면 전환은 유지한다.
- 시간·날씨 변경으로 효과 문구와 강조가 바뀌어도 행을 재정렬하거나 펼친 상세를 닫지 않는다.
- 제조 확률은 `현재 환경으로 새로 제조할 때`와 `진행 중 제조에 이미 적용된 확률`이 다를 수 있다. 현재 제조 상세는 실제 배치 값을 사용한다.
- 부족 재료, 만원 보관함, 원정 입고 대기는 원인과 자동 재개 조건을 설명한다. 해결에 불필요한 버튼을 만들지 않는다.
- 레시피·강화·원정 가격과 경제 수식은 유지한다. 자동 진행 여부는 위 확정 규칙으로 전환하되 저장된 자산·진행은 보존한다.

## 확인 기준

1. 가게를 열었을 때 강화·고용·설정 목록을 지나지 않고 재고를 확인할 수 있다.
2. 강화·고용은 성장에서, 신규 물약 해금은 레시피에서 찾을 수 있다.
3. 환경 효과가 없는 품목에 반복 안내가 없으며, 영향받는 품목은 원인을 알 수 있다.
4. 상세를 열지 않아도 구매 비용, 효과, 미충족 조건을 이해할 수 있다.
5. 재료 부족·골드 부족·명성 부족·보관함 가득 참이 서로 구별된다.
6. 페이지 전환과 창 닫기가 자동 운영·원정·확률 판정·보유 기록에 영향을 주지 않는다.
7. 새 게임과 기존 자동 꺼짐 저장 모두 별도 시작 버튼 없이 구매·제작·판매가 진행된다.
8. 원정 최초 해금 후 자동 출발하며, 재실행해도 진행과 보상이 중복 적용되지 않는다.
9. 모든 주요 항목에 의미가 맞는 아이콘과 이름이 함께 표시된다.

인터랙티브 비교 시안의 골드·재고·진행·강화 가격은 예시다. 시안에서 누른 구매와 설정은 실제 게임에 적용되지 않는다. 최종 선택 후 위 제안 중 채택할 항목만 확정 기획에 옮긴다.
