# 특별 레시피와 포션 디자인 제작 요청

2026-10-08 · **특별 레시피·포션 이미지 제작 요청 확정 / 아래 4종은 디자인 제작용 후보 / 게임 연결·경제 수치 미확정**.

사용자가 특별 레시피를 추가한다면 해당 레시피와 포션 이미지도 요청하라고 지시했다. 기존 32종 일반 물약과 별도로 원정에서 발견하는 특별 물약 후보 4종의 아트를 제작한다. 기획은 레시피 초안과 요청 범위를 관리하고, `약초와 물약 디자인 추가` 대화는 신규 이미지·신규 카탈로그를 관리하며, 개발 대화는 이후 게임 연결을 담당한다.

## 콘텐츠 후보 · 제작용 초안

이름·배합·설정은 디자인을 구체화하기 위한 후보이며 실제 게임 확정 데이터가 아니다. 기존 재료만 사용하고 선행 지역에서 후반 재료를 요구하지 않는다. 효과 설명은 세계관 설정이다. 새 전투·캐릭터 버프·자동 생산 가속 기능을 추가하라는 뜻이 아니다. 판매가·제조 시간·수익성과 자동 제작 우선순위는 개발 경제 검토 뒤 정한다.

위 ID는 신규 에셋을 구분하기 위한 예약 이름이다. 아직 런타임 아이템으로 등록하지 않는다. 기존 일반 물약, 특히 성장·은신·달빛·별빛 물약과 나란히 비교하여 병 형태·주색·문양이 구분되도록 조정한다.

## 제작 산출물

| 산출물 | 수량·규격 | 쓰임 |

| 비교 시트 | 신규 포션·레시피 짝 4세트와 기존 유사 물약 비교 | 한눈에 스타일과 구별성 검토 |

레시피 아이콘은 작은 두루마리 또는 레시피 카드에 해당 병의 문양·주색을 반복한다. 포션 병과 같은 이미지로 대체하지 않는다. 두 이미지의 짝이 읽혀야 하며 작은 아이콘 안에 한글·재료 목록·숫자 등 읽기 어려운 글씨를 넣지 않는다. 실제 이름과 배합은 게임 UI 텍스트가 담당한다.

## 스타일·작업 범위

- `assets/content_expansion_v1/catalog.json`과 기존 실제 픽셀 아트를 기준으로 한다. 어두운 자주색 외곽선·금빛 마개·단순하고 읽히는 문양·명확한 병 실루엣을 유지한다. 희귀성은 모양·문양으로 구분하며 과한 반짝임·외부 파티클을 아이콘에 굽지 않는다.
- 실제 알파 투명 PNG와 픽셀 경계를 사용한다. 배경·바닥·그림자·프레임·문구는 넣지 않는다. 작은 병은 UI 아이콘을 단순 축소해 뭉개지지 않도록 12×16에서 직접 읽히는 결과를 검토한다.
- 신규 산출물은 `assets/rare_recipes_v1/` 아래에 둔다. 기존 승인 에셋·기존 catalog·다른 디자인 작업 폴더·게임 코드·씬·project.godot·플레이어 저장·경제 데이터를 변경하지 않는다. 원본·생성 기록·비교 시트·검증은 같은 신규 폴더에 보관한다.
- 디자인 제작 완료와 게임 연결 완료를 구분한다. 레시피 획득 방식, 발견 확률·보장 횟수, 재료 충분 시 특별 발견 목적의 반복 규칙은 아직 미확정이며 디자인 작업이 이를 결정하지 않는다.
- Computer Use·사용자 화면 조작·입력·포커스 변경·눈에 보이는 게임 실행은 사용하지 않는다. 파일 검사·이미지 생성·headless 렌더로 검토한다. 완료 시 이 대화 안에 산출물 경로와 검증 결과를 남긴다.

## 결과 UI 연결 원칙

원정 결과는 재료마다 `[재료 아이콘] 이름 × 실제 수량`, 특별 레시피는 `[레시피 아이콘] 이름 · 특별 발견`으로 표시한다. 실제 습득 방식 확정 뒤 습득한 경우에만 `획득`으로 표시한다. 기존 임시 공통 레시피 아이콘은 전용 에셋이 연결되면 바꾼다. 아트 파일이 생겼다는 이유로 레시피를 자동 지급하거나 원정 보상을 다시 추첨하지 않는다.
