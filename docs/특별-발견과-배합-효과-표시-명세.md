# 특별 레시피 발견과 배합 및 강화 효과 표시

2026년 10월 13일 · **확정 범위 구현·격리 검사·파일 미리보기 검수 완료 / 경제 수치는 개발 검증용 초기값 / 실제 Windows 조작 미검증**

원정에는 아직 찾지 못한 특별 레시피와 이미 발견한 레시피를 구분해 표시한다. 포션별 배합은 재료 아이콘과 실제 필요 수량으로 읽히게 하고, 최대 강화에서도 최종 효과를 남긴다. 재고0개는 미구매·재료 부족·상위 물약 우선 등의 원인을 구분한다. 기존 먹색·세이지 관리 화면과 자동 운영을 유지한다.

## 사용자 확정

- 특별 레시피는 **원정에서 발견 → 골드로 1회 구매 → 자동 제작 합류**다. 발견만으로 구매나 제작 권한을 지급하지 않는다.
- 특별 레시피가 있는 원정은 발견 전 공용 `지도 ?` 아이콘으로 존재와 미발견 상태를 알린다. 발견 후에는 실제 레시피 아이콘과 이름, 구매 여부를 보여준다.
- 포션마다 재료 아이콘과 배합 수량을 표시한다. 여러 종류와 여러 개를 쓰는 배합을 활용한다.
- 최대 단계에서도 현재 얻은 최종 강화 효과를 알아볼 수 있게 표시한다.

## 특별 레시피의 세 상태

| 상태 | 원정의 기본 표시 | 레시피와 포션 |
| --- | --- | --- |
| 미발견 | 공용 지도 `?` + `특별 레시피 · 미발견` | 실제 이름·전용 그림·배합을 숨긴다. 원정 지역과 미발견 사실만 알려준다. |
| 발견·미구매 | 전용 레시피 아이콘 + 실제 이름 + `발견 · 구매 가능` | 레시피 탭과 성장 추천에서 실제 가격으로 1회 구매. 배합 확인 가능, 자동 제조는 아직 불가. |
| 구매 완료 | 전용 레시피 아이콘 + 실제 이름 + `구매 완료` | 포션 목록·실제 보관/제조·판매·진열 병에 합류. 원정의 발견 기록은 계속 남음. |

현재 대상은 숲 가장자리의 숲숨결 물약, 물안개 계곡의 물안개 물약, 달빛 유적의 월광봉인 물약, 별의 정원의 성운 증류액4종이다. 특별 레시피가 없는 나머지 지역에 가짜 `?`를 붙이지 않는다. 필요하면 상세에서 `특별 레시피 없음`만 확인한다.

원정 기본 행에는 상태 한 줄만 추가한다. 발견·구매 전후에 높이와 버튼 위치가 흔들리지 않게 필요한 여백을 확보한다. 기존148px를 강제로 고집해 글씨나 게이지를 겹치지 않게 하며, 특별 대상 행에만 최소한의 추가 높이를 허용한다. 발견 이름을 누르면 기존 레시피 탭으로 이동한다. 탐사 진행과 보상 상세는 유지하고 별도 수령·자동 팝업·새 최상위 탭을 추가하지 않는다.

미발견 마스킹은 원정·레시피·포션·추천·툴팁·상세 모두 같은 발견 상태를 사용한다. 카탈로그의 실제 이름/전용 아이콘을 표시용 기본값으로 잘못 불러오지 않는다. 미발견 특별 포션은 포션 목록에서 실제 이름으로 선공개하지 않는다.

## 발견과 저장

일반32종의 조사·레시피·다음 지역은 특별 발견 여부에 의존하지 않는다. 특별4종은 선택적 추가 콘텐츠다. 기존 승인 아트12개를 연결하며 이름·실제 배합을 런타임 데이터에 등록한다. 새 공급원이나 기존 구매를 중복 지급하지 않는다.

별도 특별 발견 기록과 실패 횟수를 저장하고, 구매 보유는 기존 구매 기록과 구분한다. 해당 지역의 유효 원정 출발 때 결과를 한 번 확정해 회차에 저장하고 실제 완료 때 발견을 공개한다. 새로고침·날씨 변화·재실행·중간 강화로 다시 추첨하지 않는다. 발견 대상이 이미 기록되었다면 다시 추첨/지급하지 않고, 미구매 상태에서 발견 기록을 유지한다.

이전 저장의 조사 완료 횟수나 누적 방문을 특별 발견/실패 횟수로 소급 변환하지 않는다. 기존 진행 중 회차는 저장된 결과 그대로 마치고 새 기능 이후 출발한 유효 회차부터 발견을 검사한다. 여러 원정의 동시 완료와 중간 저장/복원도 한 번만 처리한다.

기존 제안의 **완료당3%·30번째 유효 완료에서 보장**을 조정 가능한 개발용 초기값으로 검증한다. 사용자 확정 수치로 표시하지 않는다. 일반 성장 시간에 대한 이전 검사와 특별 수집 시간을 구분하며, 확률과 보장 진행은 접힌 상세에만 둔다.

## 재료가 충분해도 미발견을 탐색하는 규칙

일반 원정은 기존 주재료·보관·출발비·예비금 규칙을 유지한다. 조사 완료 후 주재료 충분/보관 공간 때문에 일반 반복이 쉬는데 특별 레시피가 미발견이면, 자동으로 **특별 탐색 회차**를 진행한다.

특별 탐색은 같은 지역의 실제 출발비와 시간으로 진행하고, 발견만 조사하며 일반 재료 보상을 추가하지 않는다. 이미 출발한 일반 회차의 재료를 삭제하거나 중간에 특별 탐색으로 바꾸지 않는다. 출발 시 회차 종류를 저장한다. 미발견 목적의 무한 재료 적체를 만들지 않고 기존 재료/미입고 보상은 보존한다.

특별 탐색도 예비금과 미완료 일반 조사의 출발비 보호를 지킨다. 자금 부족이면 자동 대기하고, 발견했으면 특별 탐색 반복을 멈춘다. 구매를 기다리는 동안 비용을 계속 내며 같은 레시피를 다시 찾지 않는다. 이후 일반 원정은 재료 필요에 따라 기존 규칙으로 재개한다.

특별 탐색 중 기본 상태는 `특별 탐색 중`으로 읽히게 한다. 이 회차에 재료를 주지 않는데 `주재료 N개 보장`이라고 표시하지 않는다. 재료 보상 풀과 유료 탐색의 정확한 의미는 상세에서 확인한다. 기능용 수동 모드 스위치·회차별 보내기·수령은 추가하지 않는다.

## 실제 배합과 자동 제작

현재 일반 레시피는 이미1~4종의 재료를 사용한다. 기본 약초는2개이고 다른 재료는 현재1개씩이다. 기존 일반32종의 소모량을 일괄 늘리지 않는다.

| 예시 | 현재 실제 배합 |
| --- | --- |
| 마나 | 기본 약초2 + 달빛 버섯1 |
| 정령 | 기본 약초2 + 푸른 갈대1 + 이슬풀1 |
| 현자의 물약 | 기본 약초2 + 별씨1 + 잿빛 세이지1 + 수정초1 |

특별4종은 기존 재료3종과 서로 다른 필요 수량을 사용한다. 디자인 제작 초안의 배합을 기본 연결안으로 삼고, 판매가·구매가·제조 시간·성공률은 해당 지역의 기존 품목과 공급량을 기준으로 개발용 초기값을 기록/검증한다. 기존 재료만 사용하며 선행 지역 특별품에 뒤 지역 재료를 요구하지 않는다.

| 특별 물약 | 기본 연결 배합 | 기존 공급과의 연결 |
| --- | --- | --- |
| 숲숨결 물약 | 이슬풀2 + 별잎1 + 달빛 버섯1 | 숲/기존 별잎/자동 발주 |
| 물안개 물약 | 푸른 갈대2 + 은빛 이끼1 + 이슬풀1 | 계곡·온실·숲 품종 |
| 월광봉인 물약 | 달꽃2 + 잿빛 세이지1 + 별잎1 | 유적·탑·기존 별잎 |
| 성운 증류액 | 별씨2 + 달꽃1 + 수정초1 | 정원·유적·광산 품종 |

더 다양한2~3개 소모량을 기존 일반품에 확대하는 것은 공급/판매 비교 후의 조정 후보다. 소비만 늘려 품절을 만드는 안을 최종 밸런스로 간주하지 않는다.

구매한 특별품도 첫 실제 제조 우선과 자동 제조·판매에 연결한다. 한 솥/한 배치 원칙은 유지한다. 계열 최상위 규칙 때문에 특별품이 영구적으로 제조되지 않거나 일반 생산을 모두 밀어내지 않도록 실제 생산 후보와 우선순위를 검증한다. 수동 레시피 전환이나 포션별 병렬 제조를 요구하지 않는다.

## 재료 아이콘과 수량 표시

포션 탭의 각 기본 행과 레시피 탭에 `1병 배합`을 표시한다. 같은 실제 `ingredients` 데이터를 읽어 `[재료 아이콘 × 필요수량] + ...`로 보여준다. 체력·마나도 각각의 배합을 확인할 수 있게 한다. 여러 종류는 공간에 맞춰 줄바꿈하고 표시를 위해 글씨·아이콘을 축소하지 않는다.

아이콘은 기존11종을 재사용한다. 짧은 기본 줄은 아이콘+수량을 중심으로 두고, 이름은 툴팁/접힌 상세에서도 확인할 수 있게 한다. 이는 필요 수량이며 현재 보유 수량으로 바꾸지 않는다. 상세에서 필요한 양·현재 보유·실제 부족량을 비교할 수 있게 한다.

현재 제작 배치는 재료를 이미 예약/소모했으므로 잔량이 적다는 이유로 현재 제조를 실패나 부족으로 표시하지 않는다. 현재 배치의 예약 완료와 다음 병의 재료 부족을 구분한다. UI 조회로 재료를 예약하거나 제조 선택/RNG를 실행하지 않는다.

## 재고0과 보관 가득의 의미

포션은 전체 공용 창고를 사용하고 약초는 품종별 한도를 사용한다. 품목 재고 막대의 분모가 각 물약의 목표 수량인 것처럼 안내하지 않는다. 공용 물약 보관량은 현재 포션 탭 상단에서 표시한다.

현재 자동 제작은 구매 직후 첫 제조 우선, 계열별 만들 수 있는 상위 품목 우선, 재료 부족 시 하위 대체다. 이미 상위 물약으로 대체된 하위 품목을 `자동 제조 순서 대기`로만 표시하지 말고 **`상위 물약 우선 · 부족 시 자동 대체`**와 실제 재료 부족·미구매·현재 제작·보관 가득을 구분한다. 기존별 생산 우선순위를 읽는 순수 조회를 사용한다. 제조 선택 함수를 UI에서 호출해 계열 커서를 바꾸지 않는다.

재료0개는 미해금 공급원·사용 즉시 소비·실제 공급 부족을 구분해 확인한다. 약초가 가득한 품종이 다른 품종의 보관을 막는다고 설명하지 않는다. 방금 팔렸다는 등의 개별 최근 이력이 없는 원인을 만들어내지 않는다.

격리된 현재 자동 운영에서 계열별 제조/판매, 사용 재료의 생성/소모, 연속 품절과 공용 창고 적체를 확인한다. 모든32종을 최소 수량으로 강제 비축하는 정책은 이번 확정에 포함하지 않는다. 계열별 재고에 따른 제조 우선권은 측정 후의 조정 후보다.

## 최대 강화에서도 현재 효과 표시

모든 설비·계열·훈련에서 `최대 단계`는 완료 상태로 남기고, 실제 최종 효과를 별도 한 줄로 표시한다. 최대 단계가 됐다고 효과를 빈 문자열이나 완료 문구로 덮어쓰지 않는다. 다음 비용/상승 화살표는 없애되 실제 얻은 능력은 읽히게 한다.

기존 단계들의 효과 키를 모두 수집하고 현재 적용 값을 읽는다. 마지막 단계에 없는 이전 효과를 누락하거나 단계별 최종 값들을 모두 더하지 않는다. 솥은 현재 제조 시간과 품질을, 판매대는 실제 거래 간격을 표시한다.

원정 길 정비 최대8/8의 자체 효과는 **원정 시간16% 단축**, 원정 길잡이 훈련 최대5/5의 자체 효과는 **14% 단축**이다. 두 효과의 실제 합산은30% 상한을 적용한다. 설비 자체 효과와 합산 적용을 구분하며, 지역 상세에는 기본 회차 시간과 다음 출발에 적용할 시간을 보여준다. 현재 출발 완료한 회차의 저장된 소요 시간은 새 강화로 소급 변경하지 않는다.

## 제작 분담과 확인 기준

기획은 이 명세와 확정/제안 상태를 관리한다. 개발은 런타임·데이터·저장·UI·격리 검사를 단독으로 맡는다. 디자인은 공용 미발견 지도 `?` 아이콘만 별도 신규 경로로 제작하고 기존 특별4종/일반 아트는 변경하지 않는다. 새 아이콘은 검수 후 개발에 전달한다.
