# 후반 투자와 흥정 훈련 개선 명세

**2026-10-20 후속 F20 확정·개발 요청:** [판매 재고 보호와 작업실 운영 확장](판매-재고-보호와-작업실-운영-확장-명세.md)의 무료 재고/재료 보호를 우선한다. 확장 전에는 보호 조건 아래 기존 한 솥 배분, 확장 구매 후에는 메인 일반 판매·보조 납품의 두 제작선으로 전환한다. 기존 F19 병수 상한·구매 실적은 계승한다. 아래 완료 기록은 해당 버전의 이력이며 F20 구현 완료를 뜻하지 않는다.

2026-10-19 · **F19 구현·격리 검사·기획 검수 완료 · 각15만/30만/45만 G·총180만 G 적용**

최신 제작값은 각15만/30만/45만 G, 두 갈래 총180만 G과 보급60초마다7/12/24개다. 최초210만 G안과 가격 후보 비교를 거쳐 대기 간격을 줄이는180만 G안을 채택했다. 최종 생산 가격·24개 성장 경로·기존 저장 보존을 확인했다. 적용 전후 상태와 비교 범위는 [기획 검수](후반-투자와-흥정-훈련-개선-기획검수.md)를 따른다.

흥정 훈련의 적용 대상이 없는데 골드를 지출하는 문제를 막고, 기존 성장을 마친 가게가 공급과 납품 능력에 다시 투자하도록 만든다. 사용자의 ‘기획서 정리와 개발 반영’ 요청에 따른 제작 범위다. 진행 방식은 확정하며 아래 비용·주기·수량은 **첫 제작과 경제 비교에 사용할 초기값**이다. 실제 적용값과 비교 결과는 개발 결과에 남긴다.

이 명세는 [기존 수주 명세](조건-흥정과-자동-납품-제작명세.md)의 흥정 훈련 구매 조건과 납품 1배치당 수량을 보완한다. 기존 첫 계약·승급 시에만 흥정, 최종 협의100%, 한 솥·일반4배치 대 납품1배치·자동 반복은 유지한다.

## 확정 범위와 비용

| 구분 | 역할 | 1단계 | 2단계 | 3단계 | 합계 |
| --- | --- | ---: | ---: | ---: | ---: |
| 흥정 훈련 | 남아 있는 확률 협의의 성공률 증가 | 8,000 G | 20,000 G | 50,000 G | 78,000 G |
| 보급 지원 | 부족한 특수 재료를 주기적으로 자동 보급 | 150,000 G | 300,000 G | 450,000 G | 900,000 G |
| 납품 일괄 조제 | 납품 한 배치의 실제 생산 병수 증가 | 150,000 G | 300,000 G | 450,000 G | 900,000 G |

새로 전부 구매하는 후반 영구 투자 두 갈래의 총 비용은 **1,800,000 G**이다. 두 갈래는 서로 독립적으로 구매하며 상대 갈래의 구매를 선행 조건으로 삼지 않는다. 새 소비 화폐·급여·추가 반복 결제는 없다.

기존에60만 G으로3단계를 산 저장의 단계·골드·실제 지출·진행 주기는 그대로 보존한다. 과거 지출을 소급해서45만으로 바꾸거나 가격 차액을 자동 환급하지 않는다. 앞으로 구매할 미보유3단계에45만 G을 적용하며, 같은 실제 가격을 정식 행·추천·결제에서 사용한다.

흥정 훈련비는 현재 가격을 유지한다. 일반 성공률60→70→80→90%와 최종100%도 유지한다. 이 훈련의 효용은 남은 협의에 한정되므로, 많은 골드를 소모할 주된 후반 성장으로 삼지 않는다. 큰 비용은 완료 이후에도 실제 생산·납품에 계속 적용되는 두 투자에 배치한다. 훈련에 납품 대금·속도 보너스를 함께 붙이지 않는다.

## 해금과 단계 진행

### 수주와 후반 투자의 해금 분리

- **수주 F18:** 현행대로 별의 정원 최초 개방 때 열린다. 이미 열린 수주·협의·계약을 다시 잠그지 않는다.
- **후반 투자 F19:** 아래의 ‘기존 성장 완료’와 해당 단계의 거래 등급을 모두 충족해야 구매할 수 있다. 수주를 시작하려고 모든 강화를 완료할 필요는 없다.
- 특별 레시피4종의 발견·구매나 흥정 훈련3단계 완료는 후반 투자 해금 조건이 아니다.

‘기존 성장 완료’는 일반 레시피32종 보유, 원정8곳 일반 조사 완료, 기존 직원4명 고용, 아래 기존16갈래 투자 단계 충족이다. 신규 후반 투자나 향후 콘텐츠를 이 판정에 다시 포함해 순환 조건을 만들지 않는다. 레거시 판매 보조 보유와 시작 보유 단계는 실제 기존 소유 판정을 따른다.

```text
cauldron=20, herb_pot=15, sales_counter=10,
potion_cabinet=8, herb_storage=10, drying_rack=8,
expedition_path=8, precision_filter=6,
family_vitality=5, family_arcane=5, family_nature=5, family_craft=5,
sales_assistant=5, cultivation_assistant=5, brewing_assistant=5, expedition_guide=5
```

| 투자 단계 | 공통 선행 조건 | 추가 조건 |
| --- | --- | --- |
| 1 | 기존 성장 완료 | 거래처 중 한 곳 이상2등급 |
| 2 | 같은 투자1단계 구매 | 거래처 중 한 곳 이상3등급 |
| 3 | 같은 투자2단계 구매 | 거래처 중 한 곳 이상4등급 |

거래 등급·누적 실적은 소비하지 않는다. 다른 거래처까지 모두 같은 등급으로 올릴 필요는 없다. 이미 최고 등급과 많은 골드를 보유한 복귀 가게도 실제 조건과 비용을 충족하면 순서대로 구매할 수 있으며 임의의 시간 잠금을 추가하지 않는다.

## 흥정 훈련의 유효 기간과 구매 방어

### 남은 적용 기회

거래처마다 **현재 등급부터3등급까지** 아직 협의할 수 있는 확률 기회를 센다. 현재 등급에서 개선 요청을 이미 판정했거나 기본 제안을 수락했다면 현재 기회는 제외하되, 앞으로 도달할 더 높은1~3등급의 기회는 포함한다. 지나간 낮은 등급은 다시 만들지 않는다. 최종4등급은 보장 협의이므로 세지 않는다.

예를 들어 현재1등급의 흥정을 마쳤어도2·3등급이 남아 있으면 훈련을 구매할 수 있다. 모든 거래처가4등급이면 남은 적용 기회는0이다. 모든 거래처가3등급이고 현재 협의까지 모두 판정·수락했다면 이 경우도0이다.

### 표시와 처리

- 다음 훈련이 있고, 수주가 열렸고, 남은 적용 기회가1개 이상이고, 골드가 충분할 때만 구매할 수 있다.
- 기회0일 때 버튼은 `적용할 흥정 없음`으로 비활성화하고 추천 후보에서 제외한다. 훈련을 실제3단계까지 구매하지 않았는데 최대 훈련 완료로 표시하지 않는다.
- 훈련 상세에 `앞으로 적용 가능한 흥정 N회`와 현재→다음 성공률을 표시한다. 모든 미래 기회가 실제로 발생한다고 보장하지 않으며 등급을 건너뛰면 적용 횟수가 줄 수 있다.
- 최대3단계·해금 조건·부족 골드는 기존처럼 실제 판정과 같은 값으로 표시한다. 추천과 직접 구매는 같은 구매 함수를 사용한다.
- 클릭 직전에 조건을 다시 검사한다. 협의 판정·수락·승급으로 적용 대상이 사라졌거나 연타로 단계가 바뀌었다면 예전 화면의 구매를 거부하고 골드를 차감하지 않는다.
- 기존 훈련 단계와 판정 이력은 보존한다. 이미 구매한 훈련의 가격 차액 환급이나 과거 협의 재추첨은 하지 않는다.

## 보급 지원

한 번 투자하면 **실행 중60초마다 특수 재료 한 종류**를 보급한다. 부족한 재료를 고르는 별도 자동 공급원이며, 기존 건조대·재배 보조의 전체 성장속도 효과와 구분한다.

| 단계 | 비용 | 보급 주기 | 한 번의 최대 보급량 |
| --- | ---: | ---: | ---: |
| 미구매 | — | 진행 없음 | 0개 |
| 1 | 150,000 G | 60초 | 7개 |
| 2 | 300,000 G | 60초 | 12개 |
| 3 | 450,000 G | 60초 | 24개 |

### 재료 선택과 입고

1. 구매한 일반·특별 레시피에서 실제 사용하는 특수 재료만 후보로 삼는다. 특별품은 구매한 경우에만 참조한다. 미발견 이름·아이콘을 표시하거나 미구매 레시피를 해금하지 않는다.
2. 대상은 기존 특수 재료9종(`starleaf`, `dewgrass`, `silver_moss`, `blue_reed`, `crystal_herb`, `mist_mushroom`, `ash_sage`, `moonflower`, `star_seed`) 중 실제 공급원이 해금된 품목이다. 기본 약초와 자동 발주 버섯은 제외한다.
3. 도착 시점에 `실제 보관량 / 해당 보관 상한`이 가장 낮은 재료를 하나 고른다. 동률은 기존 재료 카탈로그 순서로 결정하며 난수를 쓰지 않는다. 예약에 이미 소비한 재료를 보관량에 다시 더하지 않는다.
4. 해당 재료의 빈 공간만큼, 주기당 예약 수량 이하를 입고한다. 넘치는 보급분은 만들지 않고 다음 주기에 적립하지 않는다. 모든 후보가 가득 차면 그 주기는 지급 없이 지나간다.
5. 기존 원정 입고·보류 보상을 덮어쓰거나 보급품 때문에 원정을 새로 출발시키지 않는다. 같은 시각의 기존 재료 입고를 먼저 반영한 뒤 보급을 판단하고, 이후 새 제조를 예약한다.

첫 구매에서 새60초 주기를 시작하며 즉시 지급하지 않는다. 보급량은 주기 시작 때 예약하고, 중간에 강화해도 진행 중 주기의 시간·예약 수량은 유지한다. 다음 주기부터 새 수량을 사용한다. 재료 종류는 부족 상태를 반영하도록 도착 시점에 결정한다. 고액 투자에 비해 실제 공급 변화가 작지 않도록 입고량을 제조 소모와 함께 비교한다.

남은 시간·예약 수량·지원 단계는 저장한다. UI 열기·닫기·화면 모드·최소화·재접속은 주기를 새로 만들지 않는다. 기존 실행 중 시간 계산을 사용하고 종료 중 보급을 별도로 소급 지급하지 않는다. 긴 실행 시간 분할과 한 번의 시간 진행에서 같은 결과가 나도록 이벤트 경계를 처리한다.

보급은 원정 횟수·원정 보상·특별 레시피 발견 추첨을 늘리지 않는다. 재료 입고와 결과 집계에는 실제 입고량만 반영하고, 원정으로 얻은 재료와 구분할 수 있게 한다.

## 납품 일괄 조제

솥을 추가하지 않고 **기존 납품 한 배치에서 같은 물약을 여러 병** 제조한다. 일반 영업용 제조와 특별 물약 제조는 기존1병을 유지한다.

| 단계 | 비용 | 납품1배치의 최대 병수 |
| --- | ---: | ---: |
| 미구매 | — | 1병 |
| 1 | 150,000 G | 2병 |
| 2 | 300,000 G | 3병 |
| 3 | 450,000 G | 4병 |

### 배치 예약

- 계약·계열·물약의 선택 순서는 기존과 같다. 상위품을1병 만들 수 있는데 하위품4병을 만들기 위해 임의로 후보를 바꾸지 않는다.
- 실제 병수는 `단계의 최대 병수`, `현재 회차 해당 계열의 남은 요구 병수`, `현재 재료로 만들 수 있는 병수` 중 최솟값이다. 재료가1병분이면1병으로 진행하며 여러 병이 모일 때까지 기다리지 않는다.
- 기본 체력·마나를 포함해 각 물약의 실제 배합 × 실제 병수만큼 재료를 한 번 차감한다. 버섯·기본 약초·특수 재료 중 일부만 곱하는 누락을 허용하지 않는다.
- 계약·회차·품목·실제 병수·재료·제조 시간·성공률·성공 판정을 배치 시작 때 고정한다. 배치 진행 중 강화·계약 변경·환경 변화로 수량을 바꾸지 않는다.
- 초기 제조 시간은 기존 같은 품목1배치와 같다. 성공 판정도 배치당 기존1회이며, 성공하면 예약 병수 전체가 완성되고 실패하면 전량 실패한다. 병마다 RNG를 추가 소비하지 않는다.

일반4배치 : 공유 납품1배치는 **실제로 시작한 배치 횟수**로 계속 계산한다. 납품4병을 만들었다고 일반 배치4회를 추가로 요구하거나 납품 슬롯4회를 소비하지 않는다. 재료 없음·일반 재고 가득의 기존 배분 예외도 유지한다.

### 완료와 정산

- 성공 병수만 해당 계열 누계·품목별 출고·계약 실적 근거에 반영한다. 실제 요구량 이하로 예약하므로 다른 계열·다음 회차로 넘치지 않는다.
- 단가 합계에는 고정한 해당 품목 단가 × 실제 성공 병수를 더한다. 모든 요구가 채워질 때 기존 회차 배율을1회 적용·반올림하고1회 정산한다.
- 제조·실패·납품의 병수 집계와 배분용 배치 횟수를 구분한다. 일반 매출·일반 재고·선반·일반 손님 첫 판매·일반 전달 이벤트에는 납품 병을 섞지 않는다.
- 납품4병을4명의 일반 손님으로 표현하지 않는다. 기존 계약 게이지의 실제 수량을 갱신하며 새 캐릭터·주문별 애니메이션을 만들지 않는다.

## 관리 화면과 추천

- 여섯 탭과 기존 수주 관리 페이지를 사용한다. `가구·직원`에 **후반 투자** 구분선 섹션을 추가하고 보급 지원·납품 일괄 조제2행을 둔다. 단계별로 새 행을 늘리지 않는다.
- 기본 행은 아이콘·이름·현재→다음 효과·실제 비용/조건 버튼으로 구성한다. 전체 조건·수량 제한·누적 입고는 상세에 둔다. 먹색·세이지·Pretendard·기존 글씨 크기·구분선을 유지한다.
- 잠긴 버튼은 우선순위에 따라 `가게 성장 완료 필요`, `거래2등급 필요`, `이전 단계 필요`, `N G 부족` 중 현재 필요한 조건을 표시한다. 상세에는 모든 부족 조건을 표시한다.
- 첫 보급 지원 구매 후 `약초`와 가게 운영의 채집 묶음에 같은 보급 주기의 게이지1개를 연결한다. 기본 상태는 `보급 중 · N초`, 모두 가득 차면 `보관 가득`, 후보가 없으면 `대상 없음`이다. 재료 목록을 작업실에 추가하지 않는다.
- 납품 상세에는 `한 번에 최대N병`과 `재료·남은 주문량에 따라 감소`를 표시한다. 일반 제조를 포션별 병렬 작업으로 표시하지 않는다.
- 가게 운영 최상단 추천에 실제 구매 가능한 후반 투자도 넣고 버튼에서 직접 구매한다. 같은 조건이면 기본 추천 점수는 흥정 훈련70, 보급 지원65, 납품 일괄 조제60으로 두되 기존의 확정 추천 우선순위와 함께 비교한다. 비용을 감당할 수 없는 항목을 실행 가능한 추천으로 표시하지 않는다.
- 추천 클릭은 표시 당시 행동·대상·다음 단계를 검증한다. 재계산으로 다른 투자로 바뀌어 다른 가격을 결제하지 않는다. 새 탭·강제 팝업·매회 수령 버튼·작업실 크기 변경은 없다.
- 기존 아이콘을 활용한다. 새 픽셀 에셋·캐릭터·트레이·클릭 통과·창 크기는 이번 제작 범위에 추가하지 않는다.

## 저장 호환과 경제 집계

저장 버전10 및 지원하는 과거 버전에서 신규 두 투자 단계0·보급 미시작으로 이전한다. 진행 중 기존 납품 배치는 수량1로 고정해 복원한다. 기존 골드·직원·설비·훈련·협의 이력·현재 회차·누적 정산·생산/원정 RNG·일반 FIFO·통계를 유지한다.

신규 저장에는 두 투자 단계, 보급 주기 상태, 납품 배치의 예약 병수를 포함한다. 단계 범위·시간·수량·품목·회차·재료 예약의 일관성을 검사하며 잘못된 저장은 부분 적용하지 않는다. 이미 돌아가는 회차·배치를 새 구매 때문에 다시 시작하지 않는다. 일회성 비용은 직접 투자 지출에1회만 반영한다.

신규6단계는 기존125단계 완료 판정과 분리한다. 데이터에 같이 넣더라도 기준 범위를 명시해 ‘후반 투자를 사야 후반 투자가 해금’되는 순환이나 기존 성장 검사 수의 혼동을 막는다.

### 경제와 성장

비교는 가짜 상태만 사용하며 초기 백만 골드를 실제 도달 잔고로 해석하지 않는다. [현재 성장 검토](증분-성장과-흥정-비용-검토.md)의0골드 시작9회와 별도의 완성 가게 비교를 기준으로 삼는다.

1. 완성 가게에서 미구매/보급만/일괄 조제만/둘 다를 최소3시드·2시간 비교한다. 각 단계의 실제 보급량·평균 납품 병수·계약 대금·일반 판매·재료비/원정비·순수입·손님 대기·재고를 기록한다. 아직 끝나지 않은 계약의 미정산 가치는 현금과 분리한다.
2. 재료 가득·희소 상위 재료 부족·일반 재고 가득·일반 재고 적음 조건을 포함한다. 보급 강화로 실제 입고가 늘고, 일괄 강화로 실제 납품 병수가 늘어야 한다. 표준 조건에서 장기 순수입이 이전 단계보다 감소하는 단계는 그대로 완료 처리하지 않는다. 정상·최종 계약 가게의3시드2시간 비교에서 두 투자1단계 조합은 미구매 대비 현금+미정산 기준10% 이상, 두 투자3단계 조합은25% 이상 개선을 초기 체감 목표로 둔다. 목표 미달은 그대로 공개하고 공급·일괄 효과를 조정해 비교한다. 이 목표를 모든 실제 상황의 수익 보장으로 표시하지 않는다.
3. 0골드 시작부터 기존 성장과 수주를 병행하고 후반 투자까지 실제 비용으로 구매하는 경로를 측정한다.30초/15분 복귀 정책과3개 시드 이상에서 해금 시점·구매 시각·직전/직후 잔고·다음 목표·모든 신규 투자 완료 시점을 기록한다. 측정 상한 안에 못 끝났다면 미완료로 남기고 완료 시간을 추정해서 채우지 않는다.
4. 9시간 복귀 시점의약70만~85만 G을 가진 합성 가게도 비교한다. 두 갈래를 전부 즉시 구매할 수 없고, 비용이 반복 클릭·새 화폐 없이 다음 자동 성장 목표로 연결되는지 확인한다. 훈련0~3단계 구매 전략은 별도로 비교하고 협의가 소진된 뒤 사는 낭비를 막는다.
5. 장부는 `보유 골드 = 시작 골드 + 실제 일반/계약 대금 − 재료비 − 원정비 − 직접 투자비`로 맞춘다. 재료는 실제 공급·예약·실패 소비·입고/보류와 맞아야 한다. 새 비용 합계나 순수입으로 나눈 시간을 실제 플레이 시간·투자 회수 보장으로 보고하지 않는다.

최신 채택 비용은15만/30만/45만 G이다. 최초15만/30만/60만 G의 증빙과 가격 비교안은 보존하고, 새 적용 비용·구매 시각·잔고·성장 시간을 별도 증빙으로 남긴다. 비용만 높여 시간을 늘리지 않고 효과와 공급 병목을 함께 검증한다. 같은 자동 공급·동일 품목 일괄 조제 범위를 유지하며 새 재화·자동 재흥정·추가 솥·새 지역·오프라인 수입을 이 조정에 포함하지 않는다.
