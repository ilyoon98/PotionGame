# 직원 역할 동작 1 — 재배 보조 물 주기

2026-11-06. 직원 대기 움직임의 실제 속도 검토를 마친 뒤 사용자가 다음 진행을 요청해, F25 기획의 첫 역할 동작으로 재배 보조의 물 주기를 제작했다. Pixelbolt 0.11.0으로 기존 픽셀을 편집했다.

[대기와 물 주기 비교](../art/mockups/f25-staff-watering-v1/review.html) · [비교 GIF](../art/mockups/f25-staff-watering-v1/comparison-3x.gif) · [주요 자세](../art/mockups/f25-staff-watering-v1/reviews/keyposes.png)

동작은 **대기 → 준비 → 들어 올리기 → 기울여 물 주기 → 역순 복귀**이며 총 5.2초다. 5개 고유 자세를 9개 타이밍 구간으로 사용한다. 실제 직원 리소스는 한 번 재생한 뒤 원래 정지 그림에서 멈추며, 검토 화면과 GIF는 반복한다.

## 유지한 기준과 수정 범위

- 32×48, 같은 3배 표시, 머리·체간·다리와 발 y46을 유지했다. 원래 5색과 공통 외곽선도 유지한다.
- 화면 왼쪽 앞손과 물뿌리개만 움직인다. 그립은 정지 `(8,35)`에서 물 주기 `(8,29)`로 올라가고, 손과 손잡이를 붙여 유지한다. 얼굴·몸통·신발은 새로 그리지 않았다.
- 화분은 현재 승인된 `assets/pixel_v1/props/herb.png`를 바이트 그대로 보존했다. 화분+받침대가 캐릭터보다 앞쪽에 놓인 별도 검토 장면이며, 실제 작업실 배치를 확정한 것이 아니다.
- 물은 캐릭터에 합치지 않는 별도 에셋이다. 물 주기 구간에서만 노즐 `(40,39)`에서 화분 입구 `(31,45)`로 내려가며, 마지막 물방울이 입구에 닿은 뒤 반복한다. 검토 중 도착 전에 사라지던 물방울을 수정했고, 바깥 테두리보다 1픽셀 안쪽으로 도착점을 보정했다.

## 검증

- 고유 자세와 출력 타이밍 프레임 14개: 원본 5색·이진 알파·외곽선 검사, 머리/체간/다리/반대 손 고정, 원래 정지 자세와 동일한 마지막 그림을 확인했다.
- 원본 재질 후처리 전후 변화 0픽셀. 승인된 화분 원본 보존. 물방울의 마지막 위치와 실제 화분 입구 픽셀 접촉을 확인했다.
- Godot 4.6에서 직원(9구간·5.2초·반복 꺼짐), 물 효과(4구간·0.4초·반복), 검토 장면(24구간·5.2초·반복 꺼짐) 리소스를 로드했다.
- 포즈 시트와 물 이동의 연속 시점을 시각 검토했다. 이번 역할 동작은 새 후보이며, 대기 움직임의 60초 라이브 검토 기록을 이 동작의 실제 재생 검증으로 재사용하지 않는다.

근거: [제작 검사](../art/mockups/f25-staff-watering-v1/validation.json) · [Godot 검사](../art/mockups/f25-staff-watering-v1/godot-validation.json) · [포즈·접점·마스크](../art/mockups/f25-staff-watering-v1/source/poses.json).

재현 명령:

```powershell
node tools/build_f25_staff_watering_v1.mjs
```

원본은 `source/*.txt`, 결과는 `exports/staff`·`exports/water`, 장면 비교는 `exports/scene`에 있다. 물 효과의 위치와 재생 시점은 별도로 연결해야 한다. 게임 런타임과 기존 역할 아이콘은 변경하지 않았다.

재배 물 주기에 이어 [조제 보조의 플라스크 흔들기](직원-역할동작-F25-조제-플라스크.md) 후보까지 제작했다. 다음 제작 순서는 **판매 보조의 인사 → 원정 길잡이의 등불 동작**이다.
