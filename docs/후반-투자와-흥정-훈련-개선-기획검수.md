## 독립 확인한 근거

개발의 효과180조건·자연 성장24경로를 원자료로 재계산했고, 측정 소스11개가 검수 시점 파일과 일치함을 확인했다. 보완 요청 전의 소스와 해시는 별도로 보존했다. 신규 구매144건은 각 단계 비용과 잔고 차감이 일치한다. 기존 원정 개방 구매에서 추가로 빠지는 첫 출발비180건도 카탈로그의 실제 출발비로 설명되며 신규 투자비 누락이나 중복 차감이 아니다.

## 1차 보완 요청 이력

### 보급 입고를 기간 결과에 표시

실제60초 진행에서 보급7개가 입고되고 `late_investments.totals`가 늘어났지만 `ShopState.report_text()`에는 보급 행이 없다. `start_report_period()`도 보급 기준값을 보관하지 않는다. 현재는 투자 상세의 누적 총계만 확인할 수 있다.

[재현 증거](../.verification/f19-planning-review-20261019/period-report-before.json)에 실제 입고7개와 결과 본문을 함께 보존했다. 결과의 기간별 재료 목록에 출처를 ‘보급’으로 구분하고 실제 입고량만 표시하도록 요청한다. 기간 재시작·저장 복원·가득 참·미입고·원정 보상과의 구분 및 중복 지급 없음도 검사한다. 이미 실행한 버전11 저장과의 호환을 유지해야 한다.

### 마지막 단계의 비용 대비 효과 비교

실제 구매 순서를 맞춰 이전 단계와 비교하면, 같은60만 G 지출의 효과가 다르다. 아래 수치는 같은 시드끼리 비교한 정상2시간 현금+미정산 개선율의3시드 평균이다.

| 구매 | 표준 합의 | 최종 합의 |
| --- | ---: | ---: |
| 보급2 → 보급3, 일괄2 유지 | +10.74% | +10.96% |
| 일괄2 → 일괄3, 보급3 유지 | +1.90% | +5.03% |

일괄3은 완전히 무효인 투자는 아니지만, 표준 합의를 계속 쓰는 가게에서는 긴 대기에 비해 변화가 작다. ‘최대4병’은 실제 매 배치4병을 보장하지 않으며, 재료·남은 주문량에 의해 제한된다.

**비용 비교 후보:** 두 갈래3단계를60만→45만 G으로 줄인 총180만 G안을 현행210만 G안과 비교 요청한다.1·2단계와 효과·계약·난수 규칙은 같게 두고, 우선30초/15분 복귀·훈련0·3시드에서 실제 구매 시점·구매 간격·전체 완료 시점을 계산한다. 합성 복귀 가게도 전부 즉시 구매되는지 확인한다. 현재 적용 가격을 바꾸기 전에 이 비교 결과로 채택 여부를 정한다.

요청 당시 이 후보는 검수용 미적용 비교안이었다. 이후의 독립 비교와 채택 결론은 문서 맨 위 최신 검수를 따른다. 단순히 총 플레이 시간을 늘렸다는 이유만으로 가격이 적절하다고 판단하지 않으며 실제 추가 효과와 기다리는 시간을 함께 본다.

## 남은 검수와 실행 범위

최종 가격15만/30만/45만 G, 기존 구매 저장 보존, 정식 행·추천·결제·연타 방어와 새 가격의24개 성장 경로까지 검수를 마쳤다. 승인된 F19 범위의 미해결 결함은 확인되지 않았다. 기간 API는 보존됐지만 현재12행 누적 통계 화면에서 사용하지 않으며, 신규 기간 화면이나 오프라인 보상을 추가한 것은 아니다. 게임은 종료·재시작하지 않았으므로 새 코드와 가격은 다음 정상 실행부터 적용된다.

이번 기획 검수는 가짜 상태·분리된 AppData/LocalAppData·headless·파일 미리보기만 사용했다. 실행 중인 게임·실제 플레이어 저장·입력·포커스·Windows/GPU 조작과 주관적 재미는 검증하지 않았다. 검수 도구의 첫 기간 결과 호출명 오류는 수정했고, 수정 후 실제 입고와 누락을 재현했다. 초기 실패 로그를 통과 증거에 포함하지 않는다.
