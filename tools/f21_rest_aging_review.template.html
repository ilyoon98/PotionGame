정해 주실 것

1. 수면 위치: A 제자리에 앉아 졸기 (추천) 또는 B 깔개 위에서 이불 덮기. 둘 다 주인공 자리(216,96) 안에 들어가고 다른 가구를 옮기지 않습니다.
2. 기절 포즈: 머리를 뒤로 젖히고 손은 바닥에 떨군 채 앉아 있는 자세 + 머리 위를 도는 별. 받아들일지, 다른 방향(예: 완전히 쓰러진 포즈, 아래 메모 참고)을 원하는지.
3. 숙성통 위치: 벽 선반에 눕힌 숙성통 (추천, 표시 위치 219,0) 또는 판매대 왼쪽 끝 앞에 세운 통 (대안).
4. 숙성 표식: 기존 병 36종 위에 덧그리는 5×5 금색 인장. 병 그림은 바꾸지 않습니다.

검사 결과

제외한 위치 안

해먹: 걸 자리가 없습니다. 솥(123~219)과 선반 기둥(315) 사이에 걸면 솥 상태 패널(111,66~219,90)과 솥 윗부분을 가립니다.
책상에 엎드리기: 작업실에 책상이 없고, 판매대(315~459)는 손님 대기·병 전달 경로라 주인공이 옮겨 가면 판매 연출과 겹칩니다.
누워서 자기/완전히 쓰러진 기절: 전신을 눕히면 32×48 칸에 들어가지 않습니다(모자 없이도 머리 14 + 몸 23행). 하려면 48×32 가로 칸 예외 승인이 필요합니다.

제작 방식

이 세션에는 이미지 생성 도구가 없어 원본 격자 32×48에서 픽셀 지도(source/*.txt)를 직접 작성했습니다. 머리·모자는 승인된 v4 대기 그림의 픽셀을 그대로 옮기고, 바꾼 것은 감은 눈(열린 1×2 눈의 위 픽셀 제거)과 수면 자세 턱 끝 1픽셀뿐이며 검사로 확인합니다. 몸·다리·소품은 새로 그렸습니다. 모든 그림은 고정 후처리 tools/process_pixel_art.py(배경 정리 → 원본 격자 → 재질별 램프 → 검사)를 통과합니다. 재현: tools/build_f21_rest_aging_v1.py.

승인 후 런타임 연결 메모 (이번 작업에서 하지 않음)

  • 주인공 포즈에 sleep_sit/sleep_sit_breath(3초 호흡), faint를 추가하고, 지금 수면/기절 중에도 대기 포즈를 쓰는 부분을 바꿉니다. 위치는 기존 주인공 원점 (216,96) 그대로입니다. B안이면 깔개 위로 원본 4행(표시 12px) 올립니다.
  • Z(수면)와 별(기절)은 별도 효과 스프라이트로 주인공 위에 그립니다. 솥 상태 글자 “수면 중”/“기절”(scripts/management_status.gd)은 그대로 둡니다.
  • 숙성통은 작업실 그림 목록에 소품 하나로 추가(벽형: 표시 219,0). 관리 행 아이콘(현재 앞치마·흐름 아이콘)을 숙성통으로 바꿀지는 따로 정합니다.
  • 숙성 판매(ShopArt.on_aged_sale, 첫 선반 칸에서 출발)의 날아가는 병에 인장을 덧그립니다. 병 36종 그림은 바꾸지 않습니다.
