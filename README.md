# 달그늘 물약상점

바탕화면 한쪽에 띄워 두는 작은 픽셀 물약 작업실입니다. 약초 재배, 물약 제조, 판매, 원정, 납품 계약이 저절로 돌아가고, 플레이어는 번 골드로 레시피·원정·설비·직원을 고릅니다. Windows용이며 Godot 4.6으로 만들었습니다.

기능과 구현 상태는 [기획 정리본](docs/달그늘-물약상점-기획서-정리본.md)의 최신 기록을 기준으로 합니다. 이 README는 실행 방법과 전체 개요만 다룹니다. 수치는 각 문서에 있습니다.

## 실행

- `play.cmd`를 더블 클릭합니다. 내부에서 `run-game.ps1`을 실행하고, 게임은 콘솔 없이 별도 창으로 열립니다. 이 cmd 창을 닫아도 게임은 꺼지지 않습니다.
- `run-game.ps1`은 Godot 4.6 실행 파일을 다음 순서로 찾습니다.
  1. PATH에 있는 `godot` 또는 `godot4`
  2. `%USERPROFILE%\Downloads` 아래의 `Godot*_win64.exe` 중 가장 최근 파일(`console` 빌드는 제외)
- 직접 지정하려면 PowerShell에서 `./run-game.ps1 -GodotPath 'C:\경로\Godot.exe'`를 실행합니다.
- 에디터에서 `project.godot`를 열고 F5로 실행할 수도 있습니다. 다만 투명 작업실, 클릭 통과, 트레이 기능은 에디터에 내장된 게임 화면에서는 동작하지 않으니 별도 창으로 실행하세요.
- 같은 Windows 사용자 계정에서는 게임이 하나만 실행됩니다. 두 번째로 실행한 게임은 저장 파일을 건드리기 전에 종료됩니다.

## 화면

| 모드 | 내용 |
| --- | --- |
| **작업실** | 기본 화면. 벽과 바닥 없이 주인공, 솥, 약초, 진열 선반, 판매대, 손님, 창틀(날씨), 원정 표지판만 투명 창에 그립니다. 솥·약초·원정의 실제 진행 게이지가 보이고, 돋보기 버튼을 누르면 해당 관리 탭이 열립니다. |
| **캐릭터(축소)** | 주인공과 솥, 시간·날씨, 주인공 피로 상태만 보여 주는 작은 화면입니다. |
| **정보** | 그림 없이 골드, 최근 1분 수입, 재고, 제조 진행만 보여 주는 HUD입니다. |
| **전체 실내** | 예전 불투명 실내 화면입니다. 이전 저장으로 이어서 할 때를 위해 남겨 두었고, 축소·확대 단계에는 포함되지 않습니다. 이 모드에서는 불투명도(30~100%)를 조절할 수 있습니다. |

- 하단 바 버튼은 `이동 / 관리 / 축소 / 확대 / 종료` 순서입니다. 축소는 작업실 → 캐릭터 → 정보, 확대는 그 반대 방향으로 한 단계씩 바뀝니다. 오른쪽 아래 버튼 위치를 기준으로 화면이 줄어들거나 펼쳐집니다. 모드를 바꾸거나 관리 창을 닫아도 운영은 멈추지 않습니다.
- 작업실·캐릭터 모드의 그림 영역은 클릭을 뒤에 있는 프로그램으로 넘깁니다. 하단 바, 돋보기 버튼, 관리 창만 클릭을 받습니다.
- **창 이동과 위치 기억:** 하단 바를 드래그해 옮깁니다. 작업 표시줄을 덮지 않도록 현재 모니터의 작업 영역 안에서만 움직이며, 다른 모니터로 옮기는 것은 됩니다. 본 창과 관리 창의 마지막 위치를 저장해 두었다가 다음 실행 때 같은 자리에 엽니다. 저장된 모니터가 연결되어 있지 않으면 기본 위치(주 모니터 오른쪽 아래)에 엽니다.
- **항상 위·전체 화면 양보:** 기본적으로 다른 창보다 위에 표시됩니다. 작업실·캐릭터 모드에서는 다른 프로그램이 게임이 있는 모니터를 전체 화면으로 덮으면(영상, 게임 등) 잠시 그 창 뒤로 물러났다가, 전체 화면이 끝나면 다시 맨 위로 올라옵니다. 관리 창에도 같은 규칙이 적용됩니다. 전체 실내 모드는 예외입니다.
- **시스템 트레이:** 작업 표시줄 대신 알림 영역에 물약 아이콘이 생깁니다. 아이콘을 좌클릭하면 게임을 숨기거나 다시 보여 주고, 우클릭하면 `게임 숨기기 / 관리 열기 / 통계 보기 / 저장 후 종료` 메뉴가 나옵니다. 숨겨 둔 동안에도 게임은 계속 진행되고 자동 저장도 됩니다. 하단 바의 종료 버튼(X)은 저장한 뒤 종료합니다.
- **Windows 로그인 때 자동 실행:** 관리 → 설정 → `Windows 로그인마다 게임 자동 실행`(처음에는 꺼짐)을 켜면, 현재 사용자 계정의 작업 스케줄러에 로그인 작업이 등록됩니다. 로그인 후 약 10초 뒤 일반 권한으로 실행되며, 직전에 직접 종료했더라도 다시 열립니다. 설정을 끄면 등록이 해제됩니다. 자세한 내용은 [수정 결과](docs/로그인마다-자동-실행-수정결과-20261015.md)를 참고하세요.

## 자동 운영

기본 흐름은 **재료 조달 → 제조 → 판매 → 골드·명성 획득 → 직접 투자 → 자동 운영 확장**입니다. 영업을 켜고 끄거나 매번 수령 버튼을 누를 필요가 없습니다. 플레이어가 고르는 것은 구매·강화·고용·해금과 흥정뿐입니다.

- **제조:** 해금한 레시피 중에서 재료가 있는 것을 메인 솥이 한 배치씩 자동으로 만듭니다. 성공률은 레시피, 날씨·시간대, 설비, 주인공 피로에 따라 달라집니다. 진열 공간이 가득 차면 진행 상태를 유지한 채 기다렸다가, 공간이 생기면 이어서 만듭니다. 판매 재고 보호와 보조 조제대(작업실 확장)는 [F20](docs/판매-재고-보호와-작업실-운영-확장-명세.md)과 [F21](docs/숙성-수면-보조조제대-속도-기획안.md) 문서에 있습니다.
- **판매:** 손님은 여행자, 여마법사, 엘프, 고양이 도적 4종입니다(여기사는 제외됨). 시간대와 날씨에 따라 오는 손님이 달라지고, 손님마다 선호하는 물약이 있으면 먼저 사 갑니다. 진열 물약은 먼저 들어온 것부터 팔립니다.
- **재배:** 약초 화분과 특수 약초가 각자의 속도로 자라 자동으로 수확됩니다. 날씨가 성장 속도에 영향을 줍니다.
- **원정:** 지역을 한 번 열면 회차마다 출발비를 자동으로 내고 반복해서 다녀옵니다. 숲 가장자리부터 별의 정원, 새벽 등대, 오로라 설원까지 10개 지역이 있으며 여러 지역이 동시에 진행됩니다. 랜덤 재료를 가져오고, 낮은 확률로 특별 레시피를 발견합니다. 새벽 등대(F26)는 별의 정원 조사 뒤에 열리고 여명초와 물약 4종(해돋이·등대불·물보라·일월의 물약)을, 마지막 오로라 설원(F27)은 새벽 등대 조사 뒤에 열리고 서리꽃과 물약 4종(온기·살얼음·솔바람·오로라의 물약)을 더합니다. 자세한 내용은 [보상 풀](docs/원정-랜덤-보상풀과-특별-레시피.md)과 [특별 발견](docs/특별-발견과-배합-효과-표시-명세.md) 문서를 참고하세요.
- **계약(후반):** 별의 정원을 연 뒤 거래처 3곳과 계약합니다. 첫 계약 때와 거래 등급이 오를 때만 조건을 흥정하고(성공·실패 있음, 훈련으로 성공률 상승), 그 뒤의 납품·정산·반복은 자동입니다. [개발 결과](docs/조건-흥정과-자동-납품-개발결과.md), [후반 투자](docs/후반-투자와-흥정-훈련-개선-명세.md)
- **숙성:** 명성 조건을 채우면 숙성통이 열립니다. 남는 물약을 오래 숙성해 비싸게 팝니다. 게임이 켜져 있는 동안에만 숙성이 진행됩니다.
- **주인공 피로·수면:** 주인공은 피로가 쌓이고 밤에는 잠을 잡니다. 자는 동안에는 메인 솥이 멈추지만 판매·원정·재배·보조 조제대·숙성은 계속됩니다. 근무 방식(규칙적/바쁘게/철야), 피로에 따른 성공률 변화와 기절, 침대·허브차 선반 투자는 [F21 기획안](docs/숙성-수면-보조조제대-속도-기획안.md)을 참고하세요. 작업실과 캐릭터 화면에서 `상쾌 · 피로 12` 같은 상태를 볼 수 있습니다.
- **환경:** 게임 속 하루는 4분이고 날씨(맑음, 흐림, 비)는 90초마다 바뀝니다. 현실 시간이나 실제 날씨와는 관계가 없습니다.

모든 가격·확률·보상은 개발용 초기값입니다. 기준값은 [임시값](docs/구현-임시값.md), [콘텐츠 연결표와 가격표](docs/콘텐츠-연결표와-가격표.md), 각 개발 결과 문서에 있습니다.

## 관리 창

작업실의 `관리` 버튼이나 트레이 메뉴로 엽니다. 창 위쪽 제목 영역을 드래그하면 옮길 수 있습니다.

| 탭 | 내용 |
| --- | --- |
| 가게 운영 | 성장 추천(바로 구매 가능), 포션·자동 납품·채집·원정의 실제 진행 게이지 |
| 약초 | 재료별 공급 진행, 보유량, 지금 환경에서 받는 영향 |
| 포션 | 물약별 보유량, 제조 진행, 대기 이유, 배합 |
| 레시피 | 일반 레시피 1회 구매, 원정에서 발견한 특별 레시피 구매 |
| 원정 | 지역 열기, 진행·조사 상황, 예상 보상, 최근 결과 |
| 가구·직원 | 설비·계열·훈련, 숙성, 주인공(침대·허브차), 후반 투자, **꾸미기**, 직원 |
| 설정 | 캐릭터·정보 모드 바로가기, 로그인 자동 실행, 날씨 효과 강도, 밤의 밝기 하한, **효과음** 켜기/끄기, 효과음 크기 |

헤더의 **통계** 버튼을 누르면 다음 내용이 나옵니다. 새로 오른 단골 단계가 있으면 버튼에 금색 점이 표시됩니다.

- 플레이 시간, 순영업수입, 수입·지출, 누적 운영, 자동 납품, 주인공·숙성(수면·기절 횟수, 피로 때문에 실패한 병 수, 숙성 수입)
- **수집 기록:** 레시피, 특별 레시피, 원정 조사 완료 지역, 단골 기념품, 판매대 소품을 각각 `보유 / 전체`로 보여 줍니다. 모두 모으면 완성 문구가 나옵니다. 읽기 전용입니다. [F24](docs/수집-기록-F24-개발결과.md)
- **단골 손님:** 실제로 물약을 판 거래만 손님별로 기록됩니다(일반 거래 1점, 선호 물약 거래 3점, 점수는 줄지 않음). 4단계를 거치며 짧은 이야기가 열리고, 단골 단계가 되면 기념품을 받습니다. 경제에는 영향을 주지 않습니다. [F22](docs/단골-기록-F22-개발결과.md)

**꾸미기**에는 판매대 소품 칸과 기념품 칸이 있습니다. 판매대 소품(작은 찻잔, 말린 꽃병)은 한 번 사면 계속 가지며, 구매해도 자동으로 장착되지 않습니다. 기념품 4종은 해당 손님이 단골이 되면 받습니다. 장착·교체·해제는 무료이고 기능 효과는 없습니다. 장착한 물건은 작업실 화면에만 보입니다(소품은 판매대 왼쪽, 기념품은 창틀 위). [F23](docs/꾸미기-F23-개발결과.md)

**효과음**은 판매, 제조 완료, 원정 귀환, 해금 때 짧게 납니다. 같은 소리가 너무 자주 나지 않도록 최소 간격을 두고, 트레이로 숨긴 동안에는 해금 소리만 납니다. 효과음 4종은 표준 라이브러리로 합성한 파일입니다. [사운드 v1](docs/사운드-v1-적용결과.md)

## 저장

- 위치: `%APPDATA%\Godot\app_userdata\달그늘 물약상점\potion_shop.json`
- 저장 시점: 10초마다, 구매·강화·설정 변경 직후, 창 드래그를 놓았을 때, 정상 종료할 때
- 안전장치: 먼저 `.tmp` 파일에 쓴 뒤 교체합니다. 교체하기 전에 기존 파일이 정상이면 `.bak`으로 복사해 둡니다. 주 파일을 읽을 수 없으면 `.bak`에서 복구하고, 둘 다 읽을 수 없으면 새 가게로 시작한다고 알려 줍니다. 저장에 실패하면 화면 아래에 표시하고 종료할 때 다시 확인합니다. 장식·주인공 투자 같은 구매는 저장에 실패하면 결제 전 상태로 되돌립니다.
- 형식: 현재 **저장 버전 17**(`scripts/shop_state.gd`의 `SAVE_VERSION`)이며, 버전 1~16 저장도 읽습니다.
- 호환 원칙: 이전 버전 저장은 새 기능의 값을 0이나 빈 상태로 채우고, 기존 골드·재고·진행·통계는 그대로 둡니다. 예를 들어 v15 이하는 단골 기록 0, v16 이하는 장식 없음으로 시작하며, 지난 기록을 추정해 소급 지급하지 않습니다. 현재 버전 저장에 필수 키가 없거나 잘못된 값이 있으면 저장 전체를 거부하고 기존 상태를 바꾸지 않습니다. 창 위치, 관리 창 위치, 효과음 설정은 선택 키라서 값이 잘못되어도 그 항목만 기본값으로 돌아갑니다.
- headless 실행과 `--smoke-test` 실행은 검사 모드라서 플레이어 저장 파일과 Windows 자동 실행 등록을 건드리지 않습니다.
- 게임을 종료한 동안의 수익(오프라인 진행)은 없습니다.

## 개발

### 구조

- `scenes/shop.tscn`: 시작 씬
- `scripts/shop.gd`: 창 모드, 하단 바, 입력, 자동 저장, 각 기능 연결
- `scripts/shop_state.gd`: 경제 시뮬레이션과 저장 데이터. `shop_progression.gd`(환경·명성·원정), `shop_content.gd`(조정 가능한 수치), `shop_regulars.gd`, `shop_decor.gd`, `shop_workshop_operations.gd` 등으로 나뉘어 있습니다.
- `scripts/management_panel.gd`: 관리 창. `save_store.gd`: 파일 저장과 백업 복구. `system_tray.gd`, `shop_audio.gd`
- `native/windows/`: 클릭 통과·전체 화면 양보 브리지와 트레이·작업 표시줄 보조 프로그램의 공개 소스
- `assets/pixel_v1/`: 게임에 쓰는 픽셀 아트(`catalog.json`). `art/`는 편집·검토용 원본이며 엔진에서 불러오지 않습니다.

### 테스트

Godot 콘솔 실행 파일(`Godot_v4.6-stable_win64_console.exe`)로 실행하면 결과를 볼 수 있습니다.

```text
<Godot 콘솔> --headless --path <프로젝트 경로> --script res://tests/test_shop.gd
<Godot 콘솔> --headless --path <프로젝트 경로> --script res://tools/verify_f24_collection.gd
<Godot 콘솔> --path <프로젝트 경로> -- --smoke-test
```

- `tests/test_*.gd` 13개: 경제·저장(`test_shop`), 약초, 공급, 선입선출 진열, 판매대, 진행·원정, 병렬 원정, 확장, 캐릭터 동작, 픽셀 카탈로그·런타임, 통계 유지. `contracts_fixture`, `late_investment_fixture`, `state_compare`는 보조 파일이라 직접 실행하지 않습니다. `test_pixel_catalog`는 `.verification/pixel-runtime-v1/` 폴더가 있어야 끝까지 실행됩니다.
- `--smoke-test`는 실제 창을 열어 주요 화면을 확인하고 `.verification/`에 캡처를 저장합니다. 효과음이 날 수 있습니다.
- 주요 검증 도구(`tools/verify_*.gd`):
  - 기능별: `verify_f21_*`(숙성, 주인공, 피로 HUD, 보조 조제대), `verify_f22_regulars`, `verify_f23_decor`, `verify_f24_collection`, `verify_sfx_v1`, `verify_contracts_*`, `verify_late_*`, `verify_f20_*`
  - 관리 화면: `verify_management`, `verify_management_statistics`, `verify_stable_management_tabs`, `verify_currency_display`
  - 창·Windows: `verify_three_stage_modes`, `verify_window_mode_anchor`, `verify_single_instance`, `verify_system_tray`, `verify_desktop_*`, `verify_windows_startup`, `verify_login_resume`
- 일부 관리 UI 검증 도구는 예전 화면 기준의 기대값이 남아 있어 기준 커밋에서도 실패합니다. 목록은 [F22 결과의 전체 검사](docs/단골-기록-F22-개발결과.md#전체-검사--2026-10-22) 절에 있습니다. `verify_f20_unpurchased`·`verify_f20_recovery`는 `.verification/f20-20261020/`의 고정 자료가 필요하고, `verify_headless_boot`는 fixture APPDATA에서만 실행됩니다.
- 실제 저장으로 플레이를 보여 줄 때는 일반 실행이나 `tools/run_player_game.gd`를 사용합니다. `tools/play_pixel_game_review.gd`는 상태를 초기화하는 아트 검증 전용 도구입니다.

### 아트와 작업 규칙

팔레트, 픽셀 규격(32×32 소품, 32×48 캐릭터, 공통 3배 확대), 고정 후처리 `tools/process_pixel_art.py`, 승인 기록, 투명 배경 규칙은 [AGENTS.md](AGENTS.md)를 따릅니다. 승인되지 않은 후보 아트는 게임에 연결하지 않습니다.

## 아직 없는 것과 결정이 필요한 것

- **종료 중 수익은 없습니다.** 오프라인 보상은 2026-10-08 지시로 보류되어 있습니다.
- 출시 가격, Steam 연동, 포션별 병렬 제조, 자유 장식 배치는 정해지지 않았습니다.
- 가격·확률·보상과 단골 단계 점수·이야기 문장은 초안이라 확인이 필요합니다. 기존 저장의 단골 기록 소급 여부, 통계 점의 읽음 상태 저장 여부도 정해야 합니다.
- 효과음 기본값(켜짐, 크기 0.5)과 빈도는 실제로 들어 보고 정해야 합니다.
- 실제 Windows 화면에서 확인해야 할 것이 남아 있습니다. 전체 화면 양보 동작을 눈으로 확인하는 것, 실제 재부팅·로그아웃 후 자동 실행, 일부 클릭 통과·드래그 조합입니다. 자동 검사는 대부분 headless와 엔진 렌더로 했습니다.
- 이 저장소에는 원격이 없어서 푸시는 할 수 없습니다.
