# 달그늘 물약상점

> 최신 확정 수정 · 2026-10-07: **여기사는 현재 제외. 실제 등장 손님은 여행자·여마법사·엘프·고양이 도적 4종이다.** 등장 추첨·외형 로딩·관리 목록에서 제외 완료. 기존 저장의 여기사 방문은 여행자로 이어가며 과거 방문 집계·골드·재고·진행은 보존한다. 아래 이전 5종 기록보다 이 지시가 우선한다.

Godot 4.6으로 만든 Windows용 작은 방치형 물약 상점입니다.

하단 지도 버튼을 제거하고 조작 바에 세로 여유를 늘렸습니다. 본/정보 모드52px·최소 모드44px, 버튼32px 높이와 중앙 정렬을 사용합니다. 원정은 포스터 돋보기와 관리 탭에서 엽니다. [적용과 검사](docs/하단-UI-여백-적용결과.md).

글씨를 확대했습니다. 관리 본문·탭·버튼16px, 작업실 상태14px, 최소 골드15px·정보 골드22px이며 Pretendard를 유지합니다. 큰 글씨에 맞춰 행과 상태판 간격도 조정했습니다. [적용과 검사 결과](docs/글씨-확대-적용결과.md).

## 작업실 가로 확장과 단일 실행 · 2026-10-10

**이번 범위 구현과 격리 검사 완료.** 현재 본 작업실은 540×300(그림 248px·하단 52px)이며 왼쪽 창틀/약초, 중앙 솥/마녀, 오른쪽 실제 8개 진열/판매대/원정 포스터로 나눴습니다. 제조·고정 약초·고정 원정의 실제 진행과 전체 활동 수, 상세 관리 탭 진입을 연결했습니다. 최소 256×172·정보 320×124·실내 440×704입니다. 경제·저장은 유지합니다.

Windows에서 같은 사용자 저장 위치의 게임은 하나만 운영합니다. 중복 실행은 저장·로그인 기록·운영 전에 종료하며 실행 보호를 잃으면 저장·구매·강화·설정 변경을 막습니다. 일반 headless 실행도 플레이어 저장과 Windows 등록을 건드리지 않는 검사 모드입니다. 기존에 켜져 있는 게임은 재시작하거나 종료하지 않았습니다.

[적용 결과와 검사 근거](docs/작업실-확장과-단일실행-적용결과.md)에는 실제 공용 draw 명령의 파일 렌더가 있습니다. 최신 하단 크기는 [여백 적용 결과](docs/하단-UI-여백-적용결과.md)를 따릅니다. GPU 화면 캡처는 아니며 실제 화면·조명·클릭 통과·드래그·로그오프/재부팅 확인은 사용자에게 남아 있습니다. Computer Use와 실제 플레이어 저장 접근은 하지 않았습니다.

## Windows 로그인마다 자동 실행 · 2026-10-15

**관리 → 가구·직원 → 화면 설정 → Windows 로그인마다 게임 자동 실행**을 켜세요. 이전에 게임을 직접 종료했어도 다음 Windows 로그인 때 마지막 저장의 화면 모드로 열립니다. 자동 실행을 멈추려면 이 설정을 끄세요. 최초 설정은 꺼짐이며 기존 켜짐 설정은 유지합니다.

현재 사용자 계정의 로그인 작업을 Windows 작업 스케줄러에 등록합니다. 로그인 후 10초 지연을 두며 사용자 화면에서 일반 권한으로 실행하고 암호를 저장하지 않습니다. 설정을 켜면 이 게임의 이전 Run 항목을 로그인 작업으로 교체하고, 끄면 두 등록을 모두 해제합니다. 이미 게임이 켜져 있으면 중복 실행을 건너뜁니다. 종료 상태 기록은 자동 실행 허용 여부에 영향을 주지 않습니다.

현재 PC에서 실제 작업 실행 → 정상 종료 → 재실행 및 중복 방지를 확인했습니다. 실제 로그아웃·재부팅 검증은 아직 별도 단계입니다. [수정과 검증 범위](docs/로그인마다-자동-실행-수정결과-20261015.md). 기존 조건부 재개 문서는 이전 정책의 기록입니다.

## 확정 기획 구현 · 2026-10-07

전체 화면 상단의 **작업실**에서 벽·바닥이 없는 투명 화면으로 전환하고 **관리**를 눌러 가게 운영 / 레시피 / 원정 메뉴를 엽니다. 기존 전체 실내·작음·최소 화면은 유지합니다. 관리 창을 닫아도 자동 운영은 계속됩니다. 작업실은 사물을 선명하게 유지하고 빈 영역만 투명하게 하며, 기존 전체 불투명도 설정은 실내·작음·최소 모드에 적용합니다.

레시피 3종의 1회 구매와 별잎 자동 재배, 환경에 따른 특수 제조 성공률, 손님 4종과 선호 거래, 명성·판매 보조 고용·여과기 구매, 자동 원정과 영업 결과를 연결했습니다. 가격·확률·보상은 개발용 임시값입니다. [기획서 완료 상태](docs/달그늘-물약상점-기획서.md)와 [임시값·검증·남은 작업](docs/구현-임시값.md)을 확인하세요. **Windows 작업실 클릭 통과는 구현했으며 최종 조작 검증 일부가 남아 있습니다.** 하단 UI를 제외한 그림 영역은 캐릭터·날씨를 포함해 뒤 프로그램으로 클릭이 전달됩니다. 관리 버튼·아이콘·골드·날씨는 그림 아래에 모았습니다. 하단 바는 동전·골드 / 시간·날씨 / 관리 / 최소화 / 닫기 한 줄이며, 창 이동은 하단 바의 빈 부분을 드래그합니다.

환경 시간·난수·제조 판정·보유·원정·집계는 저장됩니다. 결과 화면은 이미 받은 성과를 보여주며 추가 보상을 지급하지 않습니다. 종료 중 수익은 포함하지 않습니다.

게임 방향, TBH·Deskrawl 비교, 현재 경제 분석과 개발 우선순위는 [달그늘 물약상점 게임 기획서](docs/달그늘-물약상점-기획서.md)에 정리되어 있습니다.

**구현 요청은 [확정 사항과 구현 지시 F01~F12](docs/달그늘-물약상점-기획서.md#확정-사항과-구현-지시)를 기준으로 합니다.** 투명 작업실·관리 UI부터 진행하며, `미정` 수치와 `검토` 기능을 확정 범위로 오해하지 않도록 완료 조건과 우선순위를 구분했습니다.

레시피 연구·아이템 구매·명성·설비 투자·종업원·원정과 복귀 결과는 [성장과 골드 사용처 테이블](docs/성장과-골드-사용처-테이블.md)에 정리되어 있습니다. 후속 기획이며 현재 구현 상태와는 구분합니다.

## 관리 아이콘 · 2026-10-07

솥 강화·약초 화분 강화·정밀 여과기·판매 보조 고용·손님과 명성·자동 운영·기본 레시피·원정 해금·원정 진행 카드에 픽셀 아이콘을 표시합니다. 솥과 화분은 기존 그림을 활용하고, 나머지는 같은 보라색·금색 팔레트로 새로 제작했습니다. 원정 해금과 진행은 지도·나침반 아이콘을 함께 사용합니다.

새 아이콘 6종과 [전체 미리보기](assets/management_v1/design-preview.png)는 `assets/management_v1/`, 원본과 내장 imagegen 프롬프트는 `assets/source/management_v1/`에 있습니다. `tools/prepare_management_art.gd`는 투명도를 보존하여 32 × 40 크기로 가져오고, `tools/preview_management_art.gd`는 실제 관리 화면과 글자 영역을 별도 상태에서 확인합니다.

## 플레이

- **본 작업실**은 540×288 투명 화면으로 마녀·솥·약초·실제 진열·손님과 제조/재배/원정 상태를 표시합니다. 세 작은 상세 버튼은 해당 관리 탭을 엽니다.
- **최소 작업실**은 256×160으로 마녀·솥·러그와 작은 골드·제조 게이지를 표시합니다.
- **정보 모드**는 320×112로 그림 없이 보유 골드, 최근 1분 판매 수입, 재고와 실제 제조 게이지를 표시합니다. 최근 수입은 실제 판매 매출이며 재실행 시 0부터 집계합니다.
- **축소**는 본 → 최소 → 정보, **확대**는 정보 → 최소 → 본 순서로 한 단계씩 전환합니다. 하단 관리/축소/확대/종료의 순서와 아이콘을 유지하며 마지막 단계의 불가능한 동작은 비활성화합니다. 창의 오른쪽 하단 조작 위치를 기준으로 그림이 위에서 아래로 줄고 복원됩니다. 항상 위는 유지하고 고정 전환 버튼은 없습니다.
- 하단 이동 버튼을 드래그해 창을 옮깁니다. 그림 영역은 뒤 프로그램으로 클릭을 전달하며 세 상세 버튼과 하단 조작은 입력을 받습니다. 기존 전체 실내 440×704와 이전 작음 화면 408×296은 유지하지만 현재 3단계 전환에는 추가하지 않습니다.
- 큰 골드 금액은 만·억 단위로 줄이고, 숫자 위에 마우스를 올리면 정확한 금액을 표시합니다. 휴업과 재고 가득 상태도 상태줄에서 확인할 수 있습니다.
- 전체 모드 아래의 **불투명도** 슬라이더는 30~100% 범위입니다. 낮출수록 뒤 화면이 비칩니다. 작은 모드와 최소 모드에도 적용되며 조작 버튼은 선명하게 표시합니다.
- **가게 닫기**를 누르면 손님 방문과 판매가 멈춥니다. 물약 제조는 진열대가 찰 때까지 계속됩니다. **가게 열기**를 누르면 손님이 다시 방문합니다. 게임 종료와 휴업은 별개입니다.
- 체력 물약은 처음에 5초마다 한 병씩 완성됩니다. 진열대에는 최대 12병을 보관합니다.
- 체력 물약은 **약초 2개**, 마나 물약은 **약초 2개 + 달빛 버섯 1개**를 사용합니다. 시작 시 약초 6개가 주어지며, 제조 시작 시 재료를 한 번만 차감합니다. 이미 제조 중인 물약은 재료가 0개여도 끝까지 완성됩니다.
- 약초 화분은 처음에 **4초마다 약초 2개**를 무료로 자동 수확합니다. 기본 보관량은 24개입니다. 재료가 부족하면 자동으로 수확을 기다렸다가 다시 제조하므로 골드가 0이어도 계속 운영할 수 있습니다.
- 화분의 **첫 강화는 24골드**입니다. 강화마다 수확 시간이 14% 줄고 보관량이 8개 늘어납니다. 최대 레벨은 12, 최소 수확 간격은 0.8초입니다. 버튼에 마우스를 올리면 다음 단계의 수확 시간과 보관량을 확인할 수 있습니다.
- 화분은 새싹 → 성장 → 무성한 잎 → 수확 반짝임으로 바뀝니다. 작은 모드의 가게 안에서도 성장 모습을 볼 수 있습니다. 보관함이 차면 성장을 멈추고 재료가 사용되면 다시 자랍니다.
- 제조 막대는 모든 모드에서 실제 제조 진행만 표시합니다. 재료 부족/보관 가득 상태에도 자리를 유지하며 약초 진행으로 대체하지 않습니다. 약초 수확과 물약 제조는 각 보관 한도에서 대기하고 빈자리가 생기면 자동 재개합니다.
- 손님은 3.2초마다 구매를 시도합니다. 체력 물약은 6골드, 마나 물약은 18골드이며 선호품이 있으면 해당 종류의 오래된 병부터 판매하고, 없으면 전체 선입선출로 판매합니다. 윗줄 왼쪽이 맨 앞이며, 판매된 칸 뒤의 포션들이 한 칸씩 당겨집니다. 새 포션은 항상 맨 뒤로 입고됩니다. 전체 진열 한도는 두 종류를 합쳐 12병입니다.
- **제조는 자동**입니다. 해금한 특수 레시피와 별잎이 있으면 순환 제조하고, 없으면 버섯을 사용한 마나 물약 또는 무료 약초의 체력 물약으로 복귀합니다. 이미 만들던 물약의 종류와 진행도는 바뀌지 않습니다. 마나 물약은 같은 솥에서 체력 물약보다 25% 오래 걸립니다.
- **달빛 버섯은 자동 발주**합니다. 영업 중 12초마다 최대 2개를 구매하며 1개당 4골드, 재료 보관함 한도는 6개입니다. 구매 후에도 최소 30골드가 남아야 합니다. 진열대가 가득 차도 재료는 별도로 구매합니다. 재료 공간이 한 칸이면 1개 가격만 냅니다. 보관함이 가득 차거나 골드가 부족하면 완료된 발주 시간을 유지하고, 조건이 충족되는 즉시 구매합니다. 성공한 구매 뒤에만 다음 12초 주기를 시작합니다. 실행 즉시 자동 진행하며 영업·발주 전환 버튼은 없습니다.
- **기본 구매·제작·판매는 자동**이며, 원정은 최초 해금 구매 직후 자동 출발합니다. 기존 꺼짐 저장도 진행을 보존하며 자동 재개합니다. 솥·화분 강화·설비·직원·레시피·원정 해금 구매는 사용자가 직접 선택합니다.
- 진열대가 가득 차면 제조 진행도와 이미 투입한 재료를 유지하며 대기합니다. 판매로 자리가 생기면 이어서 제조합니다.
- 실내 그림은 **뒤쪽 하늘·날씨와 앞쪽 실내 그림**으로 구성합니다. 투명 작업실은 왼쪽 창틀 안에 해·달, 오른쪽 칸에 구름·비를 표시하고 실제 약초 성장 그림을 별도 받침에 놓습니다. 게임 속 하루는 4분, 날씨는 90초 주기이며 현실 시간/날씨와 연결하지 않습니다. 환경 시간과 사물 조명은 기존대로 이어집니다.
- 버섯 발주·화분 강화·솥 강화는 같은 카드 구조를 사용합니다. 왼쪽은 아이템, 가운데는 현재 수치와 다음 상태, 강화 카드 오른쪽에는 강화 버튼이 있고, 발주 카드는 자동 진행 상태만 표시합니다. 화면 높이는 기존 704픽셀을 유지합니다.
- 주인은 숨을 쉬고 눈을 깜빡이며 물약을 제조합니다. 손님은 걸어 들어와 기다리고, 실제 판매가 이루어지면 물약을 받은 뒤 걸어 나갑니다. 재고가 없으면 구매 동작 없이 기다립니다.
- 완성된 물약은 솥에서 진열대 맨 뒤로 이동하고, 도착한 뒤 그 자리에 놓입니다. 판매대의 장식용 복제 물약은 표시하지 않습니다. 맨 앞 물약이 손님에게 출발한 뒤 0.08초 후 나머지 포션들이 0.28초 동안 한 칸씩 미끄러져 이동합니다. 아랫줄 첫 포션은 윗줄 마지막 칸으로 크게 튀지 않고 직선으로 이동합니다. 입고·정리 중 판매가 겹쳐도 현재 위치부터 새 목적지로 이어져 중복이나 순간이동 없이 순서를 유지합니다. 품절 시 손님은 물약이 준비될 때까지 기다립니다.
- 첫 솥 강화 비용은 30골드입니다. 강화할 때마다 제조 시간이 12% 줄어듭니다. 최대 레벨은 15입니다.
- 가게는 다른 프로그램을 사용하는 동안에도 돌아갑니다. 첫 버전에는 종료 중 수익 계산과 소리가 없습니다.

## 저장

10초마다, 구매·강화 및 창 설정 변경 직후, 정상 종료 시 저장합니다. 불투명도는 슬라이더 조작이 끝난 뒤 저장합니다. 골드·설비·재고·제조·성장·발주·원정 진행, 화면 모드와 불투명도를 복원합니다. 이전 영업·발주 꺼짐 상태는 자동 운영으로, 해금한 원정은 자동 진행으로 전환합니다. 항상 위는 기본 적용하며 이전 저장의 고정 전환 값은 사용하지 않습니다. 기존 버전 저장 파일은 그대로 읽으며 예전 미니모드는 작은 모드로 이어집니다.

Windows 기본 저장 위치: `%APPDATA%\Godot\app_userdata\달그늘 물약상점\potion_shop.json`

이전 정상 기록은 `.bak` 파일에 보관하며 주 저장 파일이 손상되면 복구합니다. 저장 실패 시 화면 아래에 표시하고, 종료 전에 확인합니다. 저장 형식은 버전 5이며 버전 1·2·3·4 기록도 읽습니다. 버전 4부터 포션 입고 순서를 저장하므로 재실행 후에도 선입선출이 유지됩니다. 이전 저장에는 입고 이력이 없어서 기존 판매 우선순서(마나 → 체력)로 최초 대기열을 한 번 만들고, 이후 완성된 포션은 맨 뒤에 추가합니다. 버전 1에는 레벨 1 화분과 약초 6개를 추가하고 이전 물약은 체력 물약으로 유지합니다. 제조 중인 물약에 재료를 다시 청구하지 않으며 골드·물약·솥·화분·약초 기록을 유지합니다.

## 검증

Godot 실행 파일에 아래 인수를 전달합니다.

```text
--headless --path <프로젝트 경로> --script res://tests/test_shop.gd
--headless --path <프로젝트 경로> --script res://tests/test_motion.gd
--headless --path <프로젝트 경로> --script res://tests/test_herbs.gd
--headless --path <프로젝트 경로> --script res://tests/test_supply.gd
--path <프로젝트 경로> -- --smoke-test
```

첫 명령은 경제와 저장을, 두 번째는 캐릭터 동작을, 세 번째는 약초 수급과 재료 예약을, 네 번째는 자동 발주와 마나 물약을 검사합니다. 테스트는 솥·화분 레벨 조합별로 30분을 한 번에 계산한 결과와 초당 30회 계산한 결과를 비교하며, 휴업 중 하루가 지나도 재고가 넘치지 않는지 검사합니다. 자동 발주는 판매 수입과 재료 지출이 보유 골드에 정확히 반영되는지, 강화 비용이 자동으로 빠지지 않는지도 확인합니다. 마지막 명령은 실제 게임 씬에서 공통 카드, 자동 구매 전환, 수동 강화 버튼, 마나 제조·판매 수입, 3단계 화면, 약초 대기·재개, 불투명도 등을 확인하고 `.verification/`에 화면 캡처를 저장합니다. 모두 플레이어 저장 파일은 변경하지 않습니다.

`--path <프로젝트 경로> --script res://tools/record_animation.gd`는 실제 생산·판매에 연결된 8초 분량의 애니메이션을 `.verification/motion-frames/`에 캡처합니다. 두 번의 판매를 확인한 뒤 종료하며 플레이어 저장 파일은 사용하지 않습니다.

`--path <프로젝트 경로> --script res://tools/record_herb_preview.gd`는 약초 0개에서 시작하는 14초짜리 실제 화면을 `.verification/herb-frames/`에 기록합니다. 무료 수확 후 제조가 재개되고 두 번 판매되는지 확인하며, 별도의 테스트 상태를 사용해 플레이어 기록에 접근하지 않습니다.

## 사치 요소 기획 — 구현은 다음 단계

자동 운영으로 번 돈을 보고 만족할 수 있도록, 효율 강화와 별도로 **취향을 골라 가게에 남기는 소비**를 만든다. 현재 구현된 기능이 아니며 아래 내용은 후속 작업 후보이다.

| 분류 | 예시 | 보상 | 초기 범위 |
|---|---|---|---|
| 작은 사치 | 새 모자, 고급 찻잔, 간식 접시 | 주인의 외형과 탁자 소품 변화 | 고정 위치에 교체하는 영구 소장품부터 |
| 가게 장식 | 별빛 조명, 양탄자, 화려한 간판 | 자주 보는 가게 화면 변화 | 기존 배경 위 정해진 장식 슬롯 사용 |
| 수집 | 희귀 물약병, 마법책, 손님 선물 | 진열장과 도감이 채워짐 | 구매형 수집부터, 랜덤 뽑기 없이 |
| 여유로운 생활 | 푹신한 의자, 차 마시기, 고양이 | 짧은 휴식과 동행 연출 | 추가 캐릭터 동작이 필요하므로 이후 단계 |

- 사치품은 직접 골라 구매한다. 자동 발주가 취향 소비까지 대신 결정하지 않는다.
- 초반 사치품은 약 5~10분 수입, 수집품은 30~60분 수입, 큰 인테리어는 장기 목표로 잡고 경제 밸런스가 정해진 뒤 고정 가격을 정한다.
- 생산 효율 보너스는 처음에는 붙이지 않는다. 장식을 사지 않아도 운영에 불이익이 없고, 강화와 장식 사이에서 원하는 소비를 고를 수 있게 한다.
- 구매한 물건은 영구 소장하고 무료로 다시 장착한다. 선택한 장식은 전체·작은 모드에서 보이며 최소 모드에는 장식 조작을 넣지 않는다.
- 첫 구현 후보는 **모자 3종 + 탁자 장식 3종**이다. 자유 배치, 방 확장, 동물 행동, 대규모 스킨 교체는 별도 작업으로 나눈다.
- 향후 전체 화면에 `운영 / 꾸미기` 구분을 두고 이번 공통 카드의 이름·설명·가격·버튼 구조를 재사용한다. 지금은 빈 탭이나 구매할 수 없는 버튼을 게임에 추가하지 않는다.
